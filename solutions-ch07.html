Solutions for Chapter 7. The Derivative

Exercise 7.1.2. Hint. Use induction and the product rule.

Solution. For \(n=0\), \(x^0=1\) is constant, so its derivative is \(0\). That is the formula with \(n=0\). For \(n=1\), the difference quotient of \(f(x)=x\) at \(c\) is \(\frac{x-c}{x-c}=1\) for \(x\ne c\), so \(f'(c)=1=1\cdot c^0\).

Now suppose \(\frac{d}{dx}x^k=kx^{k-1}\) for some \(k\in\mathbb{N}\). Since \(x^{k+1}=x\cdot x^k\), the product rule (Theorem 7.1.5 (2)) gives \[\frac{d}{dx}x^{k+1}=1\cdot x^k+x\cdot kx^{k-1}=(k+1)x^k.\] By induction, \(\frac{d}{dx}x^n=nx^{n-1}\) for all \(n\in\mathbb{N}\), and so for all \(n\in\mathbb{N}_0\).

Exercise 7.1.3. Hint. For \(n<0\), write \(x^n=\frac{1}{x^{-n}}\) and use the quotient rule.

Exercise 7.1.4. The difference quotient at \(0\) is \(q(x)=\frac{|x|-0}{x-0}=\frac{|x|}{x}\). It equals \(1\) for \(x>0\) and \(-1\) for \(x<0\). Suppose \(\lim_{x\to0}q(x)=L\). With \(\varepsilon=1\), there is a \(\delta>0\) such that \(|q(x)-L|<1\) whenever \(0<|x|<\delta\). Taking \(x=\frac\delta2\) and \(x=-\frac\delta2\) gives \(|1-L|<1\) and \(|-1-L|<1\). Then, by the Triangle Inequality, \[2=|1-(-1)|\le|1-L|+|L-(-1)|<1+1=2,\] which is impossible. So the limit does not exist, and \(f\) is not differentiable at \(0\).

Exercise 7.2.1. Hint. Apply the Mean Value Theorem to \(e^t\) on the interval between \(0\) and \(x\).

Solution. For \(x=0\), both sides equal \(1\). Since \(\frac{d}{dt}e^t=e^t>0\), \(e^t\) is strictly increasing by Theorem 7.2.7 (2).

Suppose \(x>0\). By the Mean Value Theorem (Theorem 7.2.4) on \([0,x]\), there is a \(c\in(0,x)\) with \(e^x-1=e^c x\). Since \(c>0\), \(e^c>e^0=1\). So \(e^x-1>x\).

Suppose \(x<0\). By the Mean Value Theorem on \([x,0]\), there is a \(c\in(x,0)\) with \(1-e^x=e^c(0-x)\). Since \(c<0\), \(e^c<1\), and \(-x>0\). So \(1-e^x<-x\), that is, \(e^x>1+x\).

In every case, \(e^x\ge1+x\).

Exercise 7.2.2. Hint. Show \(f'(x)=0\) for every \(x\), since \(\frac{|f(x+h)-f(x)|}{|h|}\le M|h|^{\alpha-1}\). Then use Theorem 7.2.7.

Solution. Let \(x\in(a,b)\). For \(y\in(a,b)\) with \(y\ne x\), \[\left|\frac{f(y)-f(x)}{y-x}\right|\le\frac{M|y-x|^\alpha}{|y-x|}=M|y-x|^{\alpha-1}.\] Since \(\alpha>1\), \(M|y-x|^{\alpha-1}\to0\) as \(y\to x\). By the Squeeze Theorem, \(f'(x)=\lim_{y\to x}\frac{f(y)-f(x)}{y-x}=0\). So \(f'(x)=0\) for every \(x\in(a,b)\). By Theorem 7.2.7 (5), \(f\) is constant on \((a,b)\).

Exercise 7.2.5. Hint. Use the Inverse Function Theorem (Theorem 7.2.9) with \(f(x)=x^n\).

Exercise 7.2.7. Assume \(M>0\). If not, replace \(M\) by \(M+1\). Let \(x,y\in I\) with \(x<y\). Since \(f\) is differentiable on \(I\), it is continuous on \([x,y]\) by Theorem 7.1.3. By the Mean Value Theorem (Theorem 7.2.4), there is a \(c\in(x,y)\) with \(f(y)-f(x)=f'(c)(y-x)\). So \[|f(y)-f(x)|=|f'(c)||y-x|\le M|y-x|.\] The same holds with the roles of \(x\) and \(y\) switched, and trivially when \(x=y\). So \(f\) is Lipschitz continuous on \(I\).

For the second part, \(\frac{d}{dx}\sin x=\cos x\) and \(|\cos x|\le1\) for all \(x\). So \(|\sin x-\sin y|\le|x-y|\) for all \(x,y\in\mathbb{R}\).

Exercise 7.3.2. (a) Let \(f(x)=\ln(1+x)\) and \(g(x)=x\) on \((0,1)\). Then \(f(x)\to0\) and \(g(x)\to0\) as \(x\to0^+\), and \(g'(x)=1\ne0\). Since \(\frac{f'(x)}{g'(x)}=\frac{1}{1+x}\to1\), L’Hospital’s Rule (Theorem 7.3.1) gives \(\lim_{x\to0^+}\frac{\ln(1+x)}{x}=1\).

(b) First, \(\lim_{x\to0^+}\frac{\sin x}{2x}=\frac12\). Indeed, \(\sin x\to0\) and \(2x\to0\), \(\frac{d}{dx}(2x)=2\ne0\), and \(\frac{\cos x}{2}\to\frac12\). Now let \(f(x)=1-\cos x\) and \(g(x)=x^2\) on \((0,\pi)\). Then \(f(x)\to0\), \(g(x)\to0\) and \(g'(x)=2x\ne0\). Since \(\frac{f'(x)}{g'(x)}=\frac{\sin x}{2x}\to\frac12\), L’Hospital’s Rule gives \(\lim_{x\to0^+}\frac{1-\cos x}{x^2}=\frac12\).

(c) Applying the rule to \(\frac{e^{-1/x}}{x}\) directly makes things worse. Instead, write \(\frac{e^{-1/x}}{x}=\frac{1/x}{e^{1/x}}\). Let \(f(x)=\frac1x\) and \(g(x)=e^{1/x}\) on \((0,1)\). Then \(g(x)\to\infty\) as \(x\to0^+\), and \(g'(x)=-\frac{e^{1/x}}{x^2}\ne0\). Since \[\frac{f'(x)}{g'(x)}=\frac{-1/x^2}{-e^{1/x}/x^2}=e^{-1/x}\to0\] as \(x\to0^+\), case (2) of L’Hospital’s Rule gives \(\lim_{x\to0^+}\frac{e^{-1/x}}{x}=0\).

Exercise 7.4.1. Let \(a<x<b\) in \(I\) and set \(t=\frac{b-x}{b-a}\). Then \(0<t<1\), \(1-t=\frac{x-a}{b-a}\), and \(ta+(1-t)b=b-t(b-a)=x\). Multiplying by \(b-a>0\) and writing \(b-a=(b-x)+(x-a)\) shows that \[f(x)\le tf(a)+(1-t)f(b)\] is the same as \((b-x)f(x)+(x-a)f(x)\le(b-x)f(a)+(x-a)f(b)\), which is the same as \((b-x)\bigl(f(x)-f(a)\bigr)\le(x-a)\bigl(f(b)-f(x)\bigr)\). Dividing by \((x-a)(b-x)>0\), this is the same as \[\frac{f(x)-f(a)}{x-a}\le\frac{f(b)-f(x)}{b-x}.\tag{$\ast$}\]

(\(\Rightarrow\)) If \(f\) is convex, the first inequality holds, so (\(\ast\)) holds.

(\(\Leftarrow\)) Suppose (\(\ast\)) holds whenever \(a<x<b\). Let \(a,b\in I\) and \(0\le t\le1\). If \(a=b\), \(t=0\) or \(t=1\), then \(f(ta+(1-t)b)=tf(a)+(1-t)f(b)\). If \(a>b\), switch the names of \(a\) and \(b\) and replace \(t\) by \(1-t\). So assume \(a<b\) and \(0<t<1\), and let \(x=ta+(1-t)b\). Then \(a<x<b\) and \(t=\frac{b-x}{b-a}\). By (\(\ast\)) and the equivalences above, \(f(x)\le tf(a)+(1-t)f(b)\). So \(f\) is convex.

The statement for concave functions follows in the same way with every inequality reversed, or by applying the first part to \(-f\).
