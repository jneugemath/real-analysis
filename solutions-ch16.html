Solutions for Chapter 16. The Lebesgue Integral

Exercise 16.1.1. Hint. Given a partition \(\mathcal{P}\), the step functions equal to \(m_i\) and to \(M_i\) on \((x_{i-1},x_i)\) have integrals \(\mathcal{L}(\mathcal{P},f)\) and \(\mathcal{U}(\mathcal{P},f)\). For the converse, use Proposition 16.1.2.

Solution. (\(\Rightarrow\)) Suppose \(f\in\mathcal{R}[a,b]\), and let \(\varepsilon>0\). By Riemann’s Criterion (Theorem 9.2.1), there is a partition \(\mathcal{P}=\{x_0,\dots,x_n\}\) with \(\mathcal{U}(\mathcal{P},f)-\mathcal{L}(\mathcal{P},f)<\varepsilon\). As in the proof of Proposition 16.1.2, let \(\psi=M_i\) and \(\varphi=m_i\) on \((x_{i-1},x_i)\), and let \(\psi=\varphi=f\) at the points \(x_i\). These are step functions on \([a,b]\) with \(\varphi\le f\le\psi\). By Lemma 16.1.1, \(\int_a^b\psi=\mathcal{U}(\mathcal{P},f)\) and \(\int_a^b\varphi=\mathcal{L}(\mathcal{P},f)\). So, by Theorem 9.2.11, \[\int_a^b(\psi-\varphi)=\mathcal{U}(\mathcal{P},f)-\mathcal{L}(\mathcal{P},f)<\varepsilon.\]

(\(\Leftarrow\)) Let \(\varepsilon>0\), and choose step functions \(\varphi\le f\le\psi\) with \(\int_a^b(\psi-\varphi)<\varepsilon\). By Proposition 16.1.2, \(\overline{\int_{a}^{b}}f\le\int_a^b\psi\) and \(\underline{\int_{a}^{b}}f\ge\int_a^b\varphi\). With Theorem 9.1.6, \[0\le\overline{\int_{a}^{b}}f-\underline{\int_{a}^{b}}f\le\int_a^b\psi-\int_a^b\varphi=\int_a^b(\psi-\varphi)<\varepsilon.\] Since \(\varepsilon>0\) was arbitrary, \(\overline{\int_{a}^{b}}f=\underline{\int_{a}^{b}}f\), and \(f\in\mathcal{R}[a,b]\).

Exercise 16.2.1. Hint. Since \(m(\mathbb{Q})=0\), \(\varphi=\left\lfloor x\right\rfloor\) except on a set of measure zero.

Solution. On \([0,1)\), \(\varphi\) is \(1\) at rational points and \(0\) at irrational points. On \([1,2)\) it is \(2\) or \(1\), and on \([2,3)\) it is \(3\) or \(2\). Also \(\varphi(3)=3+1=4\). So \(\varphi\) takes the values \(0,1,2,3,4\), and \[\begin{aligned} A_0&=\{\varphi=0\}=[0,1)\setminus\mathbb{Q}, & A_1&=\{\varphi=1\}=\bigl([0,1)\cap\mathbb{Q}\bigr)\cup\bigl([1,2)\setminus\mathbb{Q}\bigr),\\ A_2&=\{\varphi=2\}=\bigl([1,2)\cap\mathbb{Q}\bigr)\cup\bigl([2,3)\setminus\mathbb{Q}\bigr), & A_3&=\{\varphi=3\}=[2,3)\cap\mathbb{Q},\\ A_4&=\{\varphi=4\}=\{3\}. \end{aligned}\] Intervals and \(\mathbb{Q}\) are measurable (Theorem 14.2.10 and Exercise 14.2.1), so each \(A_i\) is measurable. So \(\varphi\) is measurable, with finitely many values, and it is simple. Its canonical representation is \[\varphi=0\cdot\chi_{A_0}+1\cdot\chi_{A_1}+2\cdot\chi_{A_2}+3\cdot\chi_{A_3}+4\cdot\chi_{A_4}.\] A countable set has measure \(0\). So for an interval \(I\), \(m(I\cap\mathbb{Q})=0\) and \(m(I\setminus\mathbb{Q})=\ell(I)\). So \(m(A_0)=m(A_1)=m(A_2)=1\) and \(m(A_3)=m(A_4)=0\). The function vanishes outside \([0,3]\), so by Definition 16.2.1, \[\int_{[0,3]}\varphi=0\cdot1+1\cdot1+2\cdot1+3\cdot0+4\cdot0=3.\] This agrees with \(\int_0^3\left\lfloor x\right\rfloor\,dx=0+1+2=3\), since \(\varphi=\left\lfloor x\right\rfloor\) except on a set of measure zero.

Exercise 16.2.2. Hint. If \(\varphi=\sum a_i\chi_{A_i}\) is the canonical representation, then \(|\varphi|=\sum|a_i|\chi_{A_i}\).

Solution. Let \(\varphi=\sum_{i=1}^na_i\chi_{A_i}\) be the canonical representation. On \(A_i\), \(|\varphi|=|a_i|\). So \(|\varphi|\) takes finitely many values. For each \(\alpha\), the set \(\{|\varphi|>\alpha\}\) is the union of the sets \(A_i\) with \(|a_i|>\alpha\), which is measurable. So \(|\varphi|\) is simple. Also \(\{|\varphi|\ne0\}=\{\varphi\ne0\}\), which has finite measure.

Drop the terms with \(a_i=0\). The remaining sets \(A_i\) lie in \(\{\varphi\ne0\}\), so they have finite measure, and they are disjoint. Then \(\varphi=\sum_{a_i\ne0}a_i\chi_{A_i}\) and \(|\varphi|=\sum_{a_i\ne0}|a_i|\chi_{A_i}\). By Lemma 16.2.2 and the Triangle Inequality, \[\left|\int\varphi\right|=\left|\sum_{a_i\ne0}a_im(A_i)\right|\le\sum_{a_i\ne0}|a_i|\,m(A_i)=\int|\varphi|.\]

Exercise 16.3.2. Each \(f_n=n\chi_{(0,1/n)}\) is a simple function that vanishes outside \(\left(0,\frac1n\right)\). So \[\int_{[0,1]}f_n=n\,m\left(\left(0,\tfrac1n\right)\right)=n\cdot\frac1n=1.\] The sequence converges to \(0\) at every point. First, \(f_n(0)=0\) for all \(n\). If \(0<x\le1\) and \(n>\frac1x\), then \(x>\frac1n\), so \(f_n(x)=0\). So \(f_n\to0\) on \([0,1]\), and \(\int_{[0,1]}0=0\ne1=\lim_{n\to\infty}\int_{[0,1]}f_n\).

The set \([0,1]\) has finite measure, and each \(f_n\) is measurable. What fails is the bound. Since \(f_n\left(\frac1{2n}\right)=n\), no single \(M\) satisfies \(|f_n|\le M\) for all \(n\).

Exercise 16.3.3. Hint. The first integrand tends to \(1\) on \([0,1)\). For the second, \(2nx\le1+n^2x^2\), so the integrands are bounded by \(\frac12\).

Solution. Both sequences consist of continuous, so measurable, functions on \([0,1]\).

Let \(g_n(x)=\frac{1}{1+x^n}\). Then \(0<g_n\le1\). For \(0\le x<1\), \(x^n\to0\), so \(g_n(x)\to1\). At \(x=1\), \(g_n(1)=\frac12\). So \(g_n\to1\) except at one point, that is, a.e. By Corollary 16.3.7 with \(M=1\), \[\lim_{n\to\infty}\int_{[0,1]}\frac{dm}{1+x^n}=\int_{[0,1]}1\,dm=1.\]

Let \(h_n(x)=\frac{nx}{1+n^2x^2}\). Since \((1-nx)^2\ge0\), \(2nx\le1+n^2x^2\), so \(0\le h_n\le\frac12\) on \([0,1]\). Also \(h_n(0)=0\), and for \(x>0\), \(0\le h_n(x)\le\frac{nx}{n^2x^2}=\frac{1}{nx}\to0\). So \(h_n\to0\) on \([0,1]\). By Corollary 16.3.7 with \(M=\frac12\), \[\lim_{n\to\infty}\int_{[0,1]}\frac{nx}{1+n^2x^2}\,dm=0.\]

To check this, note that \(\frac{1}{2n}\ln(1+n^2x^2)\) has derivative \(h_n(x)\). By Theorem 16.3.3 and the Fundamental Theorem of Calculus, \[\int_{[0,1]}h_n=\int_0^1h_n=\frac{\ln(1+n^2)}{2n}.\] By Lemma 12.2.9 with \(u=\ln n\) and \(m=2\), \(n\ge\frac{(\ln n)^2}{2}\), so \(\ln n\le\sqrt{2n}\). Since \(1+n^2\le2n^2\), \[0\le\frac{\ln(1+n^2)}{2n}\le\frac{\ln2+2\ln n}{2n}\le\frac{\ln2}{2n}+\frac{\sqrt2}{\sqrt n}\to0.\]

Exercise 16.3.4. Hint. Consider \(A=\left\{f>\frac1n\right\}\).

Solution. For \(n\in\mathbb{N}\), let \(A_n=\left\{x\in E:f(x)>\frac1n\right\}\), which is measurable. Since \(f>\frac1n\) on \(A_n\), Theorem 16.3.5 (5) on \(A_n\) gives \[0=\int_{A_n}f\ge\frac1n\,m(A_n).\] So \(m(A_n)=0\). The set \(\{f>0\}\) is \(\bigcup_nA_n\), so it has measure zero by subadditivity. In the same way, with \(B_n=\left\{f<-\frac1n\right\}\), \(0=\int_{B_n}f\le-\frac1n\,m(B_n)\), so \(m(B_n)=0\) and \(m(\{f<0\})=0\). So \(\{f\ne0\}\) has measure zero, that is, \(f=0\) a.e. on \(E\).

Exercise 16.4.1. Hint. Consider the sets \(\{f>\frac1n\}\).

Solution.(\(\Rightarrow\)) Suppose that \(f>0\) on some set \(S\subset E\) with \(m(S)>0\). Then there exists a set \(A\subset S\) with \(m(A)>0\) and an \(\varepsilon>0\) such that \(f\geq\varepsilon\) on \(A\). Indeed, take \(S=\{x\in E:f(x)>0\}\), which is measurable. Then \(S=\bigcup_{k\in\mathbb{N}}\{x\in S:f(x)>\frac1k\}\). If each of these sets had measure zero, then \(m(S)=0\) by subadditivity. So some \(A=\{x\in S:f(x)>\frac1k\}\) has \(m(A)>0\). Take \(\varepsilon=\frac1k\). So \[\int_E f\geq \int_S f\geq \int_A f {}\geq{} \varepsilon m(A)>0.\] The inequalities use Lemma 16.4.4 (2) and Theorem 16.4.2 (3), with \(\int_A\varepsilon=\varepsilon m(A)\). So by contrapositive, if \(\int_E f=0\), \(f=0\) a.e.

(\(\Leftarrow\)) Suppose \(f=0\) a.e. on \(E\). Then \(\int_E f=\int_E 0= 0\) by Theorem 16.4.2 (3), since \(f\le0\) a.e. and \(0\le f\) a.e.

Exercise 16.4.2. First, notice \(\{f_n\}\) is a sequence of nonnegative measurable functions. Note that for each \(x\in\mathbb{R}\), there exists an \(N\in \mathbb{N}\) with \(N>x\) such that for all \(n\geq N\), \(f_n(x)=0\). Thus \(f_n(x)\to f\equiv0\). So the hypotheses of Fatou’s Lemma are satisfied. Now \(\int_{[0,\infty)} f=0\). But \(\int_{[0,\infty)} f_n=\int_{[n,n+1)} 1 = 1\) and so \(\liminf\int_{[0,\infty)} f_n=1\). Thus \(\int_{[0,\infty)} f < \liminf\int_{[0,\infty)} f_n\).

Exercise 16.4.3. Each \(f_n\) is nonnegative and measurable, and the sequence decreases since \([n+1,\infty)\subset[n,\infty)\). For each \(x\in\mathbb{R}\), there exists an \(N\in \mathbb{N}\) with \(N>x\) such that for all \(n\geq N\), \(f_n(x)=0\). Thus \(f_n(x)\to f\equiv0\). So \(\int_\mathbb{R}f=0\). However, \(\int_\mathbb{R}f_n = \int_{[n,\infty)}1=\infty\). So \(0=\int_\mathbb{R}f\neq \lim\int_\mathbb{R}f_n=\infty\) and the Monotone Convergence Theorem does not hold.

Exercise 16.5.1. Hint. For \(\alpha\ge0\), \(\{f^+>\alpha\}=\{f>\alpha\}\). For \(\alpha<0\), it is the whole domain.

Solution. Let \(f\) be measurable with domain \(D\). If \(\alpha\ge0\), then \(\{f^+>\alpha\}=\{f>\alpha\}\). Indeed, if \(f(x)>\alpha\ge0\), then \(f^+(x)=f(x)>\alpha\). If \(f^+(x)>\alpha\ge0\), then \(f^+(x)>0\), so \(f^+(x)=f(x)\). If \(\alpha<0\), then \(\{f^+>\alpha\}=D\), since \(f^+\ge0\). In both cases the set is measurable. So \(f^+\) is measurable.

The function \(-f\) is measurable, since \(\{-f>\alpha\}=\{f<-\alpha\}\) is measurable by Theorem 15.1.1. Since \(f^-=\max\{-f,0\}=(-f)^+\), the first part shows \(f^-\) is measurable.

If \(f(x)\ge0\), then \(f^+(x)=f(x)\) and \(f^-(x)=0\). If \(f(x)<0\), then \(f^+(x)=0\) and \(f^-(x)=-f(x)\). In both cases, \[f^+(x)-f^-(x)=f(x)\quad\text{and}\quad f^+(x)+f^-(x)=|f(x)|.\] These also hold when \(f(x)=\pm\infty\), since one of \(f^+(x)\) and \(f^-(x)\) is \(0\).

Exercise 16.5.2. First, notice that if \(c\ge0\), then \(cf=(cf)^+-(cf)^-=cf^+-cf^-\). That is, \((cf)^+=cf^+\) and \((cf)^-=cf^-\). If \(c<0\), then \(cf=(cf)^+-(cf)^-=-cf^-+cf^+\), with \((cf)^+=-cf^-\) and \((cf)^-=-cf^+\). If \(c=0\), then \(cf=0\) and both sides are \(0\). So by Theorem 16.4.2 (1), for \(c>0\), \[\int_E cf = \int_E(cf)^+-\int_E(cf)^-=\int_Ecf^+-\int_Ecf^-=c\int_Ef^+-c\int_Ef^-=c\left(\int_Ef^+-\int_Ef^-\right)=c\int_Ef.\] For \(c<0\), using (1) with \(-c>0\), \[\begin{aligned} \int_E cf &= \int_E(cf)^+-\int_E(cf)^-=\int_E-cf^--\int_E-cf^+\\ &=-c\int_Ef^--(-c)\int_Ef^+=c\left(-\int_Ef^-+\int_Ef^+\right)=c\int_Ef. \end{aligned}\] In each case \(\int_E(cf)^+\) and \(\int_E(cf)^-\) are finite multiples of \(\int_Ef^\pm\), so they are finite and \(cf\) is integrable.

Exercise 16.5.6. Hint. (a) Integrate by parts first.

Solution. (a) The integrand is continuous on \([0,1]\), so by Theorem 16.3.3 the Lebesgue integral equals the Riemann integral. Integrate by parts (Theorem 9.6.2) with \(\frac{1}{x+1}\) and \(x^n\). \[\int_0^1\frac{nx^{n-1}}{x+1}\,dx=\left[\frac{x^n}{x+1}\right]_0^1+\int_0^1\frac{x^n}{(x+1)^2}\,dx=\frac12+\int_{[0,1]}\frac{x^n}{(x+1)^2}\,dm.\] For \(0\le x<1\), \(\frac{x^n}{(x+1)^2}\to0\), so the integrands tend to \(0\) a.e. on \([0,1]\). Also \(0\le\frac{x^n}{(x+1)^2}\le1\), and \(1\) is integrable over \([0,1]\). By the Dominated Convergence Theorem (Theorem 16.5.6), the last integral tends to \(0\). So the limit is \(\frac12\).

(b) Set \(f_n(x)=\frac{\sin^3(x/n)}{x^3}\). Then \[\lim_{n\to\infty}f_n(x)=\lim_{n\to\infty}\frac{\sin^3(x/n)}{x^3}=\frac{\sin^3(0)}{x^3}=0\] since sine is continuous. Define \(g(x)=\frac{1}{x^3}\), which is integrable on \([1,\infty)\) by Proposition 16.4.15 and the \(p\)-Test. Since \(|\sin^3(x/n)| \le 1\) for all \(n\in\mathbb{N}\) and for all \(x\in[1,\infty)\), \(|f_n(x)|\le g(x)\) for all \(n\in\mathbb{N}\) and for all \(x\in[1,\infty)\). So Lebesgue’s Dominated Convergence Theorem can be applied. Thus \[\lim_{n\to\infty}\int_{[1,\infty)}\frac{\sin^3(x/n)}{x^3}\,dm(x)=\int_{[1,\infty)}\lim_{n\to\infty}\frac{\sin^3(x/n)}{x^3}\,dm(x)=\int_{[1,\infty)}0\,dm=0.\]
