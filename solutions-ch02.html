Solutions for Chapter 2. Cardinality

Exercise 2.1.1. Suppose \(f(n)=f(k)\). Now \(f(n)>0\) or \(f(n)\le 0\). First, suppose \(f(n)>0\). Then \(f(k)>0\), so \(n\) and \(k\) are both even, and \(f(n)=\frac{n}{2}=\frac{k}{2}=f(k)\). So \(k=n\). Now suppose \(f(n)\le 0\). Then \(f(k)\le 0\), so \(n\) and \(k\) are both odd, and so \(f(n)=-\frac{n-1}{2}=-\frac{k-1}{2}=f(k)\). So \(k=n\). Thus \(f\) is an injection.

Now let \(n\in\mathbb{Z}\). If \(n> 0\), \(2n\in\mathbb{N}\) and \(f(2n)=\frac{2n}{2}=n\). If \(n\le0\), \(-2n+1\in\mathbb{N}\) and \(f(-2n+1)=-\frac{-2n+1-1}{2}=n\). So \(f\) is a surjection. Therefore, \(f\) is a bijection and \(\mathbb{N}\sim\mathbb{Z}\). So \(\mathbb{Z}\) is countable.

Exercise 2.1.2. Define \(g:\mathbb{Z}\to\mathbb{O}\) by \(g(k)=2k-1\). Each \(2k-1=2(k-1)+1\) is odd, so \(g\) maps into \(\mathbb{O}\). If \(g(k)=g(j)\), then \(2k-1=2j-1\), so \(k=j\). So \(g\) is one-to-one. If \(m\in\mathbb{O}\), then \(m=2j+1\) for some \(j\in\mathbb{Z}\), and \(g(j+1)=m\). So \(g\) is onto. Thus \(\mathbb{Z}\sim\mathbb{O}\). By Exercise 2.1.1, \(\mathbb{N}\sim\mathbb{Z}\). By Theorem 2.1.8 (3), \(\mathbb{N}\sim\mathbb{O}\), so \(\mathbb{O}\) is countable.

The same idea shows that the odd positive integers are countable. The function \(n\mapsto\frac{n+1}{2}\) is a bijection from them onto \(\mathbb{N}\).

Exercise 2.2.1. Hint. Use induction on \(n\) and Theorem 2.2.1, since \(\mathbb{N}^{n+1}\sim\mathbb{N}^n\times\mathbb{N}\).

Solution. Use induction on \(n\). For \(n=1\), \(\mathbb{N}^1=\mathbb{N}\), and the identity map is a bijection. So \(\mathbb{N}^1\) is countable.

Now suppose \(\mathbb{N}^n\) is countable, and let \(g:\mathbb{N}^n\to\mathbb{N}\) be a bijection. Define \(h:\mathbb{N}^{n+1}\to\mathbb{N}\times\mathbb{N}\) by \[h(x_1,\dots,x_n,x_{n+1})=\bigl(g(x_1,\dots,x_n),x_{n+1}\bigr).\] If \(h(x)=h(y)\), then \(g(x_1,\dots,x_n)=g(y_1,\dots,y_n)\) and \(x_{n+1}=y_{n+1}\). Since \(g\) is one-to-one, \(x_i=y_i\) for \(i=1,\dots,n\). So \(x=y\) and \(h\) is one-to-one. If \((a,b)\in\mathbb{N}\times\mathbb{N}\), let \((x_1,\dots,x_n)=g^{-1}(a)\) and \(x_{n+1}=b\). Then \(h(x_1,\dots,x_{n+1})=(a,b)\). So \(h\) is onto. Thus \(\mathbb{N}^{n+1}\sim\mathbb{N}\times\mathbb{N}\). By Theorem 2.2.1, \(\mathbb{N}\times\mathbb{N}\sim\mathbb{N}\). By Theorem 2.1.8 (3), \(\mathbb{N}^{n+1}\sim\mathbb{N}\). By induction, \(\mathbb{N}^n\) is countable for every \(n\in\mathbb{N}\).

Exercise 2.3.2. Hint. If \(\mathbb{R}\setminus\mathbb{Q}\) were countable, then \(\mathbb{R}=\mathbb{Q}\cup(\mathbb{R}\setminus\mathbb{Q})\) would be countable by Theorem 2.2.6.

Solution. Suppose \(\mathbb{R}\setminus\mathbb{Q}\) is countable. Let \(E_1=\mathbb{Q}\) and \(E_n=\mathbb{R}\setminus\mathbb{Q}\) for \(n\ge2\). Each \(E_n\) is countable, so \(\mathbb{R}=\bigcup_{n=1}^\infty E_n\) is countable by Theorem 2.2.6. Then \([0,1]\) is an infinite subset of a countable set. By Theorem 2.2.4, \([0,1]\) is countable. This contradicts Theorem 2.3.2. So \(\mathbb{R}\setminus\mathbb{Q}\) is uncountable.

Exercise 2.4.3. Since \(|x|<1+|x|\), \(|f(x)|<1\), so \(f\) maps \(\mathbb{R}\) into \((-1,1)\). Also \(f(x)\) has the same sign as \(x\), and \(|f(x)|=\frac{|x|}{1+|x|}\).

One-to-one. Let \(f(x)=f(y)\). Then \(x\) and \(y\) have the same sign, and \(\frac{|x|}{1+|x|}=\frac{|y|}{1+|y|}\). Cross-multiplying gives \(|x|+|x||y|=|y|+|x||y|\), so \(|x|=|y|\). So \(x=y\).

Onto. Let \(y\in(-1,1)\), and let \(x=\frac y{1-|y|}\). Then \(x\) has the sign of \(y\) and \(|x|=\frac{|y|}{1-|y|}\), so \(1+|x|=\frac1{1-|y|}\) and \(f(x)=\frac{y/(1-|y|)}{1/(1-|y|)}=y\).

So \(\mathbb{R}\sim(-1,1)\). The function \(g(x)=\frac{x+1}2\) is a bijection from \((-1,1)\) to \((0,1)\). By Example 2.4.3, \((0,1)\sim[0,1]\), and by Theorem 2.4.4, \([0,1]\sim2^\mathbb{N}\). By Theorem 2.1.8, \(\mathbb{R}\sim[0,1]\sim2^\mathbb{N}\).

Exercise 2.4.4. Let \(\Phi(E)=\chi_E\). If \(E\ne F\), there is a \(k\) in one set and not the other, and then \(\chi_E(k)\ne\chi_F(k)\). So \(\Phi\) is one-to-one. Let \(s\in2^\mathbb{N}\), and let \(E=\{k\in\mathbb{N}:s(k)=1\}\). Then \(\chi_E=s\). So \(\Phi\) is onto, and \(\mathcal{P}(\mathbb{N})\sim2^\mathbb{N}\). By Exercise 2.4.3 and Theorem 2.1.8, \(\mathcal{P}(\mathbb{N})\sim\mathbb{R}\).

Exercise 2.4.5. Hint. If \(A_m\sim A_n\) with \(m<n\), show \(\mathcal{P}(A_m)\lesssim A_m\). Then use Theorems 2.4.2 and 2.4.5.

Exercise 2.4.6. Hint. To invert the map, read off the odd-numbered and even-numbered terms of \(u\). Then use Exercise 2.4.3.

Solution. Call the map \(\Psi\). If \(\Psi(s,t)=\Psi(s',t')=u\), then \(s(k)=u(2k-1)=s'(k)\) and \(t(k)=u(2k)=t'(k)\) for all \(k\). So \((s,t)=(s',t')\). Given \(u\in2^\mathbb{N}\), let \(s(k)=u(2k-1)\) and \(t(k)=u(2k)\). Then \(\Psi(s,t)=u\). So \(\Psi\) is a bijection.

By Exercise 2.4.3, there is a bijection \(\phi:\mathbb{R}\to2^\mathbb{N}\). Then \((x,y)\mapsto(\phi(x),\phi(y))\) is a bijection from \(\mathbb{R}\times\mathbb{R}\) to \(2^\mathbb{N}\times2^\mathbb{N}\). So \(\mathbb{R}\times\mathbb{R}\sim2^\mathbb{N}\times2^\mathbb{N}\sim2^\mathbb{N}\sim\mathbb{R}\) by Theorem 2.1.8.

Exercise 2.4.7. Hint. Constant functions show \(\mathbb{R}\lesssim\mathcal F\). The functions that take only the values \(0\) and \(1\) show \(\mathcal{P}(\mathbb{R})\lesssim\mathcal F\). Then use Theorems 2.4.2 and 2.4.5.
