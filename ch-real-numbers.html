Calculus uses the real numbers without ever defining them. Limits exist. Continuous functions on closed intervals have maximum values. Equations like \(x^2=2\) have solutions. Behind each of these facts is a property of the real numbers that the rational numbers do not have. This chapter finds that property.

The chapter starts from the beginning. Section 1.1 introduces sets and their properties. Section 1.2 covers the integers and the two main tools for proving facts about integers, the Well-Ordering Principle and the Principle of Mathematical Induction. Section 1.3 shows the rational numbers have a hole where \(\sqrt2\) should be. Sections 1.4, 1.5 and 1.6 build the language needed to describe that hole precisely. Section 1.7 introduces the real numbers, which have no holes.

This chapter is also about how to read and write proofs. Each new proof technique is explained the first time it is used.

1.1 Sets

Almost every statement in this book is about sets. Sequences converge to points. Functions are continuous on intervals. Sets have suprema. This section fixes the notation for sets and the basic ways to combine them. It also contains the first proofs in the book. They are short, which makes them a good place to see how a proof is built.

Definition 1.1.1. A set is a collection of objects. The objects in a set are called its elements. If \(x\) is an element of the set \(A\), write \(x\in A\). If \(x\) is not an element of \(A\), write \(x\notin A\). The set with no elements is called the empty set and is denoted \(\emptyset\).

A set can be described by listing its elements, such as \(A=\{1,2,3\}\). A set can also be described by a property its elements satisfy. If \(P(x)\) is a statement about \(x\), then \[\{x\in A:P(x)\}\] is the set of all elements \(x\) of \(A\) for which \(P(x)\) is true. It is read “the set of all \(x\) in \(A\) such that \(P(x)\).”

Example 1.1.2. Let \(A=\{1,2,3,4,5,6\}\). Then \(\{x\in A:x>3\}=\{4,5,6\}\). Also, \(\{1,2,3\}=\{3,1,2\}\). The order the elements are listed in does not matter.

Definition 1.1.3. Let \(A\) and \(B\) be sets. \(A\) is a subset of \(B\), written \(A\subset B\), if every element of \(A\) is an element of \(B\). \(A\) and \(B\) are equal, written \(A=B\), if \(A\subset B\) and \(B\subset A\). If \(A\subset B\) and \(A\ne B\), \(A\) is a proper subset of \(B\), written \(A\subsetneqq B\).

Remark 1.1.4. Some books write \(A\subseteq B\) for a subset and \(A\subset B\) for a proper subset. In this book, \(A\subset B\) allows \(A=B\). Notice every set is a subset of itself. Also, \(\emptyset\subset A\) for every set \(A\). Since \(\emptyset\) has no elements, there is nothing to check.

Example 1.1.5. \(\{1,2\}\subsetneqq\{1,2,3\}\). However, \(\{1,4\}\not\subset\{1,2,3\}\), since \(4\in\{1,4\}\) but \(4\notin\{1,2,3\}\).

Proof Technique (Proving One Set Is a Subset of Another). To prove \(A\subset B\), let \(x\) be an arbitrary element of \(A\). Then show \(x\in B\). The word arbitrary is important. Nothing can be assumed about \(x\) except that \(x\in A\). Since \(x\) was any element of \(A\), every element of \(A\) is in \(B\).

Proof Technique (Proving Two Sets Are Equal). To prove \(A=B\), prove two things. First show \(A\subset B\). Then show \(B\subset A\). This is called a double inclusion argument. The proof of Theorem 1.1.9 (3) below is an example.

Definition 1.1.6. Let \(A\) and \(B\) be sets.

  1. The union of \(A\) and \(B\) is \(A\cup B=\{x:x\in A\text{ or }x\in B\}\).

  2. The intersection of \(A\) and \(B\) is \(A\cap B=\{x:x\in A\text{ and }x\in B\}\).

  3. The difference of \(A\) and \(B\) is \(A\setminus B=\{x:x\in A\text{ and }x\notin B\}\).

If \(A\cap B=\emptyset\), \(A\) and \(B\) are disjoint. If every set under discussion is a subset of a fixed set \(X\), then \(X\) is called the universal set. In this case, the complement of \(A\) is \(A^c=X\setminus A\).

Remark 1.1.7. In mathematics, “or” always allows both. The statement “\(x\in A\) or \(x\in B\)” is true when \(x\) is in both sets.

Example 1.1.8. Let \(X=\{1,2,3,4,5,6\}\), \(A=\{1,2,3,4\}\), and \(B=\{3,4,5\}\). Then \[A\cup B=\{1,2,3,4,5\},\quad A\cap B=\{3,4\},\quad A\setminus B=\{1,2\},\quad B\setminus A=\{5\}.\] Also, \(A^c=\{5,6\}\) and \(B^c=\{1,2,6\}\). Notice \(A^c\cap B^c=\{6\}=(A\cup B)^c\). This is a special case of De Morgan’s Laws (Theorem 1.1.10).

Proof Technique (Direct Proof). Most theorems have the form “If \(P\), then \(Q\).” The statement \(P\) is the hypothesis. The statement \(Q\) is the conclusion. In a direct proof, assume \(P\) is true. Then use definitions and results that are already proved to show \(Q\) is true. Each step must follow from the steps before it. A good first step is to write out what the hypothesis means using definitions. Then write out what the conclusion means. The proof connects the two. The proofs of Theorem 1.1.9 are direct proofs.

Theorem 1.1.9. Let \(A\), \(B\) and \(C\) be subsets of a universal set \(X\).

  1. \(A\cap B\subset A\) and \(A\subset A\cup B\).

  2. \(A\cap B=B\cap A\) and \(A\cup B=B\cup A\).

  3. \(A\cap(B\cup C)=(A\cap B)\cup(A\cap C)\).

  4. \(A\cup(B\cap C)=(A\cup B)\cap(A\cup C)\).

  5. \(A\setminus B=A\cap B^c\).

Proof.

  1. Let \(x\in A\cap B\). Then \(x\in A\) and \(x\in B\). So \(x\in A\). Thus \(A\cap B\subset A\).

    Next, let \(x\in A\). Then \(x\in A\) or \(x\in B\). So \(x\in A\cup B\). Thus \(A\subset A\cup B\).

  2. Exercise.

  3. Let \(x\in A\cap(B\cup C)\). Then \(x\in A\) and \(x\in B\cup C\). So \(x\in B\) or \(x\in C\). If \(x\in B\), then \(x\in A\cap B\). If \(x\in C\), then \(x\in A\cap C\). In either case, \(x\in(A\cap B)\cup(A\cap C)\). So \(A\cap(B\cup C)\subset(A\cap B)\cup(A\cap C)\).

    Now let \(x\in(A\cap B)\cup(A\cap C)\). Then \(x\in A\cap B\) or \(x\in A\cap C\). If \(x\in A\cap B\), then \(x\in A\) and \(x\in B\). If \(x\in A\cap C\), then \(x\in A\) and \(x\in C\). In either case, \(x\in A\) and \(x\in B\cup C\). So \(x\in A\cap(B\cup C)\). Thus \((A\cap B)\cup(A\cap C)\subset A\cap(B\cup C)\).

    Therefore \(A\cap(B\cup C)=(A\cap B)\cup(A\cap C)\).

  4. Exercise.

  5. Exercise.

∎

Proof Technique (Proof by Cases). Sometimes a proof splits into cases. Each case must be handled, and together the cases must cover every possibility. In the proof of Theorem 1.1.9 (3), \(x\in B\cup C\) means \(x\in B\) or \(x\in C\). So there are two cases. The proof handles each one. Then it notices both cases give the same conclusion.

Theorem 1.1.10 (De Morgan’s Laws).

Let \(A\) and \(B\) be subsets of a universal set \(X\). Then

  1. \((A\cup B)^c=A^c\cap B^c\); and

  2. \((A\cap B)^c=A^c\cup B^c\).

Proof.

  1. Let \(x\in(A\cup B)^c\). Then \(x\in X\) and \(x\notin A\cup B\). If \(x\in A\), then \(x\in A\cup B\). So \(x\notin A\). Similarly, \(x\notin B\). Thus \(x\in A^c\) and \(x\in B^c\). So \(x\in A^c\cap B^c\). Therefore \((A\cup B)^c\subset A^c\cap B^c\).

    Now let \(x\in A^c\cap B^c\). Then \(x\notin A\) and \(x\notin B\). So \(x\) is not in \(A\cup B\). Thus \(x\in(A\cup B)^c\). Therefore \(A^c\cap B^c\subset(A\cup B)^c\). So \((A\cup B)^c=A^c\cap B^c\).

  2. Exercise.

∎

Definition 1.1.11. Let \(\Lambda\) be a nonempty set. Suppose for each \(\alpha\in\Lambda\), \(A_\alpha\) is a set. Then \(\{A_\alpha\}_{\alpha\in\Lambda}\) is called a family of sets and \(\Lambda\) is called an index set. Define the union and intersection of the family by \[\bigcup_{\alpha\in\Lambda}A_\alpha=\{x:x\in A_\alpha\text{ for some }\alpha\in\Lambda\}\] and \[\bigcap_{\alpha\in\Lambda}A_\alpha=\{x:x\in A_\alpha\text{ for all }\alpha\in\Lambda\}.\] If \(\Lambda=\{1,2,\dots,n\}\), write \(\bigcup_{i=1}^nA_i\) and \(\bigcap_{i=1}^nA_i\). If \(\Lambda=\{1,2,3,\dots\}\), write \(\bigcup_{n=1}^\infty A_n\) and \(\bigcap_{n=1}^\infty A_n\).

Example 1.1.12. For each \(n\in\{1,2,3,\dots\}\), let \(A_n=\{1,2,\dots,n\}\). Then \(\bigcup_{n=1}^\infty A_n=\{1,2,3,\dots\}\) and \(\bigcap_{n=1}^\infty A_n=\{1\}\).

For each \(n\in\{1,2,3,\dots\}\), let \(B_n=\{n,n+1,n+2,\dots\}\). Then \(\bigcap_{n=1}^\infty B_n=\emptyset\). To see this, let \(k\) be any positive integer. Then \(k\notin B_{k+1}\). So \(k\) is not in every \(B_n\).

Proof Technique (Negating Statements). The negation of a statement \(P\) is the statement “\(P\) is false,” or “not \(P\).” Many proofs need the negation of a complicated statement. These rules give it.

  • The negation of “\(P\) and \(Q\)” is “not \(P\) or not \(Q\).”

  • The negation of “\(P\) or \(Q\)” is “not \(P\) and not \(Q\).”

  • The negation of “for all \(x\), \(P(x)\)” is “there exists an \(x\) such that not \(P(x)\).”

  • The negation of “there exists an \(x\) such that \(P(x)\)” is “for all \(x\), not \(P(x)\).”

  • The negation of “if \(P\), then \(Q\)” is “\(P\) and not \(Q\).”

For example, \(A\subset B\) means every element of \(A\) is in \(B\). So \(A\not\subset B\) means there exists an element of \(A\) that is not in \(B\). Notice De Morgan’s Laws match the first two rules.

Statements in analysis often have several “for all” and “there exists” phrases in a row. To negate one, work from left to right. Change each “for all” to “there exists.” Change each “there exists” to “for all.” Then negate the last statement. Exercise 1.1.10 gives practice.

Theorem 1.1.13 (De Morgan’s Laws).

Let \(\{A_\alpha\}_{\alpha\in\Lambda}\) be a family of subsets of a universal set \(X\). Then

  1. \(\left(\bigcup_{\alpha\in\Lambda}A_\alpha\right)^c=\bigcap_{\alpha\in\Lambda}A_\alpha^c\); and

  2. \(\left(\bigcap_{\alpha\in\Lambda}A_\alpha\right)^c=\bigcup_{\alpha\in\Lambda}A_\alpha^c\).

Proof.

  1. Let \(x\in\left(\bigcup_{\alpha\in\Lambda}A_\alpha\right)^c\). Then \(x\notin\bigcup_{\alpha\in\Lambda}A_\alpha\). So it is false that \(x\in A_\alpha\) for some \(\alpha\in\Lambda\). Negating this statement, \(x\notin A_\alpha\) for all \(\alpha\in\Lambda\). So \(x\in A_\alpha^c\) for all \(\alpha\in\Lambda\). Thus \(x\in\bigcap_{\alpha\in\Lambda}A_\alpha^c\).

    Now let \(x\in\bigcap_{\alpha\in\Lambda}A_\alpha^c\). Then \(x\notin A_\alpha\) for all \(\alpha\in\Lambda\). So there is no \(\alpha\in\Lambda\) with \(x\in A_\alpha\). Thus \(x\notin\bigcup_{\alpha\in\Lambda}A_\alpha\). So \(x\in\left(\bigcup_{\alpha\in\Lambda}A_\alpha\right)^c\).

  2. Exercise.

∎

Definition 1.1.14. Let \(A\) and \(B\) be sets. An ordered pair \((a,b)\) is a pair of objects where the order matters. Two ordered pairs \((a,b)\) and \((c,d)\) are equal if \(a=c\) and \(b=d\). The Cartesian product of \(A\) and \(B\) is \[A\times B=\{(a,b):a\in A,\ b\in B\}.\]

Example 1.1.15. \(\{1,2\}\times\{3,4,5\}=\{(1,3),(1,4),(1,5),(2,3),(2,4),(2,5)\}\).

Definition 1.1.16. A relation on a set \(A\) is a subset \(R\) of \(A\times A\). If \((x,y)\in R\), write \(x\,R\,y\). A relation \(\sim\) on \(A\) is an equivalence relation if

  1. \(x\sim x\) for all \(x\in A\) (reflexive);

  2. if \(x\sim y\), then \(y\sim x\) (symmetric); and

  3. if \(x\sim y\) and \(y\sim z\), then \(x\sim z\) (transitive).

Proof Technique (Counterexample). A statement of the form “for all \(x\), \(P(x)\)” is false if \(P(x)\) fails for just one \(x\). An \(x\) for which \(P(x)\) fails is called a counterexample. One counterexample is enough to show a “for all” statement is false. However, examples where \(P(x)\) is true never prove a “for all” statement. Example 1.1.17 uses a counterexample.

Example 1.1.17. Equality is an equivalence relation on any set. Now consider the relation \(\le\) on \(\{1,2,3\}\). It is reflexive and transitive. However, it is not symmetric. To see this, notice \(1\le 2\) but \(2\not\le 1\). So \(x=1\), \(y=2\) is a counterexample. Thus \(\le\) is not an equivalence relation.

Definition 1.1.18. The power set of a set \(A\), denoted \(\mathcal{P}(A)\), is the set of all subsets of \(A\).

Example 1.1.19. \(\mathcal{P}(\{1,2\})=\bigl\{\emptyset,\{1\},\{2\},\{1,2\}\bigr\}\).

1.2 The Integers

The integers are the starting point for every number system in this chapter. This section does not prove the rules of integer arithmetic. It takes them as known. Instead it proves facts about even numbers, odd numbers and division. These facts are needed later, for example to show \(\sqrt2\) is irrational. Along the way, the section introduces the Well-Ordering Principle and induction. They are the main tools for proving a statement about every natural number at once.

Definition 1.2.1. Define the natural numbers \(\mathbb{N}=\{1,2,3,\dots\}\), the whole numbers \(\mathbb{N}_0=\{0,1,2,\dots\}\) and the integers \(\mathbb{Z}=\{\dots,-3,-2,-1,0,1,2,3,\dots\}\).

Remark 1.2.2. This book assumes the usual arithmetic and order of the integers. Sums, differences and products of integers are integers. The rules of algebra, such as \(m(n+k)=mn+mk\), hold. Also, if \(n\in\mathbb{Z}\) and \(n>0\), then \(n\ge1\). These facts can be proved from a short list of axioms, but that is not done here.

Definition 1.2.3. An integer \(n\) is even if \(n=2k\) for some \(k\in\mathbb{Z}\). An integer \(n\) is odd if \(n=2k+1\) for some \(k\in\mathbb{Z}\).

Example 1.2.4. \(0=2\cdot0\) is even. \(-7=2(-4)+1\) is odd.

Theorem 1.2.5. Let \(m,n\in\mathbb{Z}\).

  1. If \(m\) and \(n\) are even, then \(m+n\) is even.

  2. If \(m\) and \(n\) are odd, then \(m+n\) is even.

  3. If \(m\) is even, then \(mn\) is even.

  4. If \(m\) and \(n\) are odd, then \(mn\) is odd.

Proof.

  1. Since \(m\) and \(n\) are even, \(m=2j\) and \(n=2k\) for some \(j,k\in\mathbb{Z}\). Then \[m+n=2j+2k=2(j+k).\] Since \(j+k\in\mathbb{Z}\), \(m+n\) is even.

  2. Since \(m\) and \(n\) are odd, \(m=2j+1\) and \(n=2k+1\) for some \(j,k\in\mathbb{Z}\). Then \[m+n=2j+2k+2=2(j+k+1).\] Since \(j+k+1\in\mathbb{Z}\), \(m+n\) is even.

  3. Exercise.

  4. Since \(m\) and \(n\) are odd, \(m=2j+1\) and \(n=2k+1\) for some \(j,k\in\mathbb{Z}\). Then \[mn=4jk+2j+2k+1=2(2jk+j+k)+1.\] Since \(2jk+j+k\in\mathbb{Z}\), \(mn\) is odd.

∎

Remark 1.2.6. The proof of (1) writes \(m=2j\) and \(n=2k\). Writing \(m=2k\) and \(n=2k\) would assume \(m=n\). Each new object in a proof gets its own letter.

Proof Technique (Converse). The converse of “If \(P\), then \(Q\)” is “If \(Q\), then \(P\).” A statement and its converse are different statements. One can be true while the other is false. For example, the converse of Theorem 1.2.5 (1) is “If \(m+n\) is even, then \(m\) and \(n\) are even.” This is false. A counterexample is \(m=n=1\). Then \(m+n=2\) is even, but \(1\) is not even, since \(1=2k\) has no solution \(k\in\mathbb{Z}\).

The next axiom looks obvious. It is still the key property of \(\mathbb{N}\). It fails for \(\mathbb{Z}\), which has no smallest element. It also fails for the positive rational numbers, since \(\frac{q}{2}\) is a smaller positive rational than \(q\).

Axiom 1.2.7 (The Well-Ordering Principle).

Every nonempty subset of \(\mathbb{N}\) has a smallest element.

Corollary 1.2.8. Every nonempty subset of \(\mathbb{N}_0\) has a smallest element.

Proof. Let \(S\subset\mathbb{N}_0\) with \(S\ne\emptyset\). If \(0\in S\), then \(0\) is the smallest element of \(S\), since every element of \(\mathbb{N}_0\) is at least \(0\). If \(0\notin S\), then \(S\subset\mathbb{N}\). So by the Well-Ordering Principle, \(S\) has a smallest element.

∎

Proof Technique (Proof by Contradiction). To prove a statement \(P\) by contradiction, assume \(P\) is false. Then use this assumption to reach a statement that is impossible. Examples are \(1<0\), or \(x\in A\) and \(x\notin A\). This impossible statement is called a contradiction. A false statement leads to a contradiction, but a true statement never does. So the assumption that \(P\) is false must be wrong, and \(P\) is true. Proofs by contradiction in this book start with “Assume by way of contradiction.” The proof of Theorem 1.2.9 is by contradiction.

Theorem 1.2.9 (Principle of Mathematical Induction).

For each \(n\in\mathbb{N}\), let \(P(n)\) be a statement about the positive integer \(n\). If

  1. \(P(1)\) is true, and

  2. \(P(k+1)\) is true whenever \(P(k)\) is true,

then \(P(n)\) is true for all \(n\in\mathbb{N}\).

Proof. Assume by way of contradiction that there exists a positive integer \(n\) such that the statement \(P(n)\) is false. Let \[A=\{k\in\mathbb{N}:P(k)\text{ is false}\}.\] Now \(n\in A\), so \(A\ne\emptyset\), and \(A\) has a smallest element \(m\). Since \(P(1)\) is true, \(1\notin A\), and \(m>1\). So \(m-1\in\mathbb{N}\). Also, since \(m\) is the smallest element of \(A\), \(m-1\notin A\). So \(P(m-1)\) is true. But then, by (2), \(P(m)\) is also true. So \(m\notin A\), a contradiction. Consequently, \(P(n)\) must be true for all \(n\in\mathbb{N}\).

∎

Induction works like a row of dominoes. Condition (1) knocks over the first domino. Condition (2) says each domino knocks over the next one. Then every domino falls.

Proof Technique (Proof by Induction). To prove \(P(n)\) is true for all \(n\in\mathbb{N}\) by induction, do two steps. First, prove \(P(1)\) is true. This is the base case. Second, let \(k\in\mathbb{N}\) and assume \(P(k)\) is true. Then prove \(P(k+1)\) is true. This is the inductive step. The assumption that \(P(k)\) is true is called the inductive hypothesis. The inductive step does not assume what is being proved. It only shows that each statement implies the next one.

Induction can start at any integer \(n_0\). To prove \(P(n)\) for all integers \(n\ge n_0\), prove \(P(n_0)\). Then prove \(P(k)\) implies \(P(k+1)\) for all \(k\ge n_0\). This follows from Theorem 1.2.9 applied to the statement \(Q(n)=P(n+n_0-1)\).

Definition 1.2.10. Many objects are defined one step at a time. This is called a recursive definition. Let \(a,a_1,a_2,\dots\) be numbers.

  1. The powers of \(a\) are \(a^1=a\) and \(a^{n+1}=a^n\cdot a\) for \(n\in\mathbb{N}\). If \(a\ne0\), \(a^0=1\).

  2. The sum of \(a_1,\dots,a_n\) is \(\sum_{i=1}^1a_i=a_1\) and \(\sum_{i=1}^{n+1}a_i=\sum_{i=1}^na_i+a_{n+1}\) for \(n\in\mathbb{N}\). So \(\sum_{i=1}^na_i=a_1+a_2+\cdots+a_n\). Sums starting at an index other than \(1\) are defined the same way.

  3. The factorial of \(n\in\mathbb{N}_0\) is \(0!=1\) and \((n+1)!=(n+1)\cdot n!\). So \(n!=1\cdot2\cdots n\) for \(n\in\mathbb{N}\).

Example 1.2.11. For all \(n\in\mathbb{N}\), \[\sum_{i=1}^ni=\frac{n(n+1)}{2}.\] To prove this by induction, first notice that when \(n=1\), the left side is \(1\) and the right side is \(\frac{1\cdot2}{2}=1\). So the statement is true for \(n=1\). Now let \(k\in\mathbb{N}\) and assume \(\sum_{i=1}^ki=\frac{k(k+1)}{2}\). Then \[\sum_{i=1}^{k+1}i=\sum_{i=1}^ki+(k+1)=\frac{k(k+1)}{2}+(k+1)=\frac{(k+1)(k+2)}{2}.\] So the statement is true for \(k+1\). By induction, it is true for all \(n\in\mathbb{N}\).

Proof Technique (Proving Uniqueness). To prove there is exactly one object with some property, prove two things. Existence shows there is at least one such object. Uniqueness shows there is at most one. To prove uniqueness, assume two objects have the property. Then show they are equal. The proof of Theorem 1.2.12 does both.

Theorem 1.2.12 (Division Algorithm).

Let \(n\in\mathbb{Z}\) and \(d\in\mathbb{N}\). Then there exist unique \(q,r\in\mathbb{Z}\) such that \(n=qd+r\) and \(0\le r<d\).

Proof. First, the existence of \(q\) and \(r\). Let \[S=\{n-kd:k\in\mathbb{Z},\ n-kd\ge0\}.\] Let \(k=-|n|\), where \(|n|=n\) if \(n\ge0\) and \(|n|=-n\) if \(n<0\). Then \(n-kd=n+|n|d\ge n+|n|\ge0\). So \(S\) is a nonempty subset of \(\mathbb{N}_0\). By Corollary 1.2.8, \(S\) has a smallest element \(r\). So \(r=n-qd\) for some \(q\in\mathbb{Z}\), and \(r\ge0\). Assume by way of contradiction that \(r\ge d\). Then \[r-d=n-(q+1)d\ge0.\] So \(r-d\in S\). But \(r-d<r\), a contradiction to the fact that \(r\) is the smallest element of \(S\). So \(0\le r<d\) and \(n=qd+r\).

Next, uniqueness. Suppose \(n=qd+r=q'd+r'\) with \(0\le r<d\) and \(0\le r'<d\). Without loss of generality, assume \(r\le r'\). Then \[r'-r=(q-q')d.\] Also, \(0\le r'-r<d\). So \(0\le(q-q')d<d\). Dividing by \(d\), \(0\le q-q'<1\). Since \(q-q'\) is an integer, \(q-q'=0\). So \(q=q'\), and then \(r=r'\).

∎

Proof Technique (Without Loss of Generality). Sometimes two cases are the same after renaming. In the proof of Theorem 1.2.12, the cases \(r\le r'\) and \(r'\le r\) are the same with the roles of \((q,r)\) and \((q',r')\) switched. So only one case needs a proof. Writing “without loss of generality” tells the reader this. Only use it when the other cases really are the same.

Corollary 1.2.13. Every integer is either even or odd, but not both.

Proof. Let \(n\in\mathbb{Z}\). By the Division Algorithm with \(d=2\), \(n=2q+r\) where \(q\in\mathbb{Z}\) and \(r\in\{0,1\}\). If \(r=0\), \(n\) is even. If \(r=1\), \(n\) is odd. If \(n\) were both even and odd, then \(n=2q+0=2q'+1\) for some \(q,q'\in\mathbb{Z}\). This contradicts the uniqueness part of the Division Algorithm.

∎

Example 1.2.14. For every \(n\in\mathbb{Z}\), \(n^2+n\) is even. By Corollary 1.2.13, there are two cases. If \(n\) is even, then \(n=2k\) for some \(k\in\mathbb{Z}\). So \(n^2+n=4k^2+2k=2(2k^2+k)\) is even. If \(n\) is odd, then \(n=2k+1\) for some \(k\in\mathbb{Z}\). So \[n^2+n=4k^2+4k+1+2k+1=2(2k^2+3k+1)\] is even.

Proof Technique (If and Only If). The statement “\(P\) if and only if \(Q\)” means both “If \(P\), then \(Q\)” and “If \(Q\), then \(P\)” are true. So a proof of an if and only if statement has two parts. The (\(\Rightarrow\)) part assumes \(P\) and proves \(Q\). The (\(\Leftarrow\)) part assumes \(Q\) and proves \(P\).

Proof Technique (Contrapositive). The contrapositive of “If \(P\), then \(Q\)” is “If not \(Q\), then not \(P\).” A statement and its contrapositive are either both true or both false. So to prove a statement, it is enough to prove its contrapositive. In the (\(\Leftarrow\)) part of the proof of Theorem 1.2.15, it is hard to start from “\(n^2\) is even.” It is easier to start from “\(n\) is not even.”

Theorem 1.2.15. Let \(n\in\mathbb{Z}\). Then \(n\) is even if and only if \(n^2\) is even.

Proof. (\(\Rightarrow\)) Suppose \(n\) is even. Then by Theorem 1.2.5 (3), \(n^2=n\cdot n\) is even.

(\(\Leftarrow\)) This part is proved by contrapositive. Suppose \(n\) is not even. By Corollary 1.2.13, \(n\) is odd. So by Theorem 1.2.5 (4), \(n^2=n\cdot n\) is odd. By Corollary 1.2.13, \(n^2\) is not even. So if \(n^2\) is even, then \(n\) is even.

∎

Proof Technique (Smallest Counterexample). Here is another way to use the Well-Ordering Principle. To prove a statement for all \(n\in\mathbb{N}\), assume by way of contradiction that it is false for some \(n\). Then the set of such \(n\) is a nonempty subset of \(\mathbb{N}\). So it has a smallest element. Then use the fact that the statement is true for every smaller number to reach a contradiction. The existence part of the proof of Theorem 1.2.16 works this way.

Theorem 1.2.16. For each \(k\in\mathbb{N}\), there exist unique \(m,n\in\mathbb{N}\) such that \(k=2^{m-1}(2n-1)\).

Proof. First, existence. Assume by way of contradiction that some \(k\in\mathbb{N}\) cannot be written this way. Let \(S\) be the set of all such \(k\). Then \(S\) is a nonempty subset of \(\mathbb{N}\). So by the Well-Ordering Principle, \(S\) has a smallest element \(k\).

If \(k\) is odd, then \(k=2j+1\) for some \(j\in\mathbb{N}_0\). So \(k=2^{1-1}\bigl(2(j+1)-1\bigr)\) with \(1,j+1\in\mathbb{N}\). So \(k\notin S\), a contradiction.

If \(k\) is even, then \(k=2j\) for some \(j\in\mathbb{N}\), and \(j<k\). Since \(k\) is the smallest element of \(S\), \(j\notin S\). So \(j=2^{m-1}(2n-1)\) for some \(m,n\in\mathbb{N}\). Then \(k=2j=2^{(m+1)-1}(2n-1)\) with \(m+1,n\in\mathbb{N}\). So \(k\notin S\), a contradiction.

By Corollary 1.2.13, these are the only two cases. So \(S=\emptyset\).

Next, uniqueness. Suppose \(2^{m-1}(2n-1)=2^{p-1}(2q-1)\) with \(m,n,p,q\in\mathbb{N}\). Without loss of generality, assume \(m\le p\). Dividing by \(2^{m-1}\), \[2n-1=2^{p-m}(2q-1).\] If \(p>m\), then the right side is even by Theorem 1.2.5 (3), and the left side is odd. This contradicts Corollary 1.2.13. So \(p=m\). Then \(2n-1=2q-1\), and \(n=q\).

∎

1.3 The Rational Numbers

The rational numbers are the fractions. They can be added, subtracted, multiplied and divided, and the answers are still rational. So for arithmetic, \(\mathbb{Q}\) is enough. The trouble is that \(\mathbb{Q}\) has holes. The side of a square with area \(2\) should have a length \(p\) with \(p^2=2\). Theorem 1.3.4 shows no rational number does this. Theorem 1.3.5 shows something stronger. The rational numbers with \(p^2<2\) and the ones with \(p^2>2\) crowd right up against each other, and no rational number sits between them.

Definition 1.3.1. Define the rational numbers \(\mathbb{Q}=\left\{\frac{m}{n}:m,n\in\mathbb{Z},\ n\ne0\right\}\).

Remark 1.3.2. Two fractions \(\frac{m}{n}\) and \(\frac{p}{q}\) are equal if \(mq=np\). So \(\frac{1}{2}=\frac{2}{4}\). Every integer \(m\) is rational, since \(m=\frac{m}{1}\). So \(\mathbb{N}\subset\mathbb{N}_0\subset\mathbb{Z}\subset\mathbb{Q}\). The usual arithmetic and order of \(\mathbb{Q}\) are assumed for now. Section 1.5 lists the rules they satisfy.

Lemma 1.3.3. Let \(p\in\mathbb{Q}\) with \(p>0\). Then there exist \(m,n\in\mathbb{N}\) such that \(p=\frac{m}{n}\) and \(m\) and \(n\) are not both even.

Proof. Since \(p\in\mathbb{Q}\), \(p=\frac{a}{b}\) for some \(a,b\in\mathbb{Z}\) with \(b\ne0\). Since \(p>0\), \(a\) and \(b\) are both positive or both negative. If both are negative, then \(p=\frac{-a}{-b}\). So \(p=\frac{a}{b}\) with \(a,b\in\mathbb{N}\). Let \[S=\left\{n\in\mathbb{N}:p=\frac{m}{n}\text{ for some }m\in\mathbb{N}\right\}.\] Then \(b\in S\), so \(S\ne\emptyset\). By the Well-Ordering Principle, \(S\) has a smallest element \(n\). So \(p=\frac{m}{n}\) for some \(m\in\mathbb{N}\). Assume by way of contradiction that \(m\) and \(n\) are both even. Then \(m=2j\) and \(n=2k\) for some \(j,k\in\mathbb{N}\). So \(p=\frac{2j}{2k}=\frac{j}{k}\), and \(k\in S\). But \(k<n\), a contradiction to the fact that \(n\) is the smallest element of \(S\). So \(m\) and \(n\) are not both even.

∎

Theorem 1.3.4. There exists no \(p\in\mathbb{Q}\) with \(p^2=2\).

Proof. Assume by way of contradiction that there exists a \(p\in\mathbb{Q}\) such that \(p^2=2\). Since \((-p)^2=p^2\) and \(0^2\ne2\), assume \(p>0\). By Lemma 1.3.3, \(p=\frac{m}{n}\) with \(m,n\in\mathbb{N}\), where \(m\) and \(n\) are not both even. So \(p^2=\frac{m^2}{n^2}\). Since \(p^2=2\), \(2n^2=m^2\). Therefore, since \(n^2\in\mathbb{N}\), \(m^2\) is even. So by Theorem 1.2.15, \(m\) must be even. Thus, there exists a \(k\in\mathbb{N}\) such that \(m=2k\), implying \(4k^2=m^2\), or \(2n^2=4k^2\). Thus \(n^2=2k^2\) and \(n^2\) is even. So by Theorem 1.2.15, \(n\) is also even, a contradiction to the fact that \(m\) and \(n\) are not both even. So there exists no such \(p\).

∎

Proof Technique (Proving Existence by Construction). The statement “\(A\) has no largest element” means for every \(p\in A\), there exists a \(q\in A\) with \(q>p\). To prove a “there exists” statement, it is often best to build the object. The proof of Theorem 1.3.5 builds \(q_p\) from \(p\) with a formula. Finding the formula is scratch work. It is not part of the proof. The proof only has to check that \(q_p\) works.

Theorem 1.3.5. The set \(A=\{p\in\mathbb{Q}:p>0,\ p^2<2\}\) has no largest element and the set \(B=\{p\in\mathbb{Q}:p>0,\ p^2>2\}\) has no smallest element.

Proof. For each \(p\in\mathbb{Q}\), \(p>0\), define \[q_p=p-\frac{p^2-2}{p+2}=\frac{2p+2}{p+2}.\] Notice \(q_p\in\mathbb{Q}\) and \(q_p>0\). Then \[q_p^2-2=\frac{2(p^2-2)}{(p+2)^2}.\]

Let \(p\in A\). Then \(p^2-2<0\). So \(q_p>p\) and \(q_p^2<2\). So \(q_p\in A\).

Next, let \(p\in B\). Then \(p^2-2>0\). So \(q_p<p\) and \(q_p^2>2\). Thus \(q_p\in B\).

∎

Where does the formula for \(q_p\) come from? If \(p\in A\), the goal is a number a little bigger than \(p\) whose square is still less than \(2\). The step up should shrink as \(p^2\) gets close to \(2\). So it makes sense to step by a multiple of \(2-p^2\). Dividing by \(p+2\) keeps the step small enough that \(q_p^2\) stays below \(2\). The identity for \(q_p^2-2\) in the proof checks this. The same formula moves each element of \(B\) down.

So \(A\) and \(B\) split the positive rational numbers into two pieces, as in Figure 1.1. There is no largest number on the left and no smallest number on the right. Section 1.4 gives the language to say exactly what is missing.

1.4 Ordered Sets

To describe the hole in \(\mathbb{Q}\) precisely, the language of order is needed. This section works with any set that has an order, not just \(\mathbb{Q}\). Its main definition is the supremum, or least upper bound. It is the most important definition in this chapter.

Definition 1.4.1. Let \(S\) be a set. A relation \(<\) on \(S\) is an order on \(S\) if it has the following two properties.

  1. (Trichotomy) For all \(x,y\in S\), exactly one of \(x<y\), \(x=y\), \(y<x\) is true.

  2. (Transitivity) For all \(x,y,z\in S\), if \(x<y\) and \(y<z\), then \(x<z\).

Write \(y>x\) to mean \(x<y\). Write \(x\le y\) to mean \(x<y\) or \(x=y\), and \(y\ge x\) to mean \(x\le y\). A set together with an order is called an ordered set.

Example 1.4.2. \(\mathbb{Q}\) is an ordered set if for \(r,s\in \mathbb{Q}\), \(r<s\) is defined as \(s-r\) is a positive rational number.

Definition 1.4.3. Suppose \(S\) is an ordered set and \(E\subset S\). If there exists a \(\beta\in S\) such that \(x\le\beta\) for all \(x\in E\), \(E\) is said to be bounded above, and \(\beta\) is called an upper bound of \(E\).

If there exists an \(\alpha\in S\) such that \(x\ge \alpha\) for all \(x\in E\), \(E\) is said to be bounded below and \(\alpha\) is called a lower bound of \(E\).

Definition 1.4.4. Let \(S\) be an ordered set and \(E\subset S\). An element \(\beta\in S\) is the supremum, or least upper bound, of \(E\) if

  1. \(\beta\) is an upper bound of \(E\), and

  2. no element of \(S\) smaller than \(\beta\) is an upper bound of \(E\). That is, if \(\gamma<\beta\), then there exists an \(x\in E\) with \(x>\gamma\).

In this case, write \[\beta=\sup E=\operatorname{lub}E.\] Similarly, an element \(\alpha\in S\) is the infimum, or greatest lower bound, of \(E\) if

  1. \(\alpha\) is a lower bound of \(E\), and

  2. no element of \(S\) larger than \(\alpha\) is a lower bound of \(E\). That is, if \(\alpha<\gamma\), then there exists an \(x\in E\) with \(x<\gamma\).

In this case, write \[\alpha=\inf E=\operatorname{glb}E.\]

The supremum is the smallest upper bound. It does not have to be an element of \(E\). If \(E\) has a largest element, then that element is \(\sup E\). So the supremum takes the place of a largest element when there is none. Example 1.4.6 gives a set whose infimum is not in the set.

Theorem 1.4.5. Suppose \(S\) is an ordered set. If \(E\subset S\), \(E\ne\emptyset\), has a supremum, it is unique. Similarly, if \(E\) has an infimum, it is unique.

Proof. Let both \(\beta_1,\beta_2\in S\) be a supremum of the set \(E\). Since \(S\) is an ordered set, \(\beta_1<\beta_2\), \(\beta_1>\beta_2\), or \(\beta_1=\beta_2\). If \(\beta_1<\beta_2\), then by the definition of \(\beta_2\), \(\beta_1\) is not an upper bound of \(E\), contradicting the fact that \(\beta_1\) is a supremum of \(E\). So \(\beta_1\geq \beta_2\). If \(\beta_2<\beta_1\), then by the definition of \(\beta_1\), \(\beta_2\) is not an upper bound of \(E\), contradicting the fact that \(\beta_2\) is a supremum of \(E\). So \(\beta_1=\beta_2\).

Let both \(\alpha_1,\alpha_2\in S\) be an infimum of the set \(E\). Since \(S\) is an ordered set, \(\alpha_1<\alpha_2\), \(\alpha_1>\alpha_2\), or \(\alpha_1=\alpha_2\). If \(\alpha_1<\alpha_2\), then by the definition of \(\alpha_1\), \(\alpha_2\) is not a lower bound of \(E\), contradicting the fact that \(\alpha_2\) is an infimum of \(E\). So \(\alpha_1\geq \alpha_2\). If \(\alpha_2<\alpha_1\), then by the definition of \(\alpha_2\), \(\alpha_1\) is not a lower bound of \(E\), contradicting the fact that \(\alpha_1\) is an infimum of \(E\). So \(\alpha_1=\alpha_2\).

∎

Example 1.4.6. Let \(E=\{1/n:n\in\mathbb{N}\}\subset\mathbb{Q}\). Then \(\sup E=1\in E\) and \(\inf E=0\notin E\). To see this, first notice \(\frac{1}{n}\le1\) for all \(n\in\mathbb{N}\). So \(1\) is an upper bound of \(E\). If \(\gamma<1\), then \(\gamma\) is not an upper bound of \(E\), since \(1\in E\). So \(\sup E=1\).

Next, \(\frac{1}{n}>0\) for all \(n\in\mathbb{N}\). So \(0\) is a lower bound of \(E\). Let \(\gamma\in\mathbb{Q}\) with \(\gamma>0\). Then \(\gamma=\frac{a}{b}\) for some \(a,b\in\mathbb{N}\). So \(\frac{1}{b+1}<\frac{1}{b}\le\frac{a}{b}=\gamma\), and \(\gamma\) is not a lower bound of \(E\). So \(\inf E=0\).

Example 1.4.7. Let \(A\) and \(B\) be the sets in Theorem 1.3.5. Every element of \(B\) is an upper bound of \(A\). To see this, let \(q\in B\) and \(p\in A\). If \(q\le p\), then \(q^2\le p^2<2<q^2\), which is impossible. So \(p<q\). In particular, \(2\), \(5\), and \(3/2\) are upper bounds of \(A\).

However, \(\sup A\) does not exist in \(\mathbb{Q}\). Assume by way of contradiction that \(s=\sup A\in\mathbb{Q}\). Since \(1\in A\), \(s\ge1>0\). By Theorem 1.3.4, \(s^2\ne2\). If \(s^2<2\), then \(s\in A\). By Theorem 1.3.5, there exists a \(q\in A\) with \(q>s\). This contradicts the fact that \(s\) is an upper bound of \(A\). If \(s^2>2\), then \(s\in B\). By Theorem 1.3.5, there exists a \(q\in B\) with \(q<s\). But \(q\) is an upper bound of \(A\). This contradicts the fact that \(s\) is the least upper bound of \(A\). So \(\sup A\) does not exist in \(\mathbb{Q}\).

Definition 1.4.8. An ordered set \(S\) is said to have the least upper bound property if for all \(E\subset S\) with \(E\ne\emptyset\), \(E\) bounded above, \(\sup E\in S\).

Example 1.4.9. By Example 1.4.7, \(\mathbb{Q}\) does not have the least upper bound property.

This is the precise form of the hole in \(\mathbb{Q}\). The set \(A\) is nonempty and bounded above in \(\mathbb{Q}\), but nothing in \(\mathbb{Q}\) is its least upper bound. The real numbers are built to fix exactly this problem.

Theorem 1.4.10. Suppose \(S\) is an ordered set with the least upper bound property, \(E\subset S\), \(E\ne\emptyset\) and \(E\) is bounded below. Then \(\inf E\) exists in \(S\).

Proof. Let \(L\) be the set of all lower bounds of \(E\). That is, \[L=\{y\in S:y\le x\text{ for all }x\in E\}.\] Since \(E\) is bounded below, \(L\ne\emptyset\). By the definition of \(L\), every element of \(E\) is an upper bound of \(L\). Since \(E\ne\emptyset\), \(L\) is bounded above. By the least upper bound property, \(\alpha=\sup L\) exists in \(S\). The claim is that \(\alpha=\inf E\).

First, \(\alpha\) is a lower bound of \(E\). Let \(x\in E\). Then \(x\) is an upper bound of \(L\). If \(x<\alpha\), then \(x\) would not be an upper bound of \(L\), by the definition of \(\alpha\). So \(\alpha\le x\).

Second, let \(\gamma\in S\) with \(\alpha<\gamma\). Since \(\alpha\) is an upper bound of \(L\), \(\gamma\notin L\). So \(\gamma\) is not a lower bound of \(E\). Therefore \(\alpha=\inf E\).

∎

1.5 Fields and Ordered Fields

The rational numbers and the real numbers follow the same rules of arithmetic. This section lists those rules as axioms. A set with an addition and a multiplication that satisfy them is called a field. Anything proved from the axioms is then true in \(\mathbb{Q}\), in \(\mathbb{R}\), and in every other field. That is the advantage of working from axioms. One proof covers many number systems.

Definition 1.5.1. A field is a set \(\mathbb{F}\) with two operations \(+\) and \(\cdot\) which satisfy the following axioms.

  1. If \(x\in \mathbb{F}\) and \(y\in \mathbb{F}\), then \(x+y\in \mathbb{F}\).

  2. \(x+y=y+x\) for all \(x,y\in \mathbb{F}\).

  3. \((x+y)+z=x+(y+z)\) for all \(x,y,z\in \mathbb{F}\).

  4. There exists a \(0\in\mathbb{F}\) such that \(0+x=x\) for all \(x\in\mathbb{F}\).

  5. For all \(x\in\mathbb{F}\), there exists a \(-x\in\mathbb{F}\) such that \(x+(-x)=0\).

  6. If \(x\in \mathbb{F}\) and \(y\in \mathbb{F}\), then \(x\cdot y\in \mathbb{F}\).

  7. \(x\cdot y=y\cdot x\) for all \(x,y\in \mathbb{F}\).

  8. \((x\cdot y)\cdot z=x\cdot(y\cdot z)\) for all \(x,y,z\in \mathbb{F}\).

  9. There exists a \(1\in\mathbb{F}\) with \(1\ne 0\) such that \(1\cdot x=x\) for all \(x\in\mathbb{F}\).

  10. For all \(x\in\mathbb{F}\setminus\{0\}\), there exists an \(x^{-1}\in\mathbb{F}\) such that \(x\cdot x^{-1}=1\).

  11. \(x\cdot(y+z)=x\cdot y+x\cdot z\) for all \(x,y,z\in\mathbb{F}\).

Remark 1.5.2. In a field, \(x-y\) means \(x+(-y)\). If \(y\ne0\), \(\frac{x}{y}\) means \(x\cdot y^{-1}\). Also \(xy\) means \(x\cdot y\), and powers \(x^n\) are defined as in Definition 1.2.10. The elements \(1+1\), \(1+1+1\), and so on are written \(2\), \(3\), and so on.

Example 1.5.3. \(\mathbb{Q}\) with \(+\) and \(\cdot\) defined as addition and multiplication is a field.

Example 1.5.4. \(\mathbb{Z}\) is not a field. The integer \(2\) has no multiplicative inverse in \(\mathbb{Z}\). If \(2n=1\) for some \(n\in\mathbb{Z}\), then \(1\) is even, which contradicts Corollary 1.2.13.

Definition 1.5.6. An ordered field is a field \(\mathbb{F}\) which is also an ordered set with the following properties.

  1. If \(x,y\in\mathbb{F}\) with \(x\le y\), then \(x+z\le y+z\) for all \(z\in\mathbb{F}\).

  2. If \(x,y\in\mathbb{F}\) with \(0\le x\) and \(0\le y\), then \(0\le x\cdot y\).

If \(x>0\), \(x\) is positive. If \(x<0\), \(x\) is negative.

Example 1.5.7. \(\mathbb{Q}\), with the usual operations and order, is an ordered field.

1.6 The Absolute Value Function

Distance on the number line is measured with absolute values. The distance between \(x\) and \(y\) is \(|x-y|\). Most estimates in analysis are statements about distances, so the facts in this section are used on almost every page of the rest of the book.

Definition 1.6.1. If \(\mathbb{F}\) is an ordered field and \(x\in\mathbb{F}\), the absolute value of \(x\), denoted \(|x|\), is defined by \[|x|=\begin{cases} -x, & x<0, \\ x, & x\ge 0.\end{cases}\]

Theorem 1.6.2. Let \(\mathbb{F}\) be an ordered field and \(x,b\in\mathbb{F}\).

  1. \(|x|\ge0\), and \(|x|=0\) if and only if \(x=0\).

  2. \(|-x|=|x|\).

  3. \(-|x|\le x\le|x|\).

  4. If \(b\ge0\), then \(|x|\le b\) if and only if \(-b\le x\le b\).

  5. If \(b>0\), then \(|x|<b\) if and only if \(-b<x<b\).

Proof.

  1. If \(x>0\), then \(|x|=x>0\). If \(x<0\), then \(|x|=-x>0\) by Theorem 1.5.8 (1). If \(x=0\), then \(|x|=0\). So \(|x|\ge0\), and \(|x|=0\) if and only if \(x=0\).

  2. Exercise.

  3. If \(x\ge0\), then \(-|x|=-x\le0\le x=|x|\). If \(x<0\), then \(-|x|=x<0<-x=|x|\).

  4. (\(\Rightarrow\)) Suppose \(|x|\le b\). By (3), \(x\le|x|\le b\). Also, by (2) and (3), \(-x\le|-x|=|x|\le b\). So by Theorem 1.5.8 (2), \(-b\le x\). Thus \(-b\le x\le b\).

1.7 The Completeness of the Real Numbers

The rational numbers are an ordered field without the least upper bound property. The real numbers are an ordered field with it. That one property is what makes analysis work. This section introduces \(\mathbb{R}\) and proves the first consequences of the least upper bound property. There are no infinitely large real numbers, there is a rational number between any two real numbers, and positive real numbers have \(n\)th roots.

Definition 1.7.1. If \(\mathbb{F}\) is an ordered field with operations \(+\) and \(\cdot\) and order \(<\), \(\mathbb{H}\) is a subfield of \(\mathbb{F}\) if \(\mathbb{H}\subset\mathbb{F}\) and \(\mathbb{H}\) is an ordered field with operations \(+\) and \(\cdot\) and order \(<\).

Theorem 1.7.2. There is an ordered field \(\mathbb{R}\) with the least upper bound property such that \(\mathbb{Q}\), with its usual operations and order, is a subfield of \(\mathbb{R}\).

Proof. See Appendix A. A second proof is in Appendix B.

∎

Remark 1.7.3. The proof of Theorem 1.7.2 builds \(\mathbb{R}\) out of \(\mathbb{Q}\). Appendix A gives a construction using cuts, and Appendix B gives a second one using Cauchy sequences. Everything in Sections 1.4, 1.5 and 1.6 applies to \(\mathbb{R}\), since \(\mathbb{R}\) is an ordered field. The least upper bound property of \(\mathbb{R}\) is also called completeness. It is the one property that separates \(\mathbb{R}\) from \(\mathbb{Q}\). Every theorem in this book that says something exists, such as a limit, a maximum value or a root, depends on it.

Definition 1.7.4. The elements of the field \(\mathbb{R}\) are called real numbers. The elements of \(\mathbb{R}\setminus\mathbb{Q}\) are called irrational numbers.

Definition 1.7.5. Let \(J\subset \mathbb{R}\), \(J\ne\emptyset\). If for all \(x,y\in J\) with \(x\le y\) and for all \(z\in\mathbb{R}\) such that \(x\le z\le y\), \(z\in J\), \(J\) is called an interval.

Definition 1.7.6. Let \(a,b\in\mathbb{R}\) with \(a\le b\). Define \[\begin{aligned} &=\{x\in\mathbb{R}:a\le x\le b\}, & (a,b)&=\{x\in\mathbb{R}:a<x<b\},\\ [a,b)&=\{x\in\mathbb{R}:a\le x<b\}, & (a,b]&=\{x\in\mathbb{R}:a<x\le b\},\\ [a,\infty)&=\{x\in\mathbb{R}:x\ge a\}, & (a,\infty)&=\{x\in\mathbb{R}:x>a\},\\ (-\infty,b]&=\{x\in\mathbb{R}:x\le b\}, & (-\infty,b)&=\{x\in\mathbb{R}:x<b\}, \end{aligned}\] and \((-\infty,\infty)=\mathbb{R}\). The interval \([a,b]\) is called a closed interval. If \(a<b\), \((a,b)\) is called an open interval. The symbols \(\infty\) and \(-\infty\) are not real numbers.

Proof Technique (Working with Suprema). Two facts about \(\beta=\sup E\) are used again and again. First, \(\beta\) is an upper bound of \(E\). So \(x\le\beta\) for all \(x\in E\). Second, nothing smaller than \(\beta\) is an upper bound of \(E\). So for every \(\varepsilon>0\), some element of \(E\) is bigger than \(\beta-\varepsilon\). This second fact is Theorem 1.7.7. To prove a number is \(\sup E\), prove both facts.

Theorem 1.7.7.

Let \(E\subset\mathbb{R}\) be nonempty and bounded above, and let \(\beta=\sup E\). Then for all \(\varepsilon>0\), there exists an \(x\in E\) such that \(\beta-\varepsilon<x\le\beta\). Similarly, if \(E\) is nonempty and bounded below and \(\alpha=\inf E\), then for all \(\varepsilon>0\), there exists an \(x\in E\) such that \(\alpha\le x<\alpha+\varepsilon\).

Proof. Let \(\varepsilon>0\). Then \(\beta-\varepsilon<\beta\). So \(\beta-\varepsilon\) is not an upper bound of \(E\). Thus there exists an \(x\in E\) with \(x>\beta-\varepsilon\). Since \(\beta\) is an upper bound of \(E\), \(x\le\beta\). The proof for \(\inf E\) is an exercise.

∎

The next theorem says \(\mathbb{R}\) has no infinitely large numbers. However small \(x>0\) is and however large \(y\) is, adding \(x\) to itself enough times gets past \(y\). Taking \(x=1\), the natural numbers are not bounded above in \(\mathbb{R}\). Taking \(y=1\), for every \(\varepsilon>0\) there is an \(N\in\mathbb{N}\) with \(\frac{1}{N}<\varepsilon\). That last form is used constantly in later chapters.

Theorem 1.7.8 (Archimedean Principle).

If \(x,y\in\mathbb{R}\) and \(x>0\), then there exists an \(n\in\mathbb{N}\) such that \(nx>y\). Hence, for all \(x\in\mathbb{R}\), there exists an \(n\in\mathbb{N}\) such that \(x<n\).

Proof. Let \(x,y\in\mathbb{R}\) with \(x>0\). Assume by way of contradiction that \(nx\le y\) for every \(n\in\mathbb{N}\). Then the set \(A=\{nx:n\in\mathbb{N}\}\) is nonempty and bounded above by \(y\). By the least upper bound property, \(\alpha=\sup A\) exists. Since \(x>0\), \(\alpha-x<\alpha\). By Theorem 1.7.7 with \(\varepsilon=x\), there is an element of \(A\) larger than \(\alpha-x\). That is, \(mx>\alpha-x\) for some \(m\in\mathbb{N}\). Then \((m+1)x>\alpha\). But \((m+1)x\in A\), so this contradicts the fact that \(\alpha\) is an upper bound of \(A\). So \(nx>y\) for some \(n\in\mathbb{N}\).

Taking \(x=1\) and \(y\) any real number gives the second statement.

∎

Theorem 1.7.9. For all \(x\in\mathbb{R}\), there exists a unique \(n\in\mathbb{Z}\) such that \(n-1\le x<n\).

Proof. First, existence. By the Archimedean Principle, there exist \(m_1,m_2\in\mathbb{N}\) such that \(m_1>x\) and \(m_2>-x\). Let \[S=\{k\in\mathbb{N}:k-m_2>x\}.\] Since \(m_1+m_2-m_2=m_1>x\), \(m_1+m_2\in S\). So \(S\ne\emptyset\). By the Well-Ordering Principle, \(S\) has a smallest element \(j\). Let \(n=j-m_2\). Then \(n\in\mathbb{Z}\) and \(n>x\). If \(j=1\), then \(n-1=-m_2<x\). If \(j>1\), then \(j-1\in\mathbb{N}\) and \(j-1\notin S\), since \(j\) is the smallest element of \(S\). So \(n-1=(j-1)-m_2\le x\). In either case, \(n-1\le x<n\).

Next, uniqueness. Suppose \(n,n'\in\mathbb{Z}\) with \(n-1\le x<n\) and \(n'-1\le x<n'\). Then \(n'>x\ge n-1\). So \(n'>n-1\), and since \(n'\) and \(n\) are integers, \(n'\ge n\). Similarly, \(n\ge n'\). So \(n=n'\).

∎

Definition 1.7.10. For \(x\in\mathbb{R}\), the greatest integer less than or equal to \(x\) is denoted \(\left\lfloor x\right\rfloor\). By Theorem 1.7.9, \(\left\lfloor x\right\rfloor\) is the unique integer with \(\left\lfloor x\right\rfloor\le x<\left\lfloor x\right\rfloor+1\).

Theorem 1.7.11 (Density of the Rational Numbers).

For all \(x,y\in\mathbb{R}\) with \(x<y\), there exists a \(q\in\mathbb{Q}\) such that \(x<q<y\).

Proof. Since \(x<y\), \(y-x>0\), and so by the Archimedean Principle (Theorem 1.7.8), there exists an \(n\in\mathbb{N}\) such that \(n(y-x)>1\). By Theorem 1.7.9, there exists an \(m\in\mathbb{Z}\) such that \[m-1\le nx< m.\] Combining inequalities gives \[nx<m\le 1+nx<ny.\] Since \(n>0\), \[x<\frac{m}{n}<y.\] Since \(m\in\mathbb{Z}\), \(n\in\mathbb{N}\), \(\frac{m}{n}\in\mathbb{Q}\).

∎

So every open interval, however short, contains a rational number. The rational numbers are spread throughout \(\mathbb{R}\). Even so, they have holes and \(\mathbb{R}\) does not. By Exercise 1.7.5, the irrational numbers are spread throughout \(\mathbb{R}\) as well.

Lemma 1.7.12. Let \(n\in\mathbb{N}\) and \(0<a<b\). Then \(b^n-a^n\le nb^{n-1}(b-a)\).

Proof. By Exercise 1.2.8, \[b^n-a^n=(b-a)\sum_{i=0}^{n-1}b^{n-1-i}a^i.\] By Exercise 1.5.4, \(a^i\le b^i\) for each \(i\). So each term of the sum satisfies \(b^{n-1-i}a^i\le b^{n-1-i}b^i=b^{n-1}\). There are \(n\) terms. So the sum is at most \(nb^{n-1}\). Since \(b-a>0\), \(b^n-a^n\le nb^{n-1}(b-a)\).

∎

The next theorem shows \(\mathbb{R}\) has no hole at \(\sqrt2\), or at any other \(n\)th root. The idea is the one Section 1.3 suggests. Let \(E\) be the set of positive \(t\) with \(t^n<x\), and let \(y=\sup E\). If \(y^n<x\), a number slightly bigger than \(y\) is still in \(E\). If \(y^n>x\), a number slightly smaller than \(y\) is still an upper bound of \(E\). Both are impossible. Lemma 1.7.12 controls how much \(t^n\) changes when \(t\) changes a little.

Theorem 1.7.13.

For every real \(x>0\) and every integer \(n>0\), there is a unique positive real number \(y\) with \(y^n=x\). This number is denoted \(\sqrt[n]{x}\). If \(n=2\), it is denoted \(\sqrt{x}\).

Proof. First, existence. Let \(E=\{t\in\mathbb{R}:t>0,\ t^n<x\}\). Let \(t_0=\frac12\min\{1,x\}\). Then \(0<t_0<1\), so \(t_0^n\le t_0<x\) by Exercise 1.5.5. So \(t_0\in E\) and \(E\ne\emptyset\). Let \(M=\max\{1,x\}\). If \(t>M\), then \(t>1\) and \(t>x\). So \(t^n\ge t>x\) by Exercise 1.5.5, and \(t\notin E\). So \(M\) is an upper bound of \(E\). By the least upper bound property, \(y=\sup E\) exists. Since \(t_0\in E\), \(y\ge t_0>0\).

Assume by way of contradiction that \(y^n<x\). Choose \(h\) with \(0<h<1\) and \(hn(y+1)^{n-1}<x-y^n\). For example, \(h=\min\left\{\frac12,\frac{x-y^n}{2n(y+1)^{n-1}}\right\}\) works. By Lemma 1.7.12 with \(a=y\) and \(b=y+h\), \[(y+h)^n-y^n\le n(y+h)^{n-1}h\le n(y+1)^{n-1}h<x-y^n.\] So \((y+h)^n<x\), and \(y+h\in E\). Since \(y+h>y\), this contradicts the fact that \(y\) is an upper bound of \(E\). So \(y^n\ge x\).

Assume by way of contradiction that \(y^n>x\). Let \[k=\frac{y^n-x}{ny^{n-1}}.\] Then \(k>0\). Also \(k<y\), since \(y^n-x<y^n\le ny^n\). By Lemma 1.7.12 with \(a=y-k\) and \(b=y\), \[y^n-(y-k)^n\le ny^{n-1}k=y^n-x.\] So \((y-k)^n\ge x\). Now let \(t\in E\). If \(t\ge y-k\), then \(t^n\ge(y-k)^n\ge x\) by Exercise 1.5.4, which is false since \(t\in E\). So \(t<y-k\). Thus \(y-k\) is an upper bound of \(E\). But \(y-k<y\), which contradicts \(y=\sup E\). So \(y^n\le x\). Therefore \(y^n=x\).

Next, uniqueness. If \(0<y_1<y_2\), then \(y_1^n<y_2^n\) by Exercise 1.5.4. So two different positive numbers cannot both have \(n\)th power equal to \(x\).

∎
