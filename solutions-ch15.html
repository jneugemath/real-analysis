Solutions for Chapter 15. Measurable Functions

Exercise 15.1.1. We prove a little more. For any measurable sets \(A\) and \(B\), \(\chi_{A\cup B}=\chi_A+\chi_B-\chi_{A\cap B}\) and \(\chi_{A\cap B}=\chi_A\cdot\chi_B\). Check the four cases for a point \(x\).

Let \(x\notin A\), \(x\notin B\). Then \(\chi_{A\cup B}(x) = 0 = 0 + 0 - 0=\chi_A(x) + \chi_B(x) - \chi_{A\cap B}(x)\) and \(\chi_{A\cap B}(x)= 0 = 0\cdot0=\chi_A(x)\cdot\chi_B(x)\).

Let \(x\in A\), \(x\notin B\). Then \(\chi_{A\cup B}(x) = 1 = 1 + 0 - 0=\chi_A(x) + \chi_B(x) - \chi_{A\cap B}(x)\) and \(\chi_{A\cap B}(x)= 0 = 1\cdot0=\chi_A(x)\cdot\chi_B(x)\).

Let \(x\notin A\), \(x\in B\). Then \(\chi_{A\cup B}(x) = 1 = 0 + 1 - 0=\chi_A(x) + \chi_B(x) - \chi_{A\cap B}(x)\) and \(\chi_{A\cap B}(x)= 0 = 0\cdot1=\chi_A(x)\cdot\chi_B(x)\).

Let \(x\in A\), \(x\in B\). Then \(\chi_{A\cup B}(x) = 1 = 1 + 1 - 1=\chi_A(x) + \chi_B(x) - \chi_{A\cap B}(x)\) and \(\chi_{A\cap B}(x)= 1 = 1\cdot1=\chi_A(x)\cdot\chi_B(x)\).

If \(A\) and \(B\) are disjoint, then \(A\cap B=\emptyset\), so \(\chi_{A\cap B}=0\) and \(\chi_{A\cup B}=\chi_A+\chi_B\).

Exercise 15.1.3. Define \(\mathcal{S}=\{A\subset \mathbb{R}: f^{-1}[A]\in \mathcal{M}\}\). First, \(\mathbb{R}\in\mathcal{S}\), since \(f^{-1}[\mathbb{R}]=E\in\mathcal{M}\). Let \(A\in \mathcal{S}\). Then \(f^{-1}[A]\in\mathcal{M}\). Since \(\mathcal{M}\) is a \(\sigma\)-algebra, \(E\setminus f^{-1}[A]=E\cap(f^{-1}[A])^c\in\mathcal{M}\) as well. Let \(x\in f^{-1}[A^c]\). Then \(f(x)\in A^c\). So \(f(x)\notin A\) and \(x\in E\setminus f^{-1}[A]\). Thus \(f^{-1}[A^c]\subset E\setminus f^{-1}[A]\). Now let \(x\in E\setminus f^{-1}[A]\). So \(f(x)\notin A\), and \(f(x)\in A^c\). Thus \(x\in f^{-1}[A^c]\) and \(E\setminus f^{-1}[A]\subset f^{-1}[A^c]\). So \(f^{-1}[A^c]=E\setminus f^{-1}[A]\in\mathcal{M}\) and \(A^c\in \mathcal{S}\).

Now let \(\{A_n\}\subset \mathcal{S}\). So for each \(n\in\mathbb{N}\), \(f^{-1}[A_n]\in\mathcal{M}\), and since \(\mathcal{M}\) is a \(\sigma\)-algebra, \(\bigcup_{n\in\mathbb{N}}f^{-1}[A_n]\in\mathcal{M}\). Let \(x\in f^{-1}\left[\bigcup_{n\in\mathbb{N}} A_n\right]\). Then \(f(x)\in \bigcup_{n\in\mathbb{N}} A_n\). So there exists an \(n_0\in \mathbb{N}\) such that \(f(x)\in A_{n_0}\). So \(x\in f^{-1}[A_{n_0}]\subset \bigcup_{n\in\mathbb{N}}f^{-1}[A_n]\) and \(f^{-1}\left[\bigcup_{n\in\mathbb{N}} A_n\right]\subset \bigcup_{n\in\mathbb{N}}f^{-1}[A_n]\). Now let \(x\in\bigcup_{n\in\mathbb{N}}f^{-1}[A_n]\). So there exists an \(n_0\in \mathbb{N}\) such that \(x\in f^{-1}[A_{n_0}]\), implying \(f(x)\in A_{n_0}\subset \bigcup_{n\in\mathbb{N}} A_n\). So \(x\in f^{-1}\left[\bigcup_{n\in\mathbb{N}} A_n\right]\), and \(\bigcup_{n\in\mathbb{N}}f^{-1}[A_n]\subset f^{-1}\left[\bigcup_{n\in\mathbb{N}} A_n\right]\). Thus \[f^{-1}\left[\bigcup_{n\in\mathbb{N}} A_n\right]= \bigcup_{n\in\mathbb{N}}f^{-1}[A_n]\in\mathcal{M}.\] So \(\bigcup_{n\in\mathbb{N}} A_n\in \mathcal{S}\) and \(\mathcal{S}\) is a \(\sigma\)-algebra.

It remains to show that \(\mathcal{S}\) contains the open sets. Let \(\alpha,\beta\in\mathbb{R}\). Since \(f\) is measurable, \(f^{-1}[(\alpha,\infty)]=\{x:f(x)>\alpha\}\) and \(f^{-1}[(-\infty,\beta)]=\{x:f(x)<\beta\}\) are measurable, by Theorem 15.1.1. So \((\alpha,\infty)\) and \((-\infty,\beta)\) are in \(\mathcal{S}\). Since \(\mathcal{S}\) is a \(\sigma\)-algebra, \((\alpha,\beta)=(\alpha,\infty)\cap(-\infty,\beta)\in\mathcal{S}\) by Proposition 13.1.2. Also \(\mathbb{R}\in\mathcal{S}\). So every open interval, bounded or not, is in \(\mathcal{S}\). By Theorem 4.1.12, every nonempty open set is a countable union of open intervals, so it is in \(\mathcal{S}\). Also \(\emptyset=\mathbb{R}^c\in\mathcal{S}\).

Finally, \(\mathcal{B}_\mathbb{R}\) is the smallest \(\sigma\)-algebra containing the open sets, and \(\mathcal{S}\) is a \(\sigma\)-algebra containing the open sets. So \(\mathcal{B}_\mathbb{R}\subset\mathcal{S}\). That is, \(f^{-1}[B]\in\mathcal{M}\) for every Borel set \(B\).

Exercise 15.2.2. Hint. Cut \([-M,M]\) into intervals of length less than \(\varepsilon\), and let \(\varphi\) be constant on the set where \(f\) lies in each one.

Solution.Let \(\varepsilon>0\), \(M>0\). Choose \(N\in\mathbb{N}\) such that \(N>\frac{M}{\varepsilon}\). Define \(A_i=\left\{x:\frac{(i+1)M}{N}> f(x)\geq\frac{iM}{N}\right\}\) for \(-N\leq i\leq N-1\). Each \(A_i\) is measurable since \(f\) is. Note \(\frac{(i+1)M-iM}{N}=\frac{M}{N}<\varepsilon\). Define \(\varphi(x)=\sum_{i=-N}^{N-1}\frac{iM}{N}\chi_{A_i}\). So \(\varphi\) is a simple function. If \(x\in[a,b]\) and \(|f(x)|<M\), then there exists an \(A_i\) such that \(x\in A_i\). So \(|f(x)-\varphi(x)|<\left|\frac{(i+1)M}{N}-\frac{iM}{N}\right|<\varepsilon\). Indeed, \(0\le f(x)-\frac{iM}{N}<\frac MN\).

Now suppose \(\alpha\le f\le\beta\). Let \(\psi=\min\{\max\{\varphi,\alpha\},\beta\}\). That is, \(\psi(x)=\alpha\) where \(\varphi(x)<\alpha\), \(\psi(x)=\beta\) where \(\varphi(x)>\beta\), and \(\psi(x)=\varphi(x)\) otherwise. Then \(\psi\) takes finitely many values, each on a measurable set. So \(\psi\) is simple, and \(\alpha\le\psi\le\beta\). Moving \(\varphi(x)\) toward the interval \([\alpha,\beta]\), which contains \(f(x)\), cannot increase its distance from \(f(x)\). So \(|f(x)-\psi(x)|\le|f(x)-\varphi(x)|<\varepsilon\) whenever \(|f(x)|<M\).

Exercise 15.2.5. Let \(\varepsilon>0\). Since \(f\) takes on the values of \(\pm\infty\) only on a set of measure zero, by Lemma 15.2.3 there exists an \(M>0\) such that \(m(\{x:|f(x)|>M\})<\frac\varepsilon 3\). Define \(A=\{x:|f(x)|\le M\}\). Now there exists a simple function \(\varphi\) such that \(|f(x)-\varphi(x)|<\varepsilon\) for all \(x\in A\) by Lemma 15.2.4, applied with \(M+1\) in place of \(M\). Since \(\varphi\) is simple, there exists a step function \(g\) such that \(m(\{x:g(x)\neq \varphi(x)\})<\frac\varepsilon 3\) by Lemma 15.2.5. But if \(x\in A\) with \(g(x){}={}\varphi(x)\), then \(|f(x)-g(x)|<\varepsilon\). Thus \[\{x:|f(x)-g(x)|\geq\varepsilon\}\subset \{x:g(x)\ne\varphi(x)\}\cup \{x:|f(x)|>M\},\] implying \[m(\{x:|f(x)-g(x)|\geq\varepsilon\})\le m(\{x:g(x)\ne\varphi(x)\})+ m(\{x:|f(x)|>M\})<\frac\varepsilon 3+\frac\varepsilon 3<\varepsilon.\] Also, there exists a continuous function \(h\) such that \(m(\{x:g(x)\neq h(x)\})<\frac\varepsilon 3\) by Lemma 15.2.6. But if \(x\in A\) with \(h(x)=g(x)=\varphi(x)\), then \(|f(x)-h(x)|<\varepsilon\). So \[\{x:|f(x)-h(x)|\geq\varepsilon\}\subset \{x:h(x)\ne g(x)\}\cup\{x:g(x)\ne\varphi(x)\}\cup\{x:|f(x)|>M\},\] implying \(m(\{x:|f(x)-h(x)|\geq\varepsilon\})<\frac\varepsilon 3+\frac\varepsilon 3+\frac\varepsilon 3=\varepsilon\).

If \(\alpha\leq f\leq \beta\), \(\varphi\) can be chosen so that \(\alpha\leq \varphi\leq \beta\). Since \(\alpha\leq \varphi\leq \beta\), \(g\) can be chosen so that \(\alpha\leq g\leq \beta\). Since \(\alpha\leq g\leq \beta\), \(h\) can be chosen so that \(\alpha\leq h\leq \beta\).

Exercise 15.3.1. Hint. Remove a short interval \((1-\delta,1]\). On \([0,1-\delta]\), \(x^n\le(1-\delta)^n\).

Solution. For \(0\le x<1\), \(x^n\to0\) by Example 3.1.7, and \(1^n=1\). So the pointwise limit is \(f(x)=0\) for \(x\in[0,1)\) and \(f(1)=1\).

Let \(\eta>0\), let \(\delta=\min\left\{\frac\eta2,\frac12\right\}\), and let \(A=(1-\delta,1]\). Then \(m(A)=\delta<\eta\), and \([0,1]\setminus A=[0,1-\delta]\). For \(x\in[0,1-\delta]\), \(f(x)=0\) and \[|f_n(x)-f(x)|=x^n\le(1-\delta)^n.\] So \(\sup_{x\in[0,1-\delta]}|f_n(x)-f(x)|\le(1-\delta)^n\to0\), since \(0<1-\delta<1\). By Theorem 11.2.7, \(f_n\to f\) uniformly on \([0,1]\setminus A\).

Exercise 15.4.1. Hint. Try \(f=\chi_{[0,1/2]}\) on \([0,1]\).

Solution. Let \(f=\chi_{[0,1/2]}\) on \([0,1]\). It is measurable by Lemma 15.1.11. Suppose \(\varphi\) is continuous on \([0,1]\) and \(Z=\{x:f(x)\ne\varphi(x)\}\) has \(m(Z)=0\). Then \(Z\) contains no interval of positive length, since such an interval has positive measure and \(m^*\) is monotone.

For \(n\ge2\), the interval \(\left(\frac12-\frac1n,\frac12\right)\) is not contained in \(Z\). So it contains a point \(s_n\) with \(\varphi(s_n)=f(s_n)=1\). In the same way, \(\left(\frac12,\frac12+\frac1n\right)\) contains a point \(t_n\) with \(\varphi(t_n)=f(t_n)=0\). Both \(s_n\to\frac12\) and \(t_n\to\frac12\). Since \(\varphi\) is continuous, Theorem 6.3.9 gives \[\varphi\left(\tfrac12\right)=\lim_{n\to\infty}\varphi(s_n)=1\quad\text{and}\quad\varphi\left(\tfrac12\right)=\lim_{n\to\infty}\varphi(t_n)=0.\] This is impossible. So no continuous \(\varphi\) equals \(f\) almost everywhere, and \(m(\{f\ne\varphi\})<\delta\) cannot be improved to \(m(\{f\ne\varphi\})=0\).

Exercise 15.4.2. Hint. Replace \(\varphi\) by \(\max\{-M,\min\{\varphi,M\}\}\). It is still continuous, and it equals \(f\) wherever \(\varphi\) does.
