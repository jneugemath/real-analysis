Solutions for Chapter 18. \(L^p\) Spaces

Exercise 18.1.1. Let \(f\in L^r(E)\), and let \(s=\frac rp>1\), with conjugate exponent \(s'\). Then \(|f|^p\in L^s(E)\), since \((|f|^p)^s=|f|^r\), and \(1\in L^{s'}(E)\), since \(m(E)<\infty\). By Theorem 18.1.3, \[\int_E|f|^p\cdot1\le\left(\int_E|f|^r\right)^{p/r}m(E)^{1/s'}=\left\lVert f\right\rVert_r^p\,m(E)^{1-p/r}.\] So \(f\in L^p(E)\), and taking \(p\)th roots gives \(\left\lVert f\right\rVert_p\le m(E)^{1/p-1/r}\left\lVert f\right\rVert_r\). If \(f\in L^\infty(E)\), then \(|f|^p\le\left\lVert f\right\rVert_\infty^p\) almost everywhere by Exercise 18.1.4, so \(\int_E|f|^p\le\left\lVert f\right\rVert_\infty^pm(E)<\infty\).

Exercise 18.1.2. Let \(f(x)=x^{-1/2}\) for \(0<x<1\) and \(f(x)=0\) for \(x\ge1\). For \(0<\delta<1\), \(\int_\delta^1x^{-1/2}\,dx=2-2\sqrt\delta\). By Theorem 16.4.7 applied to \(f\chi_{[1/n,1)}\), \(\int_Ef=2\), so \(f\in L^1(E)\). But \(f^2=\frac1x\) on \((0,1)\), and \(\int_\delta^1\frac{dx}x=-\ln\delta\to\infty\). So \(f\notin L^2(E)\).

Let \(g(x)=0\) for \(0<x<1\) and \(g(x)=\frac1x\) for \(x\ge1\). Then \(\int_1^b\frac{dx}{x^2}=1-\frac1b\to1\), so \(g\in L^2(E)\) by Theorem 16.4.7. But \(\int_1^b\frac{dx}x=\ln b\to\infty\), so \(g\notin L^1(E)\).

Exercise 18.1.3. Hint. Take \(p=q=2\) in Theorem 18.1.3.

Exercise 18.1.4. Hint. For each \(n\), \(|f|\le\left\lVert f\right\rVert_\infty+\frac1n\) off a set of measure zero. Take the union of these sets.

Exercise 18.2.1. For \(2^k\le n<2^{k+1}\), \(f_n\) is \(1\) on an interval of length \(2^{-k}\) and \(0\) elsewhere. So \(\left\lVert f_n\right\rVert_p^p=2^{-k}\). As \(n\to\infty\), \(k\to\infty\), so \(\left\lVert f_n\right\rVert_p\to0\).

Fix \(x\in[0,1]\) and \(k\ge1\). The intervals \([j2^{-k},(j+1)2^{-k}]\) with \(0\le j<2^k\) cover \([0,1]\), so \(f_n(x)=1\) for at least one \(n\) with \(2^k\le n<2^{k+1}\). Since there are at least two such intervals and \(x\) lies in at most two of them, if \(k\ge2\) then \(f_n(x)=0\) for another such \(n\). So \(f_n(x)=1\) and \(f_n(x)=0\) each happen for infinitely many \(n\), and \(\{f_n(x)\}\) does not converge.

The subsequence \(f_{2^k}=\chi_{[0,2^{-k}]}\) converges to \(0\) at every \(x\in(0,1]\), so almost everywhere.

Exercise 18.2.2. Hint. Off one set of measure zero, \(|f_n-f_m|\le\left\lVert f_n-f_m\right\rVert_\infty\) for all \(m,n\). There the sequence is uniformly Cauchy.

Exercise 18.2.3. Hint. \(\{|f_n-f|\ge\varepsilon\}=\{|f_n-f|^p\ge\varepsilon^p\}\).

Exercise 18.3.1. Repeat the proof of Theorem 18.3.1. The first step is unchanged. In the second step, Theorem 15.2.7 also gives a continuous \(h\) with \(-N\le h\le N\) and \(m(\{x:|f_N(x)-h(x)|\ge\eta\})<\eta\). The same estimate gives \(\int_{[a,b]}|f_N-h|^p\le\eta^p(b-a)+(2N)^p\eta<\left(\frac\varepsilon 2\right)^p\) for small \(\eta\). Then \(\left\lVert f-h\right\rVert_p\le\left\lVert f-f_N\right\rVert_p+\left\lVert f_N-h\right\rVert_p<\varepsilon\).

Exercise 18.3.2. Hint. For \(f=\chi_{[c,d]}\), the integral is \(\frac{\cos nc-\cos nd}n\). Then use Theorem 18.3.1 with \(p=1\).
