Solutions for Chapter 14. Lebesgue Measure

Exercise 14.1.1. Since \(A\subset B\), \(\{\{I_n\}: B\subset\bigcup I_n\}\subset\{\{I_k\}: A\subset\bigcup I_k\}\). So \[\left\{\sum \ell(I_n): B\subset\bigcup I_n\right\}\subset\left\{\sum \ell(I_k): A\subset\bigcup I_k\right\},\] implying \[\inf_{A\subset\bigcup I_k}\sum \ell(I_k)\leq \inf_{B\subset\bigcup I_n}\sum \ell(I_n).\] Thus \(m^*(A)\leq m^*(B)\).

Exercise 14.1.2. Let \(E\subset\mathbb{R}\), \(y\in\mathbb{R}\). Notice that \(E\subset\bigcup I_n\), where each \(I_n\) is an open interval, if and only if \(E+y\subset \bigcup J_n\), where \(J_n=I_n+y\). Each \(J_n\) is an open interval and \(\ell(I_n)=\ell(J_n)\), so \(\sum \ell(I_n)=\sum \ell(J_n)\). Also notice that if \(E+y\subset \bigcup J_n\), then there exists some cover \(\{I_n\}\) of \(E\) with \(I_n=J_n-y\) such that \(E+y\subset\bigcup(I_n+y)\). Again, since \(\ell(I_n)=\ell(J_n)\), \(\sum \ell(I_n)=\sum \ell(J_n)\). So \(\left\{\sum \ell(I_n): E\subset\bigcup I_n\right\}=\left\{\sum \ell(J_n): E+y\subset\bigcup J_n\right\}\) and \[\inf_{E\subset\bigcup I_n}\sum \ell(I_n)= \inf_{E+y\subset\bigcup J_n}\sum \ell(J_n).\] So \(m^*(E)=m^*(E+y)\).

Exercise 14.1.4. Let \(\varepsilon>0\). If \(m^*(A)=\infty\), take \(U=\mathbb{R}\). So assume \(m^*(A)<\infty\). Since \(m^*(A)=\inf_{A\subset\bigcup I_n}\sum \ell(I_n)\), there exists a sequence \(\{I_n\}\) of open intervals such that \(A\subset\bigcup I_n\) and \(m^*(A)+\varepsilon\geq \sum \ell(I_n)\). Let \(U=\bigcup I_n\). Then \(U\) is open, \(A\subset U\) and \[m^*(U)=m^*\left(\bigcup I_n\right)\le\sum m^*(I_n)= \sum \ell(I_n) \leq m^*(A)+\varepsilon.\] The first inequality is Theorem 14.1.6, and \(m^*(I_n)=\ell(I_n)\) by Theorem 14.1.4.

Exercise 14.1.6. Hint. Each open interval lies in its closure, which has the same length. Each closed interval \(J_n\) lies in an open interval of length \(\ell(J_n)+\frac{\varepsilon}{2^n}\).

Exercise 14.1.7. Hint. \(\{I_n\}\) covers \(A\) if and only if \(\{cI_n\}\) covers \(cA\), and \(\ell(cI_n)=c\,\ell(I_n)\). Compare Exercise 14.1.2.

Exercise 14.2.1. Hint. Use Corollary 14.1.7 and Lemma 14.2.3.

Solution. Let \(A\) be countable. By Corollary 14.1.7, \(m^*(A)=0\). By Lemma 14.2.3, \(A\) is measurable, and \(m(A)=m^*(A)=0\).

In particular, \(\mathbb{Q}\) is measurable. Since \(\mathcal{M}\) is a \(\sigma\)-algebra (Theorem 14.2.8), \(\mathbb{R}\setminus\mathbb{Q}=\mathbb{Q}^c\) is measurable. The interval \([0,1]\) is measurable by Theorem 14.2.10. So \([0,1]\cap\mathbb{Q}\) and \([0,1]\setminus\mathbb{Q}=[0,1]\cap\mathbb{Q}^c\) are measurable and disjoint, and their union is \([0,1]\). By additivity, \[1=m([0,1])=m([0,1]\cap\mathbb{Q})+m([0,1]\setminus\mathbb{Q})=0+m([0,1]\setminus\mathbb{Q}).\] So \(m\bigl([0,1]\setminus\mathbb{Q}\bigr)=1\).

Exercise 14.2.2. Hint. Write \(F=\bigl(E\setminus(E\setminus F)\bigr)\cup(F\setminus E)\).

Exercise 14.2.4. Hint. Apply the definition of measurability of \(E\) to the sets \(A\) and \(A\cup E\).

Solution. Test the set \(A\cup E\) with the measurable set \(E\). Since \((A\cup E)\cap E=E\) and \((A\cup E)\cap E^c=A\cap E^c\), \[m^*(A\cup E)=m^*(E)+m^*(A\cap E^c).\] Add \(m^*(A\cap E)\) to both sides. Then test \(A\) with \(E\), which gives \(m^*(A\cap E)+m^*(A\cap E^c)=m^*(A)\). So \[m^*(A\cup E)+m^*(A\cap E)=m(E)+m^*(A\cap E)+m^*(A\cap E^c)=m(E)+m^*(A).\] Only addition is used, so this holds even when some of the values are \(\infty\).

Exercise 14.2.5. Hint. Countable sets have measure zero, by Corollary 14.1.7.

Exercise 14.3.1. Hint. First, show that for \(m^*(E)<\infty\), (1)\(\Rightarrow\)(2). Then show for arbitrary sets \(E\), (1)\(\Rightarrow\)(2)\(\Rightarrow\)(4)\(\Rightarrow\)(1). Finally, show (1)\(\Rightarrow\)(3)\(\Rightarrow\)(5)\(\Rightarrow\)(1).

Solution.Let \(\varepsilon>0\).

((1)\(\Rightarrow\)(2)) First assume \(m^*(E)<\infty\). Then there exists an open set \(O\) with \(E\subset O\) and \(m(O)\leq m(E)+\frac\varepsilon 2\), by Exercise 14.1.4. Since \(E\) is measurable, \(m(O\setminus E)=m(O\cap E^c)=m(O) - m(O\cap E)= m(O)-m(E)\le\frac\varepsilon 2<\varepsilon\). The subtraction is allowed because \(m(E)<\infty\). Now assume \(m^*(E)=\infty\). Let \(E_n= E\cap[-n,n]\). So \(m (E_n)\le 2n<\infty\). So there exists an open set \(O_n\) such that \(E_n\subset O_n\) and \(m(O_n\setminus E_n)< \frac{\varepsilon}{2^n}\). Let \(O=\bigcup_{n\in\mathbb{N}} O_n\). Then \(E\subset O\) and \[m^*(O\setminus E)=m(O\setminus E)=m\left(\left(\bigcup O_n\right)\setminus E\right)\le m\left(\bigcup(O_n\setminus E_n)\right)\le \sum m(O_n\setminus E_n)<\sum_{n\in\mathbb{N}} \frac{\varepsilon}{2^n}=\varepsilon.\] The first inequality holds since \(E_n\subset E\), so \(O_n\setminus E\subset O_n\setminus E_n\).

((2)\(\Rightarrow\)(4)) For each \(n\in\mathbb{N}\), there exists an open set \(O_n\) containing \(E\) such that \(m^*(O_n\setminus E)<\frac1n\). Let \(G=\bigcap_{n\in\mathbb{N}} O_n\). So \(G\) is a \(G_\delta\) containing \(E\), and for all \(n\), \(m^*(G\setminus E)\le m^*(O_n\setminus E)<\frac1n\). So \(m^*(G\setminus E)=0\).

((4)\(\Rightarrow\)(1)) Since \(G\) is a \(G_\delta\), \(G\) is measurable by Theorem 14.2.10. Now \(m^*(G\cap E^c)=m^*(G\setminus E)=0\) and so \(G\cap E^c\) is measurable by Lemma 14.2.3. But \(E= G\setminus (G\cap E^c)\) and so \(E\) is measurable.

((1)\(\Rightarrow\)(3)) Since \(E\) is measurable, \(E^c\) is measurable. So since (1)\(\Rightarrow\)(2), there exists an open set \(O\) containing \(E^c\) such that \(m^*(O\setminus E^c)<\varepsilon\). Let \(F=O^c\). So \(F\) is closed, \(F\subset E\), and \(E\setminus F=E\cap F^c=E\cap O=O\setminus E^c\). Thus \(m^*(E\setminus F)=m(O\setminus E^c)<\varepsilon\).

((3)\(\Rightarrow\)(5)) For each \(n\in\mathbb{N}\), there exists a closed set \(F_n{}\subset E\) such that \(m^*(E\setminus F_n)<\frac1n\). Let \(F=\bigcup F_n\). So \(F\) is an \(F_\sigma\) contained in \(E\), and for all \(n\), \(m^*(E\setminus F)\leq m^*(E\setminus F_n)<\frac1n\). So \(m^*(E\setminus F)=0\).

((5)\(\Rightarrow\)(1)) Since \(F\) is an \(F_\sigma\), \(F\) is measurable. Now \(m^*(E\setminus F)=0\), so \(E\setminus F\) is measurable by Lemma 14.2.3. But \(E=F\cup(E\setminus F)\), and so \(E\) is measurable.

Exercise 14.3.2. Hint. For (2)\(\Rightarrow\)(6), write the open set \(U\) as a countable union of disjoint open intervals, by Theorem 4.1.12, and keep finitely many of them.

Exercise 14.3.3. Hint. By Theorem 14.3.1 (3), there is a closed set \(F\subset E\) with \(m(E\setminus F)<\frac\varepsilon 2\). Let \(K=F\cap[-n,n]\) for large \(n\), and use Theorem 13.3.9 (4).

Solution. Let \(\varepsilon>0\). By Theorem 14.3.1 (3), there is a closed set \(F\subset E\) with \(m^*(E\setminus F)<\frac\varepsilon 2\). The sets \(F\) and \(E\setminus F\) are measurable, by Theorem 14.2.10. For \(n\in\mathbb{N}\), let \(K_n=F\cap[-n,n]\). It is closed by Theorem 4.1.17, and it lies in the compact set \([-n,n]\) (Theorem 4.2.14). So \(K_n\) is compact, by Lemma 4.2.10.

The sets \(F\setminus K_n=F\setminus[-n,n]\) decrease, and their intersection is empty, since every \(x\) lies in some \([-n,n]\). Also \(m(F\setminus K_1)\le m(E)<\infty\). By continuity from above (Theorem 13.3.9 (4)), \(m(F\setminus K_n)\to0\). Choose \(n\) with \(m(F\setminus K_n)<\frac\varepsilon 2\). Since \(K_n\subset F\subset E\), the set \(E\setminus K_n\) is the disjoint union of \(E\setminus F\) and \(F\setminus K_n\). So \[m(E\setminus K_n)=m(E\setminus F)+m(F\setminus K_n)<\frac\varepsilon 2+\frac\varepsilon 2=\varepsilon.\] So \(K=K_n\) works.

Exercise 14.3.4. Hint. Use (2) and Theorem 4.1.12.

Exercise 14.4.1. Hint. Write \(P_i\) as a union of translates of \(P\cap[0,1-r_i)\) and \(P\cap[1-r_i,1)\). So \(m^*(P_i)\le2m^*(P)\). If \(m^*(P)=0\), subadditivity gives \(m^*([0,1))=0\).

Exercise 14.4.2. Hint. In the same way, \(m^*(P)\le2m^*(P_i)\). So \(\sum m^*(P_i)=\infty\), by Exercise 14.4.1. But \(\bigcup P_i=[0,1)\).

Exercise 14.4.3. Hint. Consider the sets \(E\cap P_i\).

Solution. Use \(P\), the rational numbers \(r_0,r_1,\dots\) and the sets \(P_i=P\mathbin{\overset{\circ}{+}}r_i\) from the proof of Theorem 14.4.6. The sets \(P_i\) are disjoint and their union is \([0,1)\). So \(E\) is the disjoint union of the sets \(E\cap P_i\). We show that one of them is not measurable.

Suppose every \(E\cap P_i\) is measurable. By countable additivity, \(m(E)=\sum_im(E\cap P_i)\). Since \(m(E)>0\), some \(F=E\cap P_k\) has \(m(F)>0\).

For each \(j\), \(F\mathbin{\overset{\circ}{+}}r_j\) is measurable with \(m(F\mathbin{\overset{\circ}{+}}r_j)=m(F)\), by Lemma 14.4.4. Since \(\mathbin{\overset{\circ}{+}}\) is associative (Remark 14.4.2), \[F\mathbin{\overset{\circ}{+}}r_j\subset P_k\mathbin{\overset{\circ}{+}}r_j=P\mathbin{\overset{\circ}{+}}(r_k\mathbin{\overset{\circ}{+}}r_j).\] The number \(r_k\mathbin{\overset{\circ}{+}}r_j\) is a rational number in \([0,1)\), so it is \(r_{\sigma(j)}\) for some index \(\sigma(j)\). These indices are distinct. If \(r_k\mathbin{\overset{\circ}{+}}r_j=r_k\mathbin{\overset{\circ}{+}}r_{j'}\), then \(r_j-r_{j'}\) is \(-1\), \(0\) or \(1\). Since \(r_j,r_{j'}\in[0,1)\), it is \(0\), so \(j=j'\). So the sets \(F\mathbin{\overset{\circ}{+}}r_j\) lie in the disjoint sets \(P_{\sigma(j)}\), and they are pairwise disjoint. They all lie in \([0,1)\). By countable additivity and monotonicity, \[\sum_{j=0}^\infty m(F)=m\left(\bigcup_{j=0}^\infty F\mathbin{\overset{\circ}{+}}r_j\right)\le m([0,1))=1.\] But the left side is \(\infty\), since \(m(F)>0\). This contradiction shows that some \(E\cap P_i\) is not measurable. It is a subset of \(E\).
