Solutions for Appendix A. Construction of the Real Numbers by Cuts

Exercise A.1.1. Hint. (a) Check property (2). (b) Check property (3). (c) It is a cut. For property (3), use \(r=\frac{3p+3}{p+3}\), as in Theorem 1.3.5. (d) First find the set, using Lemma A.1.5.

Exercise A.1.2. (\(\Rightarrow\)) If \(\alpha=q^*\), then \(q\) is the smallest element of \(\mathbb{Q}\setminus\alpha\), by Example A.1.3.

(\(\Leftarrow\)) Let \(q\) be the smallest element of \(\mathbb{Q}\setminus\alpha\). If \(p\in\alpha\), then \(p<q\) by Remark A.1.2, so \(p\in q^*\). If \(p<q\), then \(p\notin\mathbb{Q}\setminus\alpha\), since \(q\) is the smallest element of that set. So \(p\in\alpha\). Thus \(\alpha=q^*\).

Exercise A.2.1. Since \(\alpha\subsetneqq\beta\), there is a \(p\in\beta\) with \(p\notin\alpha\). Since \(\beta\) has no largest element, there is a \(q\in\beta\) with \(q>p\).

If \(r\in\alpha\), then \(r<p\) by Remark A.1.2, so \(r<q\) and \(r\in q^*\). So \(\alpha\subset q^*\). Also \(p\in q^*\) and \(p\notin\alpha\). So \(\alpha<q^*\).

If \(r<q\), then \(r\in\beta\), since \(q\in\beta\). So \(q^*\subset\beta\). Also \(q\in\beta\) and \(q\notin q^*\). So \(q^*<\beta\).

Exercise A.2.2. Hint. By Theorem A.2.3, the supremum is the union of the cuts \(q^*\) with \(q\in\alpha\).

Exercise A.3.1. (1) Since \(r+s=s+r\) in \(\mathbb{Q}\), \[\alpha+\beta=\{r+s:r\in\alpha,\ s\in\beta\}=\{s+r:s\in\beta,\ r\in\alpha\}=\beta+\alpha.\]

(2) An element of \((\alpha+\beta)+\gamma\) is a sum \(w+t\) with \(w\in\alpha+\beta\) and \(t\in\gamma\), and \(w=r+s\) with \(r\in\alpha\) and \(s\in\beta\). So \((\alpha+\beta)+\gamma\) is the set of all numbers \((r+s)+t\) with \(r\in\alpha\), \(s\in\beta\) and \(t\in\gamma\). In the same way, \(\alpha+(\beta+\gamma)\) is the set of all numbers \(r+(s+t)\). Since \((r+s)+t=r+(s+t)\) in \(\mathbb{Q}\), the two cuts are equal.

Exercise A.3.2. Hint. By Example A.1.4, \(\mathbb{Q}\setminus\alpha\) is the set \(B\) of Theorem 1.3.5. Use that \(B\) has no smallest element.

Exercise A.4.1. Only the additive facts of Corollary A.3.5 are used to rearrange sums, such as \(-(\beta+\gamma)=(-\beta)+(-\gamma)\) and \(-(-\gamma)=\gamma\).

The proof starts with the rule of signs. First, \((-\alpha)\beta=-(\alpha\beta)\) for all cuts \(\alpha\) and \(\beta\). If \(\alpha=0^*\) or \(\beta=0^*\), both sides are \(0^*\). Otherwise there are four cases, by Definition A.4.6.

  • If \(\alpha>0^*\) and \(\beta>0^*\), then \(-\alpha<0^*<\beta\), so \((-\alpha)\beta=-(\alpha\beta)\) by definition.

  • If \(\alpha<0^*<\beta\), then \(\alpha\beta=-\bigl((-\alpha)\beta\bigr)\) by definition, so \((-\alpha)\beta=-(\alpha\beta)\).

  • If \(\beta<0^*<\alpha\), then \(-\alpha<0^*\) and \(\beta<0^*\). So \((-\alpha)\beta=\alpha(-\beta)\) by definition, and \(\alpha(-\beta)=-(\alpha\beta)\) since \(\alpha\beta=-\bigl(\alpha(-\beta)\bigr)\).

  • If \(\alpha<0^*\) and \(\beta<0^*\), then \(\beta<0^*<-\alpha\). So \((-\alpha)\beta=-\bigl((-\alpha)(-\beta)\bigr)=-(\alpha\beta)\).

Since multiplication is commutative, also \(\alpha(-\beta)=-(\alpha\beta)\).

Next comes associativity. If one of \(\alpha\), \(\beta\), \(\gamma\) is \(0^*\), both sides of \((\alpha\beta)\gamma=\alpha(\beta\gamma)\) are \(0^*\). If the identity holds for \(\alpha\), \(\beta\) and \(\gamma\), it also holds with \(\alpha\) replaced by \(-\alpha\), since by the rule of signs \[\bigl((-\alpha)\beta\bigr)\gamma=-\bigl((\alpha\beta)\gamma\bigr)=-\bigl(\alpha(\beta\gamma)\bigr)=(-\alpha)(\beta\gamma).\] The same computation works for \(\beta\) and for \(\gamma\). The identity holds when all three cuts are positive, by Theorem A.4.5 (2). Every nonzero cut is a positive cut or the negative of one. So the identity holds for all cuts.

Last comes distributivity. If \(\alpha(\beta+\gamma)=\alpha\beta+\alpha\gamma\), then \[(-\alpha)(\beta+\gamma)=-\bigl(\alpha\beta+\alpha\gamma\bigr)=(-\alpha)\beta+(-\alpha)\gamma.\] So it is enough to treat \(\alpha\ge0^*\), and \(\alpha=0^*\) is clear. Let \(\alpha>0^*\). If \(\beta,\gamma\ge0^*\), the identity is Theorem A.4.5 (5), or is clear when \(\beta\) or \(\gamma\) is \(0^*\). If \(\beta,\gamma\le0^*\), then \(-\beta,-\gamma\ge0^*\), and \[\alpha(\beta+\gamma)=-\bigl(\alpha((-\beta)+(-\gamma))\bigr)=-\bigl(\alpha(-\beta)+\alpha(-\gamma)\bigr)=\alpha\beta+\alpha\gamma.\] Finally, suppose one of \(\beta\), \(\gamma\) is positive and the other is negative. Since addition is commutative, it is enough to take \(\beta>0^*>\gamma\). If \(\beta+\gamma\ge0^*\), then \(\beta=(\beta+\gamma)+(-\gamma)\) is a sum of two cuts that are at least \(0^*\). So \(\alpha\beta=\alpha(\beta+\gamma)+\alpha(-\gamma)=\alpha(\beta+\gamma)-\alpha\gamma\), which gives \(\alpha(\beta+\gamma)=\alpha\beta+\alpha\gamma\). If \(\beta+\gamma<0^*\), then \(-\gamma=\bigl(-(\beta+\gamma)\bigr)+\beta\) is a sum of two positive cuts. So \[-(\alpha\gamma)=\alpha(-\gamma)=-\bigl(\alpha(\beta+\gamma)\bigr)+\alpha\beta,\] which again gives \(\alpha(\beta+\gamma)=\alpha\beta+\alpha\gamma\).

Exercise A.4.2. Hint. If \(r,s>0\) and \(r^2,s^2<2\), then \((rs)^2<4\). For the other inclusion, let \(0<p<2\). Apply Lemma A.4.4 with a rational \(t>1\) such that \(t^2\le\frac2p\).

Exercise A.5.1. (\(\Rightarrow\)) Let \(q\in\alpha\). If \(r<q\), then \(r\in\alpha\). So \(q^*\subset\alpha\). Also \(q\in\alpha\) and \(q\notin q^*\). So \(q^*<\alpha\).

(\(\Leftarrow\)) Let \(q^*<\alpha\). Then there is a \(p\in\alpha\) with \(p\notin q^*\), that is, \(p\ge q\). If \(q=p\), then \(q\in\alpha\). If \(q<p\), then \(q\in\alpha\) by property (2) of Definition A.1.1.
