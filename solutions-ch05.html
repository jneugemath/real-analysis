Solutions for Chapter 5. The Cantor Set

Exercise 5.1.1. By Lemma 5.1.2 (1), \(C_n\) is the union of the \(2^n\) disjoint intervals \(J_{n,1},\dots,J_{n,2^n}\), and each has length \(\frac{1}{3^n}\). So the sum of their lengths is \(2^n\cdot\frac{1}{3^n}=\left(\frac23\right)^n\).

The intervals removed in building \(C_1,\dots,C_n\) fill up the rest of \([0,1]\), apart from endpoints. So their lengths add up to \(1-\left(\frac23\right)^n\). As \(n\to\infty\), \(\left(\frac23\right)^n\to0\) by Example 3.1.7. So the lengths of all the removed intervals add up to \(1\). This is Theorem 5.1.5.

Exercise 5.1.2. Hint. For each \(n\) there are only finitely many endpoints. Use Theorem 2.2.6.

Exercise 5.2.3. Hint. Find a ternary expansion of \(\frac34\) that uses only the digits \(0\) and \(2\), and use Theorem 5.2.7.

Solution. Take the digits \(n_k=2\) for odd \(k\) and \(n_k=0\) for even \(k\). The odd \(k\) are \(k=2j-1\) for \(j\in\mathbb{N}\), so \[\sum_{k=1}^\infty\frac{n_k}{3^k}=\sum_{j=1}^\infty\frac{2}{3^{2j-1}}=6\sum_{j=1}^\infty\left(\frac19\right)^j=6\cdot\frac{1/9}{1-1/9}=\frac34,\] using \(\sum_{i=0}^\infty r^i=\frac{1}{1-r}\) for \(|r|<1\), as in the proof of Theorem 5.1.5. So \(.2020\dots\) is a ternary expansion of \(\frac34\) that uses only the digits \(0\) and \(2\). By Theorem 5.2.7, \(\frac34\in C\).

Exercise 5.2.4. Four points in the Cantor set include \(1/3\) and \(2/3\), which are both endpoints, and \(1/4\) and \(111/364\), which both have ternary expansions consisting of \(0\)’s and \(2\)’s. Indeed, \(\frac14=.020202\dots\) and \(\frac{111}{364}=.022020\,022020\dots\) (base \(3\)), so both are in \(C\) by Theorem 5.2.7. Every endpoint of an interval \(J_{n,i}\) has the form \(\frac{k}{3^n}\) by Lemma 5.1.2. In lowest terms, \(\frac14\) and \(\frac{111}{364}\) have denominators \(4\) and \(364\), which are not powers of \(3\). So they are not endpoints.

Exercise 5.2.5. Hint. An interval inside \(C\) lies inside \(C_n\) for every \(n\), so its length is at most \(3^{-n}\). For \(C'=C\), use Theorem 5.1.4 and the fact that \(C\) is closed.
