The Lebesgue integral of \(f\) will be built by measuring the sets where \(f\) takes values in a given range. So \(f\) must be a function for which those sets are measurable. Such functions are called measurable. This chapter shows that the class of measurable functions is very large. It contains the continuous functions, it is closed under the usual arithmetic, and, unlike the Riemann integrable functions, it is closed under pointwise limits.

Section 15.1 defines measurable functions and the phrase “almost everywhere.” Section 15.2 introduces simple functions and step functions, and shows that every measurable function on \([a,b]\) is close to a step function and to a continuous function. Section 15.3 shows that pointwise convergence is close to uniform convergence. Section 15.4, which is marked with a star, proves Lusin’s Theorem, the sharpest form of “measurable functions are nearly continuous.”

What this chapter uses from earlier chapters. Lebesgue measure and its properties (Chapter 14), the continuity of measure (Theorem 13.3.9), limits superior and inferior (Section 3.6), uniform convergence (Section 11.2), and Theorem 6.3.16.

15.1 Measurable Functions and “Almost Everywhere”

Measurable functions may take the values \(\infty\) and \(-\infty\). The extended real numbers are \([-\infty,\infty]=\mathbb{R}\cup\{-\infty,\infty\}\), with \(-\infty<x<\infty\) for every \(x\in\mathbb{R}\). An extended real-valued function is a function \(f:D\to[-\infty,\infty]\). The set \(\{x\in D:f(x)>\alpha\}\) is written \(\{x:f(x)>\alpha\}\), or just \(\{f>\alpha\}\), when the domain \(D\) is clear.

Theorem 15.1.1. Let \(D\subset\mathbb{R}\) be measurable and let \(f:D\to[-\infty,\infty]\). The following are equivalent.

  1. For each \(\alpha\in\mathbb{R}\), the set \(\{x:f(x)>\alpha\}\) is measurable.

  2. For each \(\alpha\in\mathbb{R}\), the set \(\{x:f(x)\ge \alpha\}\) is measurable.

  3. For each \(\alpha\in\mathbb{R}\), the set \(\{x:f(x)<\alpha\}\) is measurable.

  4. For each \(\alpha\in\mathbb{R}\), the set \(\{x:f(x)\le \alpha\}\) is measurable.

These statements imply:

  1. for each \(\alpha\in[-\infty,\infty]\), the set \(\{x:f(x)=\alpha\}\) is measurable.

Proof. ((1)\(\Rightarrow\)(4)) Now \(\{x:f(x)\le \alpha\}=D\setminus\{x:f(x)>\alpha\}\), and so \(\{x:f(x)\le \alpha\}\) is measurable.

((4)\(\Rightarrow\)(1)) Now \(\{x:f(x)> \alpha\}=D\setminus\{x:f(x)\le\alpha\}\), and so \(\{x:f(x)> \alpha\}\) is measurable.

((2)\(\Rightarrow\)(3)) Now \(\{x:f(x)< \alpha\}=D\setminus\{x:f(x)\ge\alpha\}\), and so \(\{x:f(x)< \alpha\}\) is measurable.

((3)\(\Rightarrow\)(2)) Now \(\{x:f(x)\ge \alpha\}=D\setminus\{x:f(x)<\alpha\}\), and so \(\{x:f(x)\ge \alpha\}\) is measurable.

((1)\(\Rightarrow\)(2)) Since \(\{x:f(x)\ge \alpha\}=\bigcap_{n=1}^\infty\left\{x:f(x)>\alpha-\frac{1}{n}\right\}\), \(\{x:f(x)\ge \alpha\}\) is measurable.

((2)\(\Rightarrow\)(1)) Since \(\{x:f(x)> \alpha\}=\bigcup_{n=1}^\infty\left\{x:f(x)\ge\alpha+\frac{1}{n}\right\}\), \(\{x:f(x)> \alpha\}\) is measurable. So (1)–(4) are equivalent.

((2),(4)\(\Rightarrow\)(5) if \(\alpha\in\mathbb{R}\)) Let \(\alpha\in\mathbb{R}\). Then \(\{x:f(x)=\alpha\}=\{x:f(x)\ge \alpha\}\cap\{x:f(x)\le \alpha\}\). So \(\{x:f(x)=\alpha\}\) is measurable.

((2)\(\Rightarrow\)(5) if \(\alpha=\infty\)) Let \(\alpha=\infty\). Since \(\{x:f(x)=\infty\}=\bigcap_{n=1}^\infty\{x:f(x)\ge n\}\), \(\{x:f(x)=\infty\}\) is measurable.

((4)\(\Rightarrow\)(5) if \(\alpha=-\infty\)) Let \(\alpha=-\infty\). Since \(\{x:f(x)=-\infty\}=\bigcap_{n=1}^\infty\{x:f(x)\le -n\}\), \(\{x:f(x)=-\infty\}\) is measurable.

∎

Definition 15.1.2. An extended real-valued function is measurable if its domain is measurable and if it satisfies one of (1)–(4) in Theorem 15.1.1.

Example 15.1.3. Let \(f:\mathbb{R}\to\mathbb{R}\) be continuous. For each \(\alpha\), the set \(\{f>\alpha\}=f^{-1}[(\alpha,\infty)]\) is open, by Theorem 6.3.16. Open sets are measurable, so \(f\) is measurable. If \(f:[a,b]\to\mathbb{R}\) is increasing, then each set \(\{f>\alpha\}\) is an interval, so \(f\) is measurable. The same holds for decreasing functions.

Measurability is a weak version of continuity. A continuous function pulls open sets back to open sets. A measurable function pulls rays, and so all Borel sets, back to measurable sets (Exercise 15.1.3).

Theorem 15.1.4. Let \(c\in\mathbb{R}\) and let \(D\) be measurable and \(f,g:D\to\mathbb{R}\) be measurable. Then the functions \(f+c\), \(cf\), \(f+g\), \(f-g\), \(g-f\), \(f^2\), and \(fg\) are also measurable.

Proof. Now \(\{x:f(x)+c<\alpha\}=\{x:f(x)<\alpha-c\}\). So \(f+c\) is measurable since \(f\) is measurable.

If \(c=0\), \(0f(x)=0\) for all \(x\), and so \(\{x:cf(x)<\alpha\}=\emptyset\) or \(\{x:cf(x)<\alpha\}=D\). Either way, \(\{x:cf(x)<\alpha\}\) is measurable. If \(c>0\), \(\{x:cf(x)<\alpha\}=\left\{x:f(x)<\frac{\alpha}{c}\right\}\) is measurable. If \(c<0\), \(\{x:cf(x)<\alpha\}=\left\{x:f(x)>\frac{\alpha}{c}\right\}\) is measurable. So for all \(c\in\mathbb{R}\), \(\{x:cf(x)<\alpha\}\) is measurable. Thus \(cf\) is measurable.

If \(f(x)+g(x)<\alpha\), then \(f(x)<\alpha-g(x)\). So there exists an \(r\in\mathbb{Q}\) such that \(f(x)<r<\alpha-g(x)\) (Theorem 1.7.11). Hence \[\{x:f(x)+g(x)<\alpha\}=\bigcup_{r\in\mathbb{Q}}\bigl(\{x:f(x)<r\}\cap\{x:g(x)<\alpha-r\}\bigr).\] Since \(\mathbb{Q}\) is countable, this set is measurable. So \(f+g\) is measurable.

Since \(-g=(-1)g\) is measurable, \(f+(-g)=f-g\) is measurable. This implies \((-1)(f-g)=g-f\) is also measurable.

Lastly, \(\{x:f^2(x)>\alpha\}=\{x:f(x)>\sqrt{\alpha}\}\cup\{x:f(x)<-\sqrt{\alpha}\}\) for \(\alpha\ge 0\) and \(\{x:f^2(x)>\alpha\}=D\) if \(\alpha<0\), and so \(f^2\) is measurable. Therefore \[fg=\frac{1}{2}\left[(f+g)^2-f^2-g^2\right]\] is measurable.

∎

Theorem 15.1.5. Let \(\{f_n\}\) be a sequence of measurable functions with the same domain \(D\). Then the functions \(\sup\{f_1,\dots,f_n\}\), \(\inf\{f_1,\dots,f_n\}\), \(\sup_{n\in\mathbb{N}} f_n\), \(\inf_{n\in\mathbb{N}}f_n\), \(\limsup f_n\), and \(\liminf f_n\) are all measurable.

Proof. For each \(x\in D\), define \(h(x)=\sup\{f_1(x),\dots,f_n(x)\}\). Then \(\{x:h(x)>\alpha\}=\bigcup_{i=1}^n\{x:f_i(x)>\alpha\}\). So \(h\) is measurable. Similarly, for each \(x\in D\), define \(g(x)=\sup_{n\in\mathbb{N}} f_n(x)\). Then \(\{x:g(x)>\alpha\}=\bigcup_{n=1}^\infty\{x:f_n(x)>\alpha\}\). So \(g\) is measurable. A similar argument establishes the fact that \(\inf\{f_1,\dots,f_n\}\) and \(\inf_{n\in\mathbb{N}}f_n\) are measurable. For example, \(\{x:\inf_nf_n(x)<\alpha\}=\bigcup_{n=1}^\infty\{x:f_n(x)<\alpha\}\). Since \(\limsup f_n=\inf_{n\in\mathbb{N}}\left(\sup_{k\ge n}f_k\right)\) and \(\liminf f_n=\sup_{n\in\mathbb{N}}\left(\inf_{k\ge n}f_k\right)\), \(\limsup f_n\) and \(\liminf f_n\) are measurable.

∎

Corollary 15.1.6. If \(\{f_n\}\) is a sequence of measurable functions with domain \(D\) and \(f_n(x)\to f(x)\) for every \(x\in D\), then \(f\) is measurable.

Proof.

Here \(f=\limsup f_n\), which is measurable by Theorem 15.1.5.

∎

This is a big improvement on the Riemann integrable functions. In Example 11.1.6, each \(f_n\) is Riemann integrable but the pointwise limit is not. Each \(f_n\) there is measurable, so the limit is measurable.

Definition 15.1.7. A property is said to hold almost everywhere (a.e.) if the set of points where it fails to hold is a set of measure zero.

For example, the Dirichlet function of Example 6.1.9 is \(0\) almost everywhere, since it is nonzero only on \(\mathbb{Q}\), which has measure zero. Two functions that are equal almost everywhere will have the same integral. So in Lebesgue theory, sets of measure zero can usually be ignored.

Theorem 15.1.8. If \(f\) is a measurable function and \(f=g\) a.e., then \(g\) is measurable. Here \(f\) and \(g\) have the same domain \(D\).

Proof. Let \(E\) be the set \(\{x:f(x)\ne g(x)\}\). By hypothesis, \(m(E)=0\). Now \[\{x:g(x)>\alpha\}=\bigl[\{x:f(x)>\alpha\}\cup\{x\in E:g(x)>\alpha\}\bigr]\setminus\{x\in E:g(x)\le\alpha\}.\] Now the sets \(\{x\in E:g(x)>\alpha\}\) and \(\{x\in E:g(x)\le\alpha\}\) are both subsets of a measure zero set \(E\), so by Lemma 14.2.4, they are both measurable. Also, since \(f\) is measurable, \(\{x:f(x)>\alpha\}\) is measurable. So \(\{x:g(x)>\alpha\}\) is measurable, implying \(g\) is measurable.

∎

Definition 15.1.9. If \(A\) is any set, the characteristic function \(\chi_A\) of the set \(A\) is defined by \[\chi_A(x)=\begin{cases}1, & x\in A, \\ 0, & x\notin A.\end{cases}\] Here \(\chi_A:\mathbb{R}\to\mathbb{R}\). In probability, \(\chi_A\) is called the indicator function of \(A\) and is often written \(\mathbf{1}_A\).

Lemma 15.1.10. Let \(A\) and \(B\) be disjoint measurable sets. Then \(\chi_{A\cup B}=\chi_A + \chi _B\) and \(\chi_{A\cap B}=\chi_A\cdot\chi_B\). (The second identity holds for any sets \(A\) and \(B\).)

Proof. See Exercise 15.1.1.

∎

Lemma 15.1.11. \(\chi_A\) is measurable if and only if \(A\) is measurable.

Proof.

The set \(\{x:\chi_A(x)>\alpha\}\) is \(\mathbb{R}\) if \(\alpha<0\), it is \(A\) if \(0\le\alpha<1\), and it is \(\emptyset\) if \(\alpha\ge1\). The sets \(\mathbb{R}\) and \(\emptyset\) are measurable. So every set \(\{x:\chi_A(x)>\alpha\}\) is measurable if and only if \(A\) is measurable.

∎

15.2 Simple Functions and Step Functions

Simple functions are to the Lebesgue integral what step functions are to the Riemann integral. A step function is constant on each of finitely many intervals. A simple function is constant on each of finitely many measurable sets. The lemmas below show that a measurable function on \([a,b]\) can be approximated by simple functions, simple functions by step functions, and step functions by continuous functions. Theorem 15.2.7 puts these together.

Definition 15.2.1. A real-valued function \(\varphi\) on a measurable set \(D\) is simple if it is measurable and assumes only a finite number of values. If \(\varphi\) is simple, and \(\{a_1,\dots,a_n\}\) is the set of values \(\varphi\) takes, \(\varphi=\sum^n_{i=1}a_i\chi_{A_i}\) where for \(i=1,\dots,n\), \(A_i=\{x:\varphi(x)=a_i\}\) is measurable. This representation is called the canonical representation of \(\varphi\). Notice \(A_i\cap A_j=\emptyset\) for \(i\ne j\).

Definition 15.2.2. A real-valued function \(g\) is a step function if \(g=\sum^n_{i=1}c_i\chi_{I_i}\), where \(I_1,\dots,I_n\) are pairwise disjoint intervals and \(c_1,\dots,c_n\in\mathbb{R}\).

Intervals are measurable, so every step function is a simple function. The converse is false. The function \(\chi_\mathbb{Q}\) is simple, but it is not a step function, since \(\mathbb{Q}\) is not a finite union of intervals.

Lemma 15.2.3. Let \(f\) be a measurable function on \([a,b]\) that takes the values \(\pm\infty\) only on a set of measure zero. Then for all \(\varepsilon>0\), there exists an \(M>0\) such that \(m(\{x:|f(x)|>M\})<\varepsilon\).

Proof. See Exercise 15.2.1.

∎

Lemma 15.2.4. Let \(f\) be a measurable function on \([a,b]\). Then for all \(\varepsilon>0\) and for all \(M>0\), there exists a simple function \(\varphi\) such that \(|f(x)-\varphi(x)|<\varepsilon\) except when \(|f(x)|\ge M\). If \(\alpha\le f\le \beta\), \(\varphi\) can be chosen so that \(\alpha\le \varphi\le \beta\).

Proof. See Exercise 15.2.2.

∎

Lemma 15.2.5. Let \(\varphi\) be a simple function on \([a,b]\). Then for all \(\varepsilon>0\), there exists a step function \(g\) defined on \([a,b]\) such that \(m(\{x:g(x)\ne \varphi(x)\})<\varepsilon\). If \(\alpha\le \varphi\le \beta\), \(g\) can be chosen so that \(\alpha\le g\le \beta\).

Proof. See Exercise 15.2.3.

∎

Lemma 15.2.6. Let \(g\) be a step function on \([a,b]\). Then for all \(\varepsilon>0\), there exists a continuous function \(h\) on \([a,b]\) such that \(m(\{x:g(x)\ne h(x)\})<\varepsilon\). If \(\alpha\le g\le \beta\), \(h\) can be chosen so that \(\alpha\le h\le \beta\).

Proof. See Exercise 15.2.4.

∎

Theorem 15.2.7. Let \(f\) be a measurable function defined on an interval \([a,b]\), and assume \(f\) takes the values \(\pm\infty\) only on a set of measure zero. Then for all \(\varepsilon>0\), there exists a step function \(g\) and a continuous function \(h\) such that \(m(\{x:|f(x)-g(x)|\ge \varepsilon\})<\varepsilon\) and \(m(\{x:|f(x)-h(x)|\ge \varepsilon\})<\varepsilon\). If \(\alpha\le f\le \beta\), \(g\) and \(h\) may be chosen so that \(\alpha\le g\le \beta\) and \(\alpha\le h\le \beta\).

Proof. See Exercise 15.2.5.

∎

Proof Technique (Approximating in Stages).

Theorem 15.2.7 goes from a measurable function to a continuous one in three steps, measurable to simple to step to continuous. Each step allows a small error. Spend \(\frac\varepsilon 3\) on each, or \(\frac{\varepsilon}{2}\) on each of the last two after the first is done. When a hard approximation is needed, look for a chain of easier ones. This is the same idea as the \(\varepsilon/3\) argument in Chapter 11. Here the errors are measured by the size of the bad set instead of by a supremum.

15.3 Egoroff’s Theorem

Remark 15.3.1. Littlewood’s Three Principles.

  1. Every measurable set is nearly a finite union of intervals. (Theorem 14.3.1.)

  2. Every measurable function is nearly continuous. (Theorem 15.2.7 and Lusin’s Theorem, Theorem 15.4.2.)

  3. Every convergent sequence of measurable functions is nearly uniformly convergent. (Weak form, Theorems 15.3.2 and 15.3.4. Stronger form, Egoroff’s Theorem, Theorem 15.3.5.)

Theorem 15.3.2. Let \(E\) be a measurable set of finite measure and \(\{f_n\}\) a sequence of measurable real-valued functions defined on \(E\). Let \(f\) be a real-valued function such that for all \(x\in E\), \(f_n(x)\to f(x)\). Then for all \(\varepsilon>0\) and for all \(\delta>0\), there exists a measurable set \(A\subset E\) with \(m(A)<\delta\) and an \(N\in\mathbb{N}\) such that for all \(x\in E\setminus A\) and all \(n\ge N\), \(|f_n(x)-f(x)|<\varepsilon\).

Proof. By Corollary 15.1.6, \(f\) is measurable, so each \(f_n-f\) is measurable. For each \(n\in\mathbb{N}\), set \(G_n=\{x\in E: |f_n(x)-f(x)|\ge \varepsilon\}\) and set \[E_N=\bigcup_{n=N}^\infty G_n=\{x\in E : |f_n(x)-f(x)|\ge \varepsilon\text{ for some }n\ge N\}.\] Now \(E_{N+1}\subset E_N\), and for each \(x\in E\), there exists an \(E_{N_0}\) such that \(x\notin E_{N_0}\), since \(f_n(x)\to f(x)\). Thus, \(\bigcap E_N=\emptyset\) and so by Theorem 13.3.9 (4), \(\lim_{N\to\infty}m(E_N)=0\). This uses \(m(E_1)\le m(E)<\infty\). Now, let \(\delta>0\). So there exists an \(N\in\mathbb{N}\) such that \(m(E_N)<\delta\). Let \(A=E_N\). Then \(m(A)<\delta\) and \[E\setminus A=\{x\in E: |f_n(x)-f(x)|<\varepsilon\text{ for all }n\ge N\}.\]

∎

Definition 15.3.3. If there exists a subset \(B\subset E\) with \(m(B)=0\) such that \(f_n\to f\) pointwise on \(E\setminus B\), then \(f_n\to f\) a.e. on \(E\).

Theorem 15.3.4. Let \(E\) be a measurable set of finite measure, and \(\{f_n\}\) a sequence of measurable real-valued functions that converge to a real-valued function \(f\) a.e. on \(E\). Then for all \(\varepsilon>0\) and for all \(\delta>0\), there exists a measurable set \(A\subset E\) with \(m(A)<\delta\) and an \(N\in\mathbb{N}\) such that for all \(x\in E\setminus A\) and all \(n\ge N\), \(|f_n(x)-f(x)|<\varepsilon\).

Proof.

Let \(B\subset E\) with \(m(B)=0\) be a set off of which \(f_n\to f\). Apply Theorem 15.3.2 on \(E\setminus B\). It gives a measurable \(A'\subset E\setminus B\) with \(m(A')<\delta\), and an \(N\). Let \(A=A'\cup B\). Then \(m(A)<\delta\), and \(E\setminus A=(E\setminus B)\setminus A'\).

∎

Theorem 15.3.5 (Egoroff’s Theorem).

If \(\{f_n\}\) is a sequence of measurable real-valued functions that converge to a real-valued function \(f\) a.e. on a measurable set \(E\) of finite measure, then for all \(\eta>0\), there exists a measurable subset \(A\subset E\) with \(m(A)<\eta\) such that \(f_n\to f\) uniformly on \(E\setminus A\).

Proof.

Let \(\eta>0\). For each \(k\in\mathbb{N}\), apply Theorem 15.3.4 with \(\varepsilon=\frac1k\) and \(\delta=\frac{\eta}{2^k}\). It gives a measurable set \(A_k\subset E\) with \(m(A_k)<\frac{\eta}{2^k}\), and an \(N_k\in\mathbb{N}\), such that \[|f_n(x)-f(x)|<\frac1k\quad\text{for all }x\in E\setminus A_k\text{ and all }n\ge N_k.\] Let \(A=\bigcup_{k\in\mathbb{N}}A_k\). Then \(A\) is measurable, and \(m(A)\le\sum_km(A_k)<\eta\) by subadditivity. The set \(A\) does not depend on any \(\varepsilon\). Now let \(\varepsilon>0\), and choose \(k\) with \(\frac1k<\varepsilon\). If \(x\in E\setminus A\), then \(x\notin A_k\). So \(|f_n(x)-f(x)|<\frac1k<\varepsilon\) for all \(n\ge N_k\) and all \(x\in E\setminus A\). So \(f_n\to f\) uniformly on \(E\setminus A\).

∎

The conclusion of Egoroff’s Theorem is called almost uniform convergence. The hypothesis \(m(E)<\infty\) cannot be dropped. Let \(f_n=\chi_{[n,\infty)}\) on \(\mathbb{R}\). Then \(f_n\to0\) everywhere. But if \(m(A)<1\), then \([n,\infty)\setminus A\) is nonempty for every \(n\), so \(\sup_{x\notin A}|f_n(x)|=1\) for every \(n\).

15.4 Lusin’s Theorem*

This section can be skipped. Nothing later depends on it.

Theorem 15.2.7 says a measurable function \(f\) on \([a,b]\) is close to a continuous function \(h\), in the sense that \(|f-h|\) is small except on a small set. Lusin’s Theorem says more. There is a continuous function that equals \(f\) except on a small set. The proof needs one lemma, which extends a continuous function from a closed set to a whole interval.

Lemma 15.4.1. Let \(F\subset[a,b]\) be closed and nonempty, and let \(g:F\to\mathbb{R}\) be continuous. Then there is a continuous function \(\varphi:[a,b]\to\mathbb{R}\) with \(\varphi=g\) on \(F\).

Proof.

The set \(U=[a,b]\setminus F\) is open relative to \([a,b]\). By Theorem 4.1.12, applied to \((a-1,b+1)\setminus F\), it is a union of countably many disjoint intervals, the gaps of \(F\). Each gap is an open interval \((c,d)\) with \(c,d\in F\), or else an interval \([a,d)\) or \((c,b]\) that contains \(a\) or \(b\) and has one endpoint in \(F\). Define \(\varphi=g\) on \(F\). On a gap \((c,d)\) with both endpoints in \(F\), let \(\varphi\) be linear, with \(\varphi(c)=g(c)\) and \(\varphi(d)=g(d)\). On a gap containing \(a\) or \(b\), let \(\varphi\) be constant, equal to \(g\) at the endpoint in \(F\).

Then \(\varphi\) is continuous at every point of a gap, and continuous from each side at the endpoints of each gap, since it is linear or constant there. It remains to check continuity at a point \(x\in F\) from a side where \(x\) is a limit of other gaps. Let \(\varepsilon>0\). Since \(F\) is compact, \(g\) is uniformly continuous on \(F\) (Theorem 6.4.7). Choose \(\delta>0\) with \(|g(s)-g(t)|<\varepsilon\) for \(s,t\in F\) with \(|s-t|<\delta\). Only finitely many gaps have length at least \(\frac\delta2\), since the gaps are disjoint and lie in \([a,b]\). Each of these is either a gap with endpoint \(x\), which is handled above, or is at a positive distance from \(x\). So there is a \(\delta'\in\left(0,\frac\delta2\right)\) such that every point \(y\in[a,b]\) with \(|y-x|<\delta'\) lies in \(F\), or in a gap with endpoint \(x\), or in a gap of length less than \(\frac\delta2\). In the last case, the endpoint of that gap on the side of \(x\) is within \(\delta'\) of \(x\), so every endpoint of the gap that lies in \(F\) is within \(\delta'+\frac\delta2<\delta\) of \(x\). The value \(\varphi(y)\) lies between the values of \(g\) at those endpoints. So \[|\varphi(y)-g(x)|\le\max\{|g(c)-g(x)|:c\text{ an endpoint of the gap in }F\}<\varepsilon.\] If \(y\in F\), then \(|\varphi(y)-g(x)|=|g(y)-g(x)|<\varepsilon\). Together with continuity from the side of any gap with endpoint \(x\), this shows \(\varphi\) is continuous at \(x\).

∎

Theorem 15.4.2 (Lusin’s Theorem).

Let \(f\) be a measurable real-valued function on an interval \([a,b]\). Then for all \(\delta>0\), there exists a continuous function \(\varphi\) on \([a,b]\) such that \(m(\{x:f(x)\ne \varphi(x)\})<\delta\).

Proof.

For each \(n\in\mathbb{N}\), Theorem 15.2.7 with \(\varepsilon=\frac{1}{2^n}\) gives a continuous function \(h_n\) on \([a,b]\) with \(m(E_n)<\frac{1}{2^n}\), where \(E_n=\{x:|f(x)-h_n(x)|\ge\frac{1}{2^n}\}\). Choose \(N\) with \(\frac{1}{2^{N-1}}<\frac\delta2\), and let \(B=\bigcup_{n\ge N}E_n\). Then \(m(B)\le\sum_{n\ge N}\frac{1}{2^n}=\frac{1}{2^{N-1}}<\frac\delta2\). For \(x\in[a,b]\setminus B\) and \(n\ge N\), \(|f(x)-h_n(x)|<\frac{1}{2^n}\). So \(h_n\to f\) uniformly on \([a,b]\setminus B\).

By Theorem 14.3.1 (3), there is a closed set \(F\subset[a,b]\setminus B\) with \(m\bigl(([a,b]\setminus B)\setminus F\bigr)<\frac\delta2\). Then \(m([a,b]\setminus F)<\delta\). (If \(F\) is empty, then \(m([a,b])<\delta\), and any continuous \(\varphi\) works.) On \(F\), the continuous functions \(h_n\) converge uniformly to \(f\). So \(f\) restricted to \(F\) is continuous, by Corollary 11.2.16. By Lemma 15.4.1, there is a continuous \(\varphi\) on \([a,b]\) that equals \(f\) on \(F\). Then \(\{x:f(x)\ne\varphi(x)\}\subset[a,b]\setminus F\), which has measure less than \(\delta\).

∎

Exercises

Exercise 15.4.1. Show that \(m(\{f\ne\varphi\})<\delta\) in Lusin’s Theorem cannot be replaced by \(m(\{f\ne\varphi\})=0\). [Hint]

Exercise 15.4.2. Show that if \(|f|\le M\) on \([a,b]\), then the function \(\varphi\) in Lusin’s Theorem can be chosen with \(|\varphi|\le M\). [Hint]

Notes

Lebesgue introduced measurable functions in his 1902 thesis [41]. Dmitri Egoroff proved his theorem in 1911 [27]. Carlo Severini had found it independently a year earlier. Nikolai Lusin proved his theorem in 1912 [51], although Lebesgue and Vitali had stated forms of it earlier. John Edensor Littlewood stated his three principles in his 1944 lectures [50]. His advice was that if a problem would be easy when one of the principles held exactly, the word “nearly” is usually good enough.
