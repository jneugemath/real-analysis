Solutions for Chapter 4. Topological Properties of the Real Line

Exercise 4.1.1. (\(\Rightarrow\)) Let \(x\in U^\circ\). Then, by definition, \(x\in U\) and so \(U^\circ\subset U\). Now, let \(x\in U\). Since \(U\) is open, there exists an \(\varepsilon>0\) such that \((x-\varepsilon,x+\varepsilon)\subset U\). So \(x\in U^\circ\). So \(U\subset U^\circ\) and consequently, \(U=U^\circ\).

(\(\Leftarrow\)) Let \(x\in U\). Since \(U=U^\circ\), \(x\in U^\circ\). So there exists an \(\varepsilon>0\) such that \((x-\varepsilon,x+\varepsilon)\subset U\). So \(U\) is open.

Exercise 4.1.2. Let \(a,b\in\mathbb{R}\) with \(a<b\). First, consider the interval \((-\infty, b)\). Let \(x\in(-\infty, b)\) and define \(\varepsilon=\frac{b-x}{2}>0\). Then \((x-\varepsilon,x+\varepsilon)\subset(-\infty,b)\) and \((-\infty, b)\) is open.

Next, consider the interval \((a,\infty)\). Let \(x\in (a,\infty)\) and define \(\varepsilon=\frac{x-a}{2}>0\). Then \((x-\varepsilon,x+\varepsilon)\subset(a,\infty)\) and \((a,\infty)\) is open.

Last, consider the interval \((a,b)\). Let \(x\in (a,b)\) and define \(\varepsilon=\min\left\{\frac{x-a}{2},\frac{b-x}{2}\right\}\). Then \((x-\varepsilon,x+\varepsilon)\subset (a,b)\) and \((a,b)\) is open. The interval \((-\infty,\infty)=\mathbb{R}\) is open, since every interval \((x-1,x+1)\) lies in \(\mathbb{R}\).

Exercise 4.1.6. Hint. Every open interval contains rational and irrational numbers, by Theorem 1.8.11 and Exercise 1.8.5.

Exercise 4.1.7. (\(\Rightarrow\)) Let \(x\in\overline{E}\). If \(x\in E\), the constant sequence \(x_n=x\) works. Otherwise \(x\) is a limit point of \(E\). So for all \(n\in\mathbb{N}\), there exists an \(x_n\in E\) such that \(|x_n-x|<1/n\). Let \(\varepsilon>0\). Then by the Archimedean Principle, there exists an \(N\in\mathbb{N}\) such that \(N>1/\varepsilon\). So for all \(n\geq N\), \(|x_n-x|<1/n\leq 1/N<\varepsilon\). So \(\{x_n:n\in\mathbb{N}\}\subset E\) and \(x_n\to x\).

(\(\Leftarrow\)) Assume \(\{x_n\}\) is a sequence in \(E\) with \(x_n\to x\). If \(x\in E\), then \(x\in\overline{E}\). Suppose \(x\notin E\). Then \(x_n\ne x\) for all \(n\). Let \(\delta>0\). Since \(x_n\to x\), there exists an \(N\in\mathbb{N}\) such that for all \(n\geq N\), \(|x_n-x|<\delta\). In particular, \(x_N\in E\), \(x_N\ne x\), and \(|x_N-x|<\delta\). So \(x\) is a limit point of \(E\), and \(x\in\overline{E}\).

Exercise 4.1.9. Hint. If only finitely many points of \(E\) other than \(a\) lie in the interval, choose a smaller \(\varepsilon\) that misses all of them.

Exercise 4.1.10. Hint. Let \(A\) be an interval. Suppose \(U\) and \(V\) are disjoint open sets with \(A\cap U\ne\emptyset\), \(A\cap V\ne\emptyset\) and \((A\cap U)\cup(A\cap V)=A\). Choose \(a\in A\cap U\) and \(b\in A\cap V\). Assume \(a<b\). Let \(c=\sup\{t\in[a,b]:[a,t]\subset U\}\). Show that \(c\in A\), \(c\notin U\) and \(c\notin V\).

Solution. Let \(A\) be an interval, and suppose \(A\) is not connected. Then there are disjoint open sets \(U\) and \(V\) with \(A\cap U\ne\emptyset\), \(A\cap V\ne\emptyset\) and \((A\cap U)\cup(A\cap V)=A\). Choose \(a\in A\cap U\) and \(b\in A\cap V\). Since \(U\cap V=\emptyset\), \(a\ne b\). By switching the names of \(U\) and \(V\) if needed, assume \(a<b\). Since \(A\) is an interval, \([a,b]\subset A\).

Let \(S=\{t\in[a,b]:[a,t]\subset U\}\). Then \(a\in S\) and \(S\) is bounded above by \(b\). Let \(c=\sup S\). Then \(a\le c\le b\), so \(c\in A\). So \(c\in U\) or \(c\in V\).

Suppose \(c\in U\). Then \(c\ne b\), since \(b\in V\). Since \(U\) is open, there is an \(\varepsilon>0\) with \((c-\varepsilon,c+\varepsilon)\subset U\), and \(\varepsilon\) can be chosen with \(\varepsilon<b-c\). If \(c=a\), then \([a,c+\frac\varepsilon 2]\subset U\). If \(c>a\), there is a \(t\in S\) with \(c-\varepsilon<t\le c\), so \([a,t]\subset U\), and then \([a,c+\frac\varepsilon 2]\subset[a,t]\cup(c-\varepsilon,c+\varepsilon)\subset U\). Either way \(c+\frac\varepsilon 2\in S\), which contradicts \(c=\sup S\).

Suppose \(c\in V\). Then \(c\ne a\), since \(a\in U\). Since \(V\) is open, there is an \(\varepsilon>0\) with \((c-\varepsilon,c+\varepsilon)\subset V\), and \(\varepsilon\) can be chosen with \(\varepsilon<c-a\). Since \(c=\sup S\), there is a \(t\in S\) with \(c-\varepsilon<t\le c\). Then \(t\in[a,t]\subset U\) and \(t\in(c-\varepsilon,c+\varepsilon)\subset V\). This contradicts \(U\cap V=\emptyset\).

Both cases are impossible. So \(A\) is connected.

Exercise 4.2.2. Let \(S=\{x_n:n\in\mathbb{N}\}\cup\{a\}\), and let \(\mathcal{U}\) be an open cover of \(S\). So there exists a \(U_a\in\mathcal{U}\) such that \(a\in U_a\). Since \(U_a\) is open, there exists a \(\delta>0\) such that \((a-\delta,a+\delta)\subset U_a\). Since \(x_n\to a\), there exists an \(N\in\mathbb{N}\) such that for all \(n\geq N\), \(|x_n-a|<\delta\). So for all \(n\geq N\), \(x_n\in(a-\delta,a+\delta)\subset U_a\). Now for \(i=1,\dots, N-1\), there is a \(U_i\in\mathcal{U}\) such that \(x_i\in U_i\). So \(\{U_1,\dots,U_{N-1},U_a\}\) is a finite subcover of \(\mathcal{U}\) that covers \(S\). So \(S\) is compact.

Exercise 4.2.3. Hint. Use the Bolzano–Weierstrass Theorem (Theorem 3.4.5) and Theorem 4.2.15.

Solution. Let \(\{x_n\}\) be a sequence in \(K\). By Theorem 4.2.9, \(K\) is closed and bounded. Since \(K\) is bounded, so is \(\{x_n\}\). By the Bolzano–Weierstrass Theorem, there is a subsequence with \(x_{n_k}\to a\) for some \(a\in\mathbb{R}\). Each \(x_{n_k}\) is in \(K\), so \(a\in\overline{K}\) by Exercise 4.1.7. Since \(K\) is closed, \(\overline{K}=K\) by Theorem 4.1.26 (2). So \(a\in K\).

Exercise 4.2.7. Let \(F\) be one of the sets \(F_\alpha\) such that \(F\) is bounded. So \(F\) is closed and bounded. Therefore, by the Heine–Borel Theorem, \(F\) is compact. Now, assume by way of contradiction that \(\bigcap_{\alpha\in \Lambda}F_\alpha=\emptyset\). So \(\left(\bigcap_{\alpha\in \Lambda}F_\alpha\right)^c=\bigcup_{\alpha\in \Lambda}F_\alpha^c=\mathbb{R}\). Thus, \(F\subset\bigcup_{\alpha\in \Lambda}F_\alpha^c\). But since each \(F_\alpha\) is closed, each \(F_\alpha^c\) is open. So \(\{F_\alpha^c\}_{\alpha\in \Lambda}\) is an open cover of \(F\). Since \(F\) is compact, there exist \(\alpha_1,\dots,\alpha_n\) such that \(F\subset \bigcup_{i=1}^n F_{\alpha_i}^c\). So \(F\cap \left[\bigcap_{i=1}^n F_{\alpha_i}\right]=\emptyset\), a contradiction to the finite intersection property. So \(\bigcap_{\alpha\in \Lambda}F_\alpha\neq\emptyset\).

Let \(\mathcal{U}=\{[n,\infty)\}_{n\in\mathbb{N}}\). Then each element of \(\mathcal{U}\) is closed and unbounded, and every finite subcollection has nonempty intersection. But \(\bigcap_{n\in\mathbb{N}} [n,\infty)=\emptyset\).
