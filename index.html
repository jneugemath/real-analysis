Real Analysis

A Rigorous Treatment from First Principles to the Lebesgue Integral

Written for anyone who has finished calculus. No proofs course required.

Jeffrey T. Neugebauer

Version 0.1, October 2026

This is the web version of the book. It has the same text, numbering and figures as the PDF. Mathematics is rendered with MathJax, so it can be read aloud by a screen reader, enlarged, and explored one piece at a time. Right-click (or long-press) any formula for accessibility options.

This book is a living document. It will change over time, and the changes will be listed here. Please send corrections and suggestions with the corrections and suggestions form. If you use the book in a course, the form is also the way to be added to the Acknowledgments.

Versions

  • Version 0.1, October 2026. The first public version, posted for review and class testing. The PDF is 7 by 10 inches, the size of the planned print edition, so page numbers in the PDF and the printed book will match. Added October 22, 2026. Section 1.2 now ends with primes, Euclid's Lemma and the Fundamental Theorem of Arithmetic, with two new exercises, and Section 1.3 has a new Exercise 1.3.4. Example 10.1.5 shows that the harmonic series diverges, and Section 10.1 now has five exercises. Exercise 10.2.8 is a new problem. The new optional Section 10.5 gives Euler's proof that there are infinitely many primes. Pages after Chapter 1 moved by two, and pages after Chapter 10 by four.
