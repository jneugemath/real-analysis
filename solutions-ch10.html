Solutions for Chapter 10. Series of Real Numbers

Exercise 10.2.1. Hint. Write \(a_k=S_k-S_{k-1}\), where \(S_k\) is the \(k\)th partial sum.

Solution. Let \(s_n=\sum_{k=1}^na_k\), and suppose \(s_n\to s\). Let \(\varepsilon>0\). There is an \(N\in\mathbb{N}\) with \(|s_n-s|<\frac\varepsilon 2\) for all \(n\ge N\). Let \(k\ge N+1\). Then \(k-1\ge N\), and \(a_k=s_k-s_{k-1}\). So \[|a_k|=|(s_k-s)+(s-s_{k-1})|\le|s_k-s|+|s_{k-1}-s|<\frac\varepsilon 2+\frac\varepsilon 2=\varepsilon.\] So \(a_k\to0\). The second statement is the contrapositive of the first.

Exercise 10.2.3. Hint. In (1), \(\frac L2b_k<a_k<\frac{3L}2b_k\) for large \(k\). In (2), \(a_k<b_k\) for large \(k\). Use Theorem 10.2.7.

Solution.

  1. Let \(\varepsilon=\frac L2\). There is a \(K\in\mathbb{N}\) such that \(\left|\frac{a_k}{b_k}-L\right|<\frac L2\) for all \(k\ge K\). Since \(b_k>0\), this gives \[\frac L2b_k<a_k<\frac{3L}2b_k\quad\text{for all }k\ge K.\] If \(\sum b_k\) converges, then \(\sum a_k\) converges by the Comparison Test (Theorem 10.2.7), with \(M=\frac{3L}2\). If \(\sum a_k\) converges, then \(\sum b_k\) converges by the Comparison Test, since \(b_k<\frac2La_k\) for all \(k\ge K\).

  2. With \(\varepsilon=1\), there is a \(K\in\mathbb{N}\) with \(\frac{a_k}{b_k}<1\), that is, \(0<a_k<b_k\), for all \(k\ge K\). If \(\sum b_k\) converges, then \(\sum a_k\) converges by the Comparison Test, with \(M=1\).

Exercise 10.2.4. Hint. Use the series \(\sum\frac1k\) and \(\sum\frac1{k^2}\). To find \(\limsup\sqrt[k]{a_k}\), first show \(\sqrt[k]{k}\to1\). One way is to write \(\sqrt[k]{k}=1+h_k\) with \(h_k\ge0\) and use the Binomial Theorem to get \(k\ge\binom{k}{2}h_k^2\) for \(k\ge2\).

Solution. First, \(\sqrt[k]{k}\to1\). Since \(k\ge1\), \(\sqrt[k]{k}\ge1\). Write \(\sqrt[k]{k}=1+h_k\) with \(h_k\ge0\). For \(k\ge2\), every term in the Binomial Theorem (Exercise 9.3.3) is nonnegative. So \[k=(1+h_k)^k\ge\binom k2h_k^2=\frac{k(k-1)}2h_k^2.\] So \(0\le h_k^2\le\frac2{k-1}\). Let \(\varepsilon>0\). If \(k>1+\frac2{\varepsilon^2}\), then \(h_k^2<\varepsilon^2\), so \(h_k<\varepsilon\). So \(h_k\to0\), and \(\sqrt[k]{k}\to1\).

Now let \(a_k=\frac1k\). Then \(\sqrt[k]{a_k}=\frac{1}{\sqrt[k]{k}}\to1\). Let \(a_k=\frac1{k^2}\). Then \(\sqrt[k]{a_k}=\left(\frac{1}{\sqrt[k]{k}}\right)^2\to1\). In both cases the sequence \(\{\sqrt[k]{a_k}\}\) converges to \(1\), so \(\alpha=\limsup\sqrt[k]{a_k}=1\) by Corollary 3.6.14. But \(\sum\frac1k\) diverges and \(\sum\frac1{k^2}\) converges, by Example 10.2.12. So when \(\alpha=1\), the series may converge or diverge, and the Root Test gives no information.

Exercise 10.2.9. Hint. Use the identity \(2\sin\frac t2\cos kt=\sin\bigl((k+\frac12)t\bigr)-\sin\bigl((k-\frac12)t\bigr)\).

Solution. Since \(\{b_k\}\) decreases to \(0\), \(b_k\ge0\) for all \(k\). Let \(t\ne2p\pi\) for every \(p\in\mathbb{Z}\). Then \(\frac t2\) is not a multiple of \(\pi\), so \(\sin\frac t2\ne0\). Let \(A_n=\sum_{k=1}^n\cos kt\). By the identity \(\sin A\cos B=\frac12[\sin(A+B)+\sin(A-B)]\), with \(A=\frac t2\) and \(B=kt\), \[2\sin\frac t2\cos kt=\sin\left(\left(k+\frac12\right)t\right)-\sin\left(\left(k-\frac12\right)t\right).\] Adding over \(k=1,\dots,n\), the sum telescopes. So \[2\sin\frac t2\,A_n=\sin\left(\left(n+\frac12\right)t\right)-\sin\frac t2, \quad\text{and}\quad |A_n|\le\frac{2}{2\left|\sin\frac t2\right|}=\frac{1}{\left|\sin\frac t2\right|}.\] So the partial sums \(A_n\) are bounded. By the Dirichlet Test (Theorem 10.2.16) with \(a_k=\cos kt\), \(\sum b_k\cos kt\) converges.

Exercise 10.3.2. Hint. For large \(k\), \(|k^pa_k|\le|A|+1\). Compare with \(\sum\frac1{k^p}\).

Solution. With \(\varepsilon=1\), there is a \(K\in\mathbb{N}\) with \(|k^pa_k-A|<1\) for all \(k\ge K\). Then \(|k^pa_k|<|A|+1\), so \[0\le|a_k|\le\frac{|A|+1}{k^p}\quad\text{for all }k\ge K.\] Since \(p>1\), \(\sum\frac1{k^p}\) converges (Example 10.2.12). By the Comparison Test (Theorem 10.2.7) with \(M=|A|+1\), \(\sum|a_k|\) converges. So \(\sum a_k\) converges absolutely.

Exercise 10.3.3. Hint. Since \(a_k\to0\), eventually \(|a_k|\le1\) and \(a_k^2\le|a_k|\). For the example, try \(a_k=\frac{(-1)^k}{\sqrt k}\).

Exercise 10.3.4. Hint. Use \(a_k^++a_k^-=|a_k|\), \(a_k^+-a_k^-=a_k\) and \(0\le a_k^\pm\le|a_k|\).

Solution. If \(a_k\ge0\), then \(a_k^+=a_k\) and \(a_k^-=0\). If \(a_k<0\), then \(a_k^+=0\) and \(a_k^-=-a_k\). In both cases, \[a_k^++a_k^-=|a_k|,\quad a_k^+-a_k^-=a_k,\quad\text{and}\quad0\le a_k^\pm\le|a_k|.\]

(\(\Rightarrow\)) Suppose \(\sum|a_k|\) converges. Since \(0\le a_k^+\le|a_k|\), \(\sum a_k^+\) converges by the Comparison Test (Theorem 10.2.7). In the same way, \(\sum a_k^-\) converges.

(\(\Leftarrow\)) Suppose \(\sum a_k^+\) and \(\sum a_k^-\) converge. By Theorem 10.2.4 (2), \(\sum(a_k^++a_k^-)=\sum|a_k|\) converges. So \(\sum a_k\) converges absolutely.

In this case, by Theorem 10.2.4 (1) with \(c=-1\) and Theorem 10.2.4 (2), \[\sum a_k=\sum\bigl(a_k^+-a_k^-\bigr)=\sum a_k^+-\sum a_k^-.\]

Exercise 10.3.5. Hint. Modify the construction in the proof of Theorem 10.3.9. Add positive terms until the total passes \(1\), then one negative term. Then add positive terms until the total passes \(2\), then one negative term, and so on.

Exercise 10.4.1. For \(|x|<1\), \(\sum_{k=0}^\infty x^k\) converges absolutely to \(\frac1{1-x}\). The Cauchy product of this series with itself has terms \(c_n=\sum_{k=0}^nx^kx^{n-k}=(n+1)x^n\). By Theorem 10.4.2, \(\sum_{n=0}^\infty(n+1)x^n=\frac1{1-x}\cdot\frac1{1-x}=\frac1{(1-x)^2}\).

Exercise 10.4.2. Hint. \(|c_n|\le\sum_{k=0}^n|a_k||b_{n-k}|\), which is the \(n\)th term of the Cauchy product of \(\sum|a_k|\) and \(\sum|b_k|\).
