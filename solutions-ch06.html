Solutions for Chapter 6. Functions and Continuity

Exercise 6.1.1. Hint. (d) First show \(|\sqrt{x}-\sqrt{c}|=\dfrac{|x-c|}{\sqrt{x}+\sqrt{c}}\).

Solution.(a) Let \(\varepsilon>0\). Define \(\delta=\varepsilon\). Then for all \(x\) with \(0<|x-c|<\delta\), \(|k-k|=0<\varepsilon\). So \(\lim_{x\to c} k=k\).

(b) Let \(\varepsilon>0\). Define \(\delta=\varepsilon\). Then for all \(x\) with \(0<|x-c|<\delta\), \(|x-c|<\delta=\varepsilon\). So \(\lim_{x\to c} x=c\).

(c) Let \(\varepsilon>0\). Define \(\delta=\varepsilon\). Then, by the reverse triangle inequality, for all \(x\) with \(0<|x-c|<\delta\), \(\bigl||x|-|c|\bigr|\le |x-c|<\delta=\varepsilon\). So \(\lim_{x\to c} |x|=|c|\).

(d) Let \(\varepsilon>0\). Define \(\delta=\sqrt{c}\,\varepsilon\). Then for all \(x\ge0\) with \(0<|x-c|<\delta\), \[|\sqrt{x}-\sqrt{c}|=|\sqrt{x}-\sqrt{c}|\frac{\sqrt{x}+\sqrt{c}}{\sqrt{x}+\sqrt{c}}=\frac{|x-c|}{\sqrt{x}+\sqrt{c}}\le \frac{|x-c|}{\sqrt{c}}<\frac{\delta}{\sqrt{c}}=\varepsilon.\] So \(\lim_{x\to c} \sqrt{x}=\sqrt{c}\).

(e) Let \(\varepsilon>0\). Define \(\delta=\frac{\varepsilon}{6}\). Then for all \(x\) with \(0<|x-3|<\delta\), \[|(6x+7)-25|=|6x-18|=6|x-3|<6\delta=\varepsilon.\] So \(\lim_{x\to 3}(6x+7)=25\).

(f) Let \(\varepsilon>0\). Define \(\delta=\min\left\{1,\frac{\varepsilon}{10} \right\}\). Then for all \(x\) with \(0<|x-2|<\delta\), \[|(x^2+5x)-14|=|x+7||x-2|.\] Since \(|x-2|<\delta\le1\), \(-1<x-2<1\), and it follows that \(8<x+7<10\). So \(|x+7|<10\). Therefore, for all \(x\) with \(0<|x-2|<\delta\), \[|(x^2+5x)-14|=|x+7||x-2|<10|x-2|<10\delta\le\varepsilon.\] So \(\lim_{x\to2}(x^2+5x)=14\).

(g) Let \(\varepsilon>0\). Define \(\delta=\min\left\{\frac{1}{2}, \frac{23\varepsilon}{54}\right\}\). Then for all \(x\) with \(0<|x-4|<\delta\), \[\left|\frac{1}{x^2+5x-24}-\frac{1}{12}\right|=\left|\frac{x^2+5x-36}{12(x^2+5x-24)}\right|=\frac{|x+9||x-4|}{12|x+8||x-3|}.\] Since \(|x-4|<\delta\le\frac{1}{2}\), it follows that \(\frac{25}{2}<x+9<\frac{27}{2}\), \(\frac{23}{2}<x+8<\frac{25}{2}\), and \(\frac{1}{2}<x-3<\frac{3}{2}\). So \(|x+9|<\frac{27}{2}\), \(\frac{1}{|x+8|}<\frac{2}{23}\), and \(\frac{1}{|x-3|}<2\). Therefore, for all \(x\) with \(0<|x-4|<\delta\), \[\left|\frac{1}{x^2+5x-24}-\frac{1}{12}\right|<\frac{54|x-4|}{23\cdot12}<\frac{54|x-4|}{23}<\frac{54\delta}{23}\le\varepsilon.\] So \(\lim_{x\to 4} \frac{1}{x^2+5x-24}=\frac{1}{12}\).

(h) Let \(\varepsilon>0\). Define \(\delta=\min\left\{\frac{1}{2},\frac{\varepsilon}{2}\right\}\). Then for all \(x\) with \(0<|x-3|<\delta\), \[\left|\frac{1}{x-2}-1\right|=\frac{|x-3|}{|x-2|}.\] Since \(|x-3|<\delta\le\frac{1}{2}\), it follows that \(\frac{1}{2}<x-2<\frac{3}{2}\), and so \(\frac{1}{|x-2|}<2\). Therefore, for all \(x\) with \(0<|x-3|<\delta\), \[\left|\frac{1}{x-2}-1\right|=\frac{|x-3|}{|x-2|}<2|x-3|<2\delta\le\varepsilon.\] So \(\lim_{x\to3}\frac{1}{x-2}=1\).

Exercise 6.1.3. Let \(L>0\). Set \(\varepsilon=L/2>0\). Then there exists a \(\delta>0\) such that for all \(x\in E\) with \(0<|x-c|<\delta\), \(|f(x)-L|<L/2\). So for all such \(x\), \(f(x)-L>-L/2\), or \(f(x)>L/2>0\). If \(L<0\), apply this to \(-f\), which has limit \(-L>0\) by Theorem 6.1.13.

Exercise 6.1.5. (1) Let \(\varepsilon>0\). There exist \(\delta_1,\delta_2>0\) with \(|f(x)-L_1|<\frac\varepsilon 2\) for \(x\in E\) with \(0<|x-c|<\delta_1\), and \(|g(x)-L_2|<\frac\varepsilon 2\) for \(x\in E\) with \(0<|x-c|<\delta_2\). Let \(\delta=\min\{\delta_1,\delta_2\}\). For \(x\in E\) with \(0<|x-c|<\delta\), the Triangle Inequality gives \(|f(x)+g(x)-(L_1+L_2)|\le|f(x)-L_1|+|g(x)-L_2|<\varepsilon\).

(2) Since \(\lim_{x\to c}f(x)\) exists, by Lemma 6.1.12 there exists an \(M>0\) and a \(\delta_1>0\) such that for all \(x\) with \(0<|x-c|<\delta_1\), \(|f(x)|\le M\). Let \(\varepsilon>0\). Since \(\lim_{x\to c}f(x)=L_1\), there exists a \(\delta_2>0\) such that for all \(x\) with \(0<|x-c|<\delta_2\), \(|f(x)-L_1|<\frac{\varepsilon}{2(|L_2|+1)}\). Since \(\lim_{x\to c}g(x)=L_2\), there exists a \(\delta_3>0\) such that for all \(x\) with \(0<|x-c|<\delta_3\), \(|g(x)-L_2|<\frac{\varepsilon}{2M}\). Set \(\delta=\min\{\delta_1,\delta_2,\delta_3\}\). Then for all \(x\) with \(0<|x-c|<\delta\), \[\begin{aligned} |f(x)g(x)-L_1L_2|&=|f(x)g(x)-f(x)L_2+f(x)L_2-L_1L_2|\\ &\le |f(x)||g(x)-L_2|+|L_2||f(x)-L_1|\\ &< M\left(\frac{\varepsilon}{2M}\right)+|L_2|\left(\frac{\varepsilon}{2(|L_2|+1)}\right)<\varepsilon. \end{aligned}\] So \(\lim_{x\to c}f(x)g(x)=L_1L_2\). Throughout, \(x\) ranges over \(E\).

Exercise 6.1.8. (\(\Rightarrow\)) Let \(\varepsilon>0\). Then there exists a \(\delta>0\) such that for all \(x\) with \(0<|x-c|<\delta\), \(|f(x)-L|<\varepsilon\). So for all \(x\in(c-\delta,c)\) and for all \(x\in(c,c+\delta)\), \(|f(x)-L|<\varepsilon\). So \(\lim_{x\to c^-}f(x)=\lim_{x\to c^+}f(x)=L\).

(\(\Leftarrow\)) Let \(\varepsilon>0\). Then there exists a \(\delta_1>0\) such that for all \(x\) with \(0<x-c<\delta_{1}\), \(|f(x)-L|<\varepsilon\). Also, there exists a \(\delta_2>0\) such that for all \(x\) with \(-\delta_{2}<x-c<0\), \(|f(x)-L|<\varepsilon\). Set \(\delta=\min\{\delta_1,\delta_2\}\). Then for all \(x\) with \(0<|x-c|<\delta\), \(|f(x)-L|<\varepsilon\). So \(\lim_{x\to c}f(x)=L\).

Exercise 6.2.1. Let \(\varepsilon>0\). Define \(d=\frac{1}{\varepsilon}\). Then for all \(x\) with \(x>d\), \[\left|\frac{1}{x}-0\right|=\frac{1}{x}<\frac{1}{d}=\frac{1}{\frac{1}{\varepsilon}}=\varepsilon.\] So \(\lim_{x\to\infty}\frac{1}{x}=0\).

Exercise 6.2.3. Hint. For \(x>0\), \(\left|\frac{2x+1}{x+3}-2\right|=\frac{5}{x+3}<\frac5x\).

Solution. For \(x>0\), \[\left|\frac{2x+1}{x+3}-2\right|=\left|\frac{2x+1-2x-6}{x+3}\right|=\frac{5}{x+3}<\frac5x.\] Let \(\varepsilon>0\) and set \(d=\frac5\varepsilon\). If \(x>d\), then \(\left|\frac{2x+1}{x+3}-2\right|<\frac5x<\frac5d=\varepsilon\). By Definition 6.2.5, \(\lim_{x\to\infty}\frac{2x+1}{x+3}=2\).

Exercise 6.3.1. Hint. \(|x\sin\frac1x|\le|x|\).

Solution. By Definition 6.3.1, it is enough to show \(\lim_{x\to0}f(x)=f(0)=0\). Let \(\varepsilon>0\) and set \(\delta=\varepsilon\). If \(0<|x|<\delta\), then \[|f(x)-0|=|x|\left|\sin\frac1x\right|\le|x|<\delta=\varepsilon,\] since \(|\sin t|\le1\) for all \(t\). So \(\lim_{x\to0}f(x)=0=f(0)\), and \(f\) is continuous at \(0\).

Exercise 6.3.6. (\(\Rightarrow\)) Let \(O\) be an open set. For all \(x\in f^{-1}[O]\), \(f(x)\in O\), and so for all \(x\in f^{-1}[O]\), there exists an \(\varepsilon_x>0\) such that \((f(x)-\varepsilon_x,f(x)+\varepsilon_x)\subset O\). Since for all \(x\in f^{-1}[O]\subset E\), \(f\) is continuous at \(x\), there exists a \(\delta_x>0\) such that for all \(y\in E\) with \(|x-y|<\delta_x\), \(|f(x)-f(y)|<\varepsilon_x\). Set \(U=\bigcup_{x\in f^{-1}[O]}(x-\delta_x, x+\delta_x)\), an open set. If \(y\in E\cap U\), then \(y\in E\) and there exists an \(x\in f^{-1}[O]\) such that \(y\in(x-\delta_x,x+\delta_x)\). So \(f(y)\in(f(x)-\varepsilon_x,f(x)+\varepsilon_x)\subset O\). So \(y\in f^{-1}[O]\) and \(E\cap U\subset f^{-1}[O]\). Now let \(x\in f^{-1}[O]\). Then \(x\in U\). Also, since \(f^{-1}[O]\subset E\), \(x\in E\). So \(x\in E\cap U\). So \(f^{-1}[O]\subset E\cap U\) and \(f^{-1}[O]=E\cap U\).

(\(\Leftarrow\)) Let \(\varepsilon>0\). Let \(x\in E\). By the assumption, there exists an open set \(U\) such that \(f^{-1}[(f(x)-\varepsilon,f(x)+\varepsilon)]=E\cap U\). So \(x\in U\). Since \(U\) is open, there exists a \(\delta>0\) such that \((x-\delta,x+\delta)\subset U\). Thus, for all \(y\in E\) with \(|x-y|<\delta\), \(y\in E\cap U\). So \(f(y)\in (f(x)-\varepsilon, f(x)+\varepsilon)\). Thus, for all \(y\in E\) with \(|x-y|<\delta\), \(|f(x)-f(y)|<\varepsilon\). So \(f\) is continuous at \(x\). Since \(x\in E\) was arbitrary, \(f\) is continuous on all of \(E\).

Exercise 6.4.1. Let \(\varepsilon>0\). Define \(\delta=a^2\varepsilon\). Then for all \(x,y\in[a,\infty)\) with \(|x-y|<\delta\), \[|f(x)-f(y)|=\left|\frac{1}{x}-\frac{1}{y}\right|=\frac{|x-y|}{xy}\le \frac{|x-y|}{a^2}<\frac{\delta}{a^2}=\frac{a^2\varepsilon}{a^2}=\varepsilon.\] So \(f\) is uniformly continuous on \([a,\infty)\).

Exercise 6.4.2. Assume, by way of contradiction, that \(f\) is uniformly continuous on \(\mathbb{R}\). Let \(\varepsilon=1\). Then there exists a \(\delta>0\) such that for all \(x,y\in\mathbb{R}\) with \(|x-y|<\delta\), \(|f(x)-f(y)|=|x^2-y^2|<1\). Set \(x=\frac{1}{\delta}-\frac{\delta}{4}\) and \(y=\frac{1}{\delta}+\frac{\delta}{4}\). Then \(|x-y|=\frac{\delta}{2}<\delta\) but \(|x^2-y^2|=|x+y||x-y|=\frac{2}{\delta}\cdot\frac{\delta}{2}=1\), a contradiction. So \(f\) is not uniformly continuous on \(\mathbb{R}\).

Exercise 6.5.1. Suppose \(f^{-1}(a)=f^{-1}(b)\). Then, since \(f\) is a function, \(f(f^{-1}(a))=f(f^{-1}(b))\). So \(a=b\) and \(f^{-1}\) is one-to-one.

Exercise 6.5.2. Suppose \(a,b\in E\) with \(a\ne b\). Without loss of generality, \(a<b\). If \(f\) is strictly increasing, then \(f(a)<f(b)\). If \(f\) is strictly decreasing, then \(f(a)>f(b)\). Either way, \(f(a)\ne f(b)\). So \(f\) is one-to-one.

Exercise 6.6.1. Hint. For the Dirichlet function, every interval contains points where \(f\) is \(0\) and points where it is \(1\). For the step function, only intervals around \(0\) cause trouble.

Exercise 6.6.2. Let \(q_1,q_2,q_3,\dots\) be an enumeration of \(\mathbb{Q}\). Each set \(\mathbb{R}\setminus\{q_k\}\) is open, and \[\mathbb{R}\setminus\mathbb{Q}=\bigcap_{k=1}^\infty\bigl(\mathbb{R}\setminus\{q_k\}\bigr).\] So \(\mathbb{R}\setminus\mathbb{Q}\) is a \(G_\delta\) set.

If \(x=\frac mn\) in lowest terms, then \(x+1=\frac{m+n}n\) in lowest terms. So \(f(x+1)=f(x)\) for every \(x\). Near a point \(c\in(k,k+1)\) with \(k\in\mathbb{Z}\), \(f(x)=g(x-k)\), where \(g\) is Thomae’s function on \((0,1)\). By Example 6.3.2, \(f\) is continuous at \(c\) when \(c\) is irrational and not continuous at \(c\) when \(c\) is rational. At an integer \(k\), \(f(k)=1\), but every interval around \(k\) contains irrational numbers, where \(f=0\). So \(f\) is not continuous at \(k\). Thus \(f\) is continuous exactly at the irrational numbers, which agrees with Theorem 6.6.2.

Exercise 6.6.3. Suppose \(\mathbb{R}\) is countable, say \(\mathbb{R}=\{x_1,x_2,x_3,\dots\}\). Let \(V_k=\mathbb{R}\setminus\{x_k\}\). Each \(V_k\) is open. It is dense, since every open interval contains points other than \(x_k\). By Theorem 6.6.3, \(\bigcap_{k=1}^\infty V_k\) is not empty. But a point in it differs from every \(x_k\), so it is not in \(\mathbb{R}\). This is a contradiction.

Exercise 6.6.4. Hint. If \(G=\bigcap U_n\) is dense, then each \(U_n\) is dense. Apply Theorem 6.6.3 to all the \(U_n\) and \(V_n\) together. For the last part, add the sets \(\mathbb{R}\setminus\{g_k\}\), as in the proof of Theorem 6.6.4.

Exercise 6.6.5. Hint. If \(\mathbb{R}=\bigcup A_n\), apply Theorem 6.6.3 to \(U_n=\mathbb{R}\setminus\overline{A_n}\). For the Cantor set, an open interval longer than \(3^{-n}\) cannot lie inside \(C_n\).
