Accessibility

This book is written for anyone who has finished calculus. That includes readers who use a screen reader, a magnifier, a keyboard, or other assistive technology.

Standard

The web version of the book is designed to meet the Web Content Accessibility Guidelines (WCAG) 2.1 at Level AA. This is the standard used in the U.S. Department of Justice rule for public colleges and universities.

What the web version does

  • Every formula is displayed with MathJax, which gives screen readers a MathML copy to read aloud. Right-click or long-press a formula for speech, zoom and exploration options.
  • Every figure has a text description.
  • Every page has real headings, labeled navigation and a link to skip to the main content.
  • Everything works with a keyboard alone. A formula too wide for the screen can be focused and scrolled with the arrow keys.
  • Text has a contrast ratio of at least 7 to 1, in light mode and in dark mode.
  • Pages reflow down to a width of 320 pixels. A very long formula scrolls inside its own line, so the page never scrolls sideways.
  • The colors follow your system's light or dark setting.

How it was tested

In October 2026, every page was tested with the axe accessibility engine against the WCAG 2.1 Level A and AA rules, in light mode and in dark mode. No failures were found. Reflow at 320 pixels, keyboard access to scrolling formulas, and text contrast were also checked. A full manual review by an outside accessibility specialist has not been done yet. This page will be updated when it is.

Known limitations

  • The PDF is not tagged for screen readers. The web version has the same text, numbering and figures, and it is the accessible version of the book.
  • Screen readers differ in how well they read mathematics. Results can depend on the screen reader and the browser.
  • Some figure descriptions may be brief. If one does not help, please say so.

Report a problem

If any part of the book is hard to use, please report it on the book's GitHub page. You can also ask for the book in another format there. Every report will be read.
