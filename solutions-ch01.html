Solutions for Chapter 1. The Real Number System

Exercise 1.1.1. \(A\cup B=\{1,2,3,4,6,8\}\), \(A\cap C=\{3\}\), \(B\setminus C=\{2,4,8\}\), and \((A\cup B)^c=X\setminus(A\cup B)=\{5,7\}\). Since \(A^c=\{4,5,6,7,8\}\), \(A^c\cap C=\{6\}\).

Exercise 1.1.3. Let \(x\in(A\cap B)^c\). Then \(x\in X\) and \(x\notin A\cap B\). So \(x\notin A\) or \(x\notin B\). If \(x\notin A\), then \(x\in A^c\). If \(x\notin B\), then \(x\in B^c\). Either way, \(x\in A^c\cup B^c\). So \((A\cap B)^c\subset A^c\cup B^c\).

Now let \(x\in A^c\cup B^c\). If \(x\in A^c\), then \(x\notin A\), so \(x\notin A\cap B\). If \(x\in B^c\), then \(x\notin B\), so again \(x\notin A\cap B\). Either way, \(x\in(A\cap B)^c\). So \(A^c\cup B^c\subset(A\cap B)^c\). By Definition 1.1.3, \((A\cap B)^c=A^c\cup B^c\).

Exercise 1.1.5. Let \(x\in A\). Since \(A\subset B\), \(x\in B\). Since \(B\subset C\), \(x\in C\). So every element of \(A\) is an element of \(C\), and \(A\subset C\).

Exercise 1.1.7. Let \(A=\{1,2\}\), \(B=\{1\}\) and \(C=\{2\}\). Then \(A\cup B=\{1,2\}=A\cup C\), but \(B\ne C\).

Exercise 1.2.2. Let \(m\) be even and \(n\) be odd. Then \(m=2j\) and \(n=2k+1\) for some \(j,k\in\mathbb{Z}\). So \(m+n=2j+2k+1=2(j+k)+1\). Since \(j+k\in\mathbb{Z}\), \(m+n\) is odd.

Exercise 1.2.3. (\(\Rightarrow\)) Suppose \(n\) is odd. Then \(n=2k+1\) for some \(k\in\mathbb{Z}\). So \(n^2=4k^2+4k+1=2(2k^2+2k)+1\). Since \(2k^2+2k\in\mathbb{Z}\), \(n^2\) is odd.

(\(\Leftarrow\)) Use the contrapositive. Suppose \(n\) is not odd. By Corollary 1.2.13, \(n\) is even. By Theorem 1.2.5 (3), \(n^2=n\cdot n\) is even. By Corollary 1.2.13 again, \(n^2\) is not odd. So if \(n^2\) is odd, then \(n\) is odd.

Exercise 1.2.4. Hint. Write \(n=3q+r\) with \(r\in\{0,1,2\}\), and compute \(n^2\) in each case.

Exercise 1.2.6. For \(n=1\), the left side is \(1\) and the right side is \(\frac{1\cdot2\cdot3}{6}=1\). Now suppose the formula holds for some \(k\in\mathbb{N}\). Then \[\sum_{i=1}^{k+1}i^2=\frac{k(k+1)(2k+1)}{6}+(k+1)^2=\frac{(k+1)\bigl(2k^2+k+6k+6\bigr)}{6}=\frac{(k+1)(k+2)(2k+3)}{6}.\] This is the formula with \(n=k+1\), since \(k+2=(k+1)+1\) and \(2k+3=2(k+1)+1\). By the Principle of Mathematical Induction, the formula holds for all \(n\in\mathbb{N}\).

Exercise 1.2.9. For \(n=1\), \(2^1=2>1\). Now suppose \(2^k>k\) for some \(k\in\mathbb{N}\). Then \(2^{k+1}=2\cdot2^k>2k=k+k\ge k+1\), since \(k\ge1\). So \(2^{k+1}>k+1\). By the Principle of Mathematical Induction, \(2^n>n\) for all \(n\in\mathbb{N}\).

Exercise 1.2.10. Hint. For the inductive step, use \((k+1)!=(k+1)\,k!\) and \(k+1\ge2\).

Exercise 1.3.1. Hint. Use Exercise 1.2.4.

Exercise 1.3.2. Hint. Follow the proof of Theorem 1.3.4. If \(6n^2=m^2\), show that \(m\) and then \(n\) must be even.

Exercise 1.3.3. Define \(c=\frac{p+q}{2}\). Then \(c\in\mathbb{Q}\) and \(p<c<q\). Indeed, \(p+q\in\mathbb{Q}\), and the quotient of a rational number by \(2\) is rational. Since \(p<q\), \(2p=p+p<p+q\), so \(p<c\). Similarly \(p+q<q+q=2q\), so \(c<q\).

Exercise 1.4.2. Let \(\alpha=\inf E\) and \(\beta=\sup E\). Since \(E\ne\emptyset\), there is an \(x\in E\). Since \(\alpha\) is a lower bound of \(E\), \(\alpha\le x\). Since \(\beta\) is an upper bound of \(E\), \(x\le\beta\). If \(\alpha=x\) or \(x=\beta\), then \(\alpha\le\beta\) follows at once. Otherwise \(\alpha<x\) and \(x<\beta\), so \(\alpha<\beta\) by transitivity. Either way, \(\inf E\le\sup E\).

Exercise 1.4.3. Hint. To show \(1\) is the least upper bound, suppose \(q<1\) is an upper bound and find an \(n\) with \(1-\frac1n>q\).

(3) Since \(z>y\), \(z+(-y)>y+(-y)=0\). Thus \(x(z+(-y))>0\), implying \(xz=x(z+(-y))+xy>0+xy=xy\).

(4) Now \(-(x(z+(-y)))=(-x)(z+(-y))>0\), and so \(x(z+(-y))<0\). Thus \(xz=x(z+(-y))+xy<0+xy=xy\).

Exercise 1.5.7. Let \(E\subset\mathbb{F}\), where \(E\neq\emptyset\) and \(E\) is bounded below. Since \(\mathbb{F}\) is a field, for each \(x\in E\), \(-x\in\mathbb{F}\). Since \(E\ne\emptyset\), there is an \(x\in E\). So \(-x\in-E\) and \(-E\) is not empty. Since \(E\) is bounded below, there exists an \(\alpha\in\mathbb{F}\) such that for all \(x\in E\), \(\alpha\le x\). Again, since \(\mathbb{F}\) is a field, \(-\alpha\in\mathbb{F}\). Since for all \(x\in E\), \(\alpha\le x\), for all \(-x\in -E\), \(-x\le -\alpha\). So \(-\alpha\) is an upper bound of \(-E\). This proves (a). Since \(\mathbb{F}\) has the least upper bound property, \(\sup(-E)\in\mathbb{F}\), say \(\beta=\sup(-E)\).

For (b), first note that \(-\beta\) is a lower bound of \(E\). Indeed, if \(x\in E\), then \(-x\in-E\), so \(-x\le\beta\) and \(x\ge-\beta\). Suppose \(y>-\beta\). Then \(-y<\beta\) and so \(-y\) is not an upper bound of \(-E\), implying there exists a \(z\in -E\) with \(-y<z\). So \(y>-z\) and \(-z\in E\). Thus \(y\) is not a lower bound of \(E\). So \(-\beta=\inf E\).

Exercise 1.7.1. Hint. If \(x\ne0\), try \(\varepsilon=\frac{|x|}{2}\).

Solution. Suppose \(x\ne0\). Then \(|x|>0\) by Theorem 1.6.2 (1). Let \(\varepsilon=\frac{|x|}{2}>0\). By hypothesis, \(|x|\le\frac{|x|}{2}\). Subtracting \(\frac{|x|}{2}\) from both sides gives \(\frac{|x|}{2}\le0\), so \(|x|\le0\). This contradicts \(|x|>0\). So \(x=0\).

Exercise 1.7.3. Hint. Show \(-1\) is a lower bound. Then, for \(\varepsilon>0\), find an odd \(n\) with \(-\frac{n}{n+1}<-1+\varepsilon\).

Solution. First, \(-1\) is a lower bound of \(E\). If \(n\) is even, then \((-1)^n\frac{n}{n+1}=\frac{n}{n+1}\ge0>-1\). If \(n\) is odd, then \((-1)^n\frac{n}{n+1}=-\frac{n}{n+1}>-1\), since \(\frac{n}{n+1}<1\).

Now let \(\gamma>-1\), and set \(\varepsilon=\gamma+1>0\). By the Archimedean Principle (Theorem 1.7.8), there is an \(N\in\mathbb{N}\) with \(N>\frac1\varepsilon\). Let \(n=2N-1\), which is odd. Then \[(-1)^n\frac{n}{n+1}=-\frac{2N-1}{2N}=-1+\frac{1}{2N}<-1+\frac1N<-1+\varepsilon=\gamma.\] So \(\gamma\) is not a lower bound of \(E\). By Definition 1.4.4, \(\inf E=-1\).

Exercise 1.7.7. First, let \(u_0\in U\). Then for all \(l\in L\), \(l<u_0\). So \(u_0\) is an upper bound for \(L\), and since \(L\) is nonempty, \(L\) has a supremum in \(\mathbb{R}\). Similarly, let \(l_0\in L\). Then for all \(u\in U\), \(l_0<u\). So \(l_0\) is a lower bound for \(U\), and since \(U\) is nonempty, \(U\) has an infimum in \(\mathbb{R}\) by Exercise 1.5.7.

Now suppose \(\sup L\notin L\). So, since \(\mathbb{R}=L\cup U\), \(\sup L\in U\). Note for \(u\in U\), \(u>l\) for all \(l\in L\), so each \(u\in U\) is an upper bound of \(L\). So \(\sup L\leq u\) for all \(u\in U\). So \(\sup L\) is a lower bound of \(U\). Let \(k\) be a lower bound of \(U\). Since \(\sup L\in U\), \(k\leq \sup L\). Thus for any lower bound \(k\) of \(U\), \(k\leq \sup L\). So \(\sup L=\inf U\). Thus \(\inf U\in U\). So if \(\sup L\notin L\), then \(\inf U\in U\), which is what was to be proved.
