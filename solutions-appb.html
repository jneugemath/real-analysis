Solutions for Appendix B. Construction of the Real Numbers by Cauchy Sequences

Exercise B.1.1. Basic facts. By induction, each \(x_n\) is a positive rational number. Let \(d_n=x_n^2-2\). Then \(d_1=2\), and \[d_{n+1}=\frac{x_n^2}4+1+\frac1{x_n^2}-2=\Bigl(\frac{x_n}2-\frac1{x_n}\Bigr)^2=\frac{d_n^2}{4x_n^2}.\] So \(d_n\ge0\) for all \(n\), and \(d_n\ne0\) by Theorem 1.3.4. So \(x_n^2>2\) and \(x_n>1\). Also \(x_n-x_{n+1}=\frac{x_n}2-\frac1{x_n}=\frac{d_n}{2x_n}>0\). So \(\{x_n\}\) decreases, and \(1<x_n\le2\).

A bound. Since \(x_n^2>2\), \(d_{n+1}<\frac{d_n^2}8\). So if \(d_n\le2\), then \(d_{n+1}<\frac{d_n}4\). Since \(d_1=2\), induction gives \(d_n\le\frac2{4^{n-1}}\) for all \(n\). Thus \[0<x_n-x_{n+1}=\frac{d_n}{2x_n}<\frac{d_n}2\le\frac1{4^{n-1}}.\]

Cauchy. Let \(m>n\). By Exercise 1.2.7, \[0<x_n-x_m=\sum_{k=n}^{m-1}(x_k-x_{k+1})<\frac1{4^{n-1}}\sum_{j=0}^{m-n-1}\frac1{4^j}<\frac1{4^{n-1}}\cdot\frac43<\frac2n,\] since \(4^{n-1}\ge n\) by induction. Let \(\varepsilon>0\) be rational. By Lemma A.1.5, choose \(N\) with \(N\varepsilon>2\). Then \(|x_m-x_n|<\frac2N<\varepsilon\) for all \(m,n\ge N\). So \(\{x_n\}\) is a Cauchy sequence in \(\mathbb{Q}\).

No rational limit. Suppose \(L\in\mathbb{Q}\) and \(|x_n-L|\to0\). Since \(0<x_n\le2\), \[|x_n^2-L^2|=|x_n-L|\,|x_n+L|\le(2+|L|)\,|x_n-L|.\] So \(|x_n^2-L^2|\to0\). Also \(|x_n^2-2|=d_n\le\frac2{4^{n-1}}\le\frac2n\to0\). Since \(|L^2-2|\le|L^2-x_n^2|+|x_n^2-2|\) for every \(n\), \(|L^2-2|\) is less than every positive rational number. So \(L^2=2\), which contradicts Theorem 1.3.4.

Exercise B.1.2. Hint. Write \(x\) as the sum of the null sequence \(x-L\) and the constant sequence \(L\).

Exercise B.2.1. Example. Let \(x_n=\frac1n\). Then \(x\) is a null sequence, so \(x\in\mathcal{C}\), and \(x_n\ne0\). But \(\frac1{x_n}=n\), and \(|m-n|\ge1\) whenever \(m\ne n\). So \(\{n\}\) is not a Cauchy sequence.

The claim. Suppose \([x]\ne[0]\) and \(x_n\ne0\) for every \(n\). Then \(x\) is not null. By Lemma B.2.3, there are a rational \(c>0\) and an \(N\) with \(|x_n|\ge c\) for all \(n\ge N\). Let \(y_n=\frac1{x_n}\). As in the proof of Theorem B.2.4, \(|y_m-y_n|\le\frac{|x_m-x_n|}{c^2}\) for \(m,n\ge N\), so \(y\in\mathcal{C}\). Also \(x_ny_n=1\) for every \(n\), so \([x][y]=[1]\). By Theorem 1.5.5 (7), \([y]=[x]^{-1}\).

Exercise B.3.1. By Theorem 1.6.3 (3), \(\bigl||x_m|-|x_n|\bigr|\le|x_m-x_n|\). So \(|x|\in\mathcal{C}\). By Lemma B.3.2 (2), there are three cases.

If \(x\) is positive, then \([x]>[0]\), so \(\bigl|[x]\bigr|=[x]\). Also \(x_n\ge c>0\) for large \(n\), so \(|x_n|=x_n\) for large \(n\). Then \(|x|-x\) is eventually \(0\), so \(|x|\sim x\) and \(\bigl[|x|\bigr]=[x]\).

If \(x\) is null, then \([x]=[0]\), and \(|x|\) is null too. So both sides are \([0]\).

If \(-x\) is positive, then \([x]<[0]\), so \(\bigl|[x]\bigr|=-[x]=[-x]\). Also \(x_n\le-c<0\) for large \(n\), so \(|x_n|=-x_n\) for large \(n\). So \(\bigl[|x|\bigr]=[-x]\).

Exercise B.4.1. By Lemma B.4.1 (2), for each \(k\in\mathbb{N}\) there is a \(q_k\in\mathbb{Q}\) with \(a_k-\frac1k<q_k<a_k\). So \(|a_k-q_k|<\frac1k\).

The sequence \(q\) is in \(\mathcal{C}\). Let \(\varepsilon>0\) be rational. Choose \(K\) with \(K\varepsilon>3\) and with \(|a_m-a_n|<\frac\varepsilon 3\) for all \(m,n\ge K\). For \(m,n\ge K\), \[|q_m-q_n|\le|q_m-a_m|+|a_m-a_n|+|a_n-q_n|<\frac1m+\frac\varepsilon 3+\frac1n\le\varepsilon.\] This is an inequality between rational numbers that holds in \(\mathbb{R}\), so it holds in \(\mathbb{Q}\), by Theorem B.3.5. So \(q\in\mathcal{C}\). Let \(s=[q]\).

Convergence. Let \(\varepsilon>0\) be a real number. By Lemma B.4.1 (2), there is a rational \(\varepsilon'\) with \(0<\varepsilon'<\varepsilon\). By Lemma B.4.2, there is an \(N\) with \(|s-q_k|\le\frac{\varepsilon'}2\) for all \(k\ge N\). Choose \(N'\ge N\) with \(N'\varepsilon'>2\). For \(k\ge N'\), \[|a_k-s|\le|a_k-q_k|+|q_k-s|<\frac1k+\frac{\varepsilon'}2<\varepsilon'<\varepsilon.\] So \(a_k\to s\).

Exercise B.4.2. Hint. Choose \(q_1\) and then each \(q_{k+1}\) in \(\mathbb{Q}\) between \(\max\bigl\{q_k,a-\frac1{k+1}\bigr\}\) and \(a\), by Lemma B.4.1 (2).

Exercise B.5.1. Adding one. First, \((m+1)_\mathbb{F}=m_\mathbb{F}+1\) for every \(m\in\mathbb{Z}\). For \(m\ge0\) this is the definition. For \(m=-1\), \(0_\mathbb{F}=0=-1_\mathbb{F}+1\). For \(m=-n\) with \(n\ge2\), the definition gives \(n_\mathbb{F}=(n-1)_\mathbb{F}+1\), so \((m+1)_\mathbb{F}=-(n-1)_\mathbb{F}=-n_\mathbb{F}+1=m_\mathbb{F}+1\).

Sums. Fix \(m\in\mathbb{Z}\). By induction on \(k\in\mathbb{N}\), \((m+k)_\mathbb{F}=m_\mathbb{F}+k_\mathbb{F}\). The case \(k=1\) was just shown. If it holds for \(k\), then \[(m+k+1)_\mathbb{F}=(m+k)_\mathbb{F}+1=m_\mathbb{F}+k_\mathbb{F}+1=m_\mathbb{F}+(k+1)_\mathbb{F}.\] The case \(k=0\) is clear. If \(k=-n\) with \(n\in\mathbb{N}\), then \((m-n)_\mathbb{F}+n_\mathbb{F}=m_\mathbb{F}\) by the case just proved, applied to \(m-n\). So \((m-n)_\mathbb{F}=m_\mathbb{F}-n_\mathbb{F}=m_\mathbb{F}+(-n)_\mathbb{F}\). In particular, \((-j)_\mathbb{F}=-j_\mathbb{F}\) for every \(j\in\mathbb{Z}\).

Products. Fix \(m\in\mathbb{Z}\). By induction on \(k\in\mathbb{N}\), \((mk)_\mathbb{F}=m_\mathbb{F}\,k_\mathbb{F}\). For \(k=1\) this is clear. If it holds for \(k\), then \[(m(k+1))_\mathbb{F}=(mk+m)_\mathbb{F}=(mk)_\mathbb{F}+m_\mathbb{F}=m_\mathbb{F}\,k_\mathbb{F}+m_\mathbb{F}=m_\mathbb{F}\,(k+1)_\mathbb{F}.\] For \(k=0\) both sides are \(0\). If \(k=-n\) with \(n\in\mathbb{N}\), then \((m(-n))_\mathbb{F}=-(mn)_\mathbb{F}=-(m_\mathbb{F}\,n_\mathbb{F})=m_\mathbb{F}\,(-n)_\mathbb{F}\), by Theorem 1.5.5 (11).

Order. By induction, \(n_\mathbb{F}>0\) for every \(n\in\mathbb{N}\), since \(1>0\) (Theorem 1.5.8 (5)) and a sum of two positive elements is positive. If \(m<k\) in \(\mathbb{Z}\), then \(k-m\in\mathbb{N}\). So \(k_\mathbb{F}-m_\mathbb{F}=(k-m)_\mathbb{F}>0\), and \(m_\mathbb{F}<k_\mathbb{F}\).

Exercise B.5.2. Hint. Show \(\varphi(1)=1\), and then \(\varphi(q)=q\) for \(q\in\mathbb{Q}\). Every \(x\ge0\) is a square, so \(\varphi(x)\ge0\). Then compare the rational numbers below \(x\) and below \(\varphi(x)\), as in Section B.5.
