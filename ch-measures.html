The Riemann integral of Chapter 9 measures area by cutting \([a,b]\) into finitely many intervals. That works well for continuous functions and badly for limits. Lebesgue’s idea was to cut up the range of \(f\) instead, and measure the sets \(\{x:c<f(x)\le d\}\). Those sets need not be intervals. They can be complicated sets like the Cantor set or the rationals. So the first job is to assign a length, or measure, to sets far more general than intervals.

Which sets can be measured, and what rules should measure obey? This chapter answers both questions in general. A \(\sigma\)-algebra is a collection of sets that is closed under complements and countable unions. A measure is a function on a \(\sigma\)-algebra that adds up correctly over countably many disjoint pieces. Lebesgue measure on \(\mathbb{R}\), built in Chapter 14, is the main example. The same language is the foundation of probability theory. A probability space is a measure space whose total measure is \(1\).

What this chapter uses from Parts I and II. Sets and De Morgan’s Laws (Section 1.1), countable sets (Chapter 2), open and closed sets and the structure of open sets (Section 4.1), and series of nonnegative terms (Theorem 10.2.6).

13.1 Algebras and \(\sigma\)-Algebras

Throughout Part III, \(X\) denotes a nonempty set. For \(E\subset X\), the complement \(E^c\) means \(X\setminus E\). The power set \(\mathcal{P}(X)\) is the collection of all subsets of \(X\) (Definition 1.1.19).

Definition 13.1.1. Let \(X\) be a nonempty set. An algebra of sets on \(X\) is a nonempty collection \(\mathcal{A}\) of subsets of \(X\) such that

  1. if \(E_1,\dots,E_n\in\mathcal{A}\), then \(\bigcup^n_{i=1}E_i\in\mathcal{A}\); and

  2. if \(E\in\mathcal{A}\), then \(E^c\in\mathcal{A}\).

An algebra \(\mathcal{A}\) on a nonempty set \(X\) is a \(\sigma\)-algebra if for any sequence \(\{E_n\}_{n\in\mathbb{N}}\subset\mathcal{A}\), \(\bigcup_{n\in\mathbb{N}}E_n\in\mathcal{A}\).

The \(\sigma\) stands for “sum,” an old word for union. An algebra is closed under finite unions. A \(\sigma\)-algebra is closed under countable unions.

Proposition 13.1.2. An algebra \(\mathcal{A}\) on a nonempty set \(X\) has the property that if \(E_1,\dots,E_n\in\mathcal{A}\), then \(\bigcap^n_{i=1}E_i\in\mathcal{A}\). Similarly, a \(\sigma\)-algebra is closed under countable intersections.

Proof. Using De Morgan’s law, \(\bigcap_{i=1}^nE_i=\left(\bigcup_{i=1}^nE_i^c\right)^c\). Since \(\mathcal{A}\) is an algebra, \(E_i^c\in\mathcal{A}\) for each \(i=1,\dots,n\), implying \(\bigcup_{i=1}^nE_i^c\in\mathcal{A}\). Therefore, \(\left(\bigcup_{i=1}^nE_i^c\right)^c\in\mathcal{A}\). So \(\bigcap_{i=1}^nE_i\in\mathcal{A}\). The countable case is the same, using Theorem 1.1.14 for a countable family.

∎

Remark 13.1.3. If \(\mathcal{A}\) is an algebra on a nonempty set \(X\), then \(\emptyset,X\in\mathcal{A}\). Indeed, since \(\mathcal{A}\) is nonempty, there is an \(E\in\mathcal{A}\), implying \(E^c\in\mathcal{A}\). So \(E\cap E^c=\emptyset\in\mathcal{A}\). Thus \(\emptyset^c=X\in\mathcal{A}\). Also, if \(E,F\in\mathcal{A}\), then \(E\setminus F=E\cap F^c\in\mathcal{A}\).

Theorem 13.1.4. An algebra \(\mathcal{A}\) is a \(\sigma\)-algebra if \(\{F_n\}_{n\in\mathbb{N}}\subset\mathcal{A}\) with \(F_i\cap F_j=\emptyset\) for all \(i\ne j\in\mathbb{N}\) implies \(\bigcup_{n\in\mathbb{N}}F_n\in\mathcal{A}\).

Proof. Suppose \(\{E_n\}_{n\in\mathbb{N}}\subset\mathcal{A}\). Set \[F_k=E_k\setminus\left[\bigcup_{i=1}^{k-1}E_i\right]=E_k\cap\left[\bigcup_{i=1}^{k-1} E_i\right]^c.\] Since \(E_i\in\mathcal{A}\), \(i=1,\dots,k-1\), \(\bigcup_{i=1}^{k-1} E_i\in\mathcal{A}\) and since \(\mathcal{A}\) is an algebra, \(\left[\bigcup_{i=1}^{k-1} E_i\right]^c\in\mathcal{A}\). Thus \(F_k\in\mathcal{A}\). Now the sets \(F_k\) are pairwise disjoint. So \(\bigcup_{n\in\mathbb{N}}F_n\in\mathcal{A}\). But \(\bigcup_{n\in\mathbb{N}}F_n=\bigcup_{n\in\mathbb{N}}E_n\). So \(\bigcup_{n\in\mathbb{N}}E_n\in\mathcal{A}\) and \(\mathcal{A}\) is a \(\sigma\)-algebra.

To see the two claims about the sets \(F_k\), note that \(F_k\) is the set of points of \(E_k\) that are in none of the earlier sets \(E_1,\dots,E_{k-1}\). If \(j<k\), then \(F_k\cap E_j=\emptyset\), and \(F_j\subset E_j\), so \(F_j\cap F_k=\emptyset\). Each \(F_n\subset E_n\), so \(\bigcup F_n\subset\bigcup E_n\). If \(x\in\bigcup E_n\), let \(k\) be the smallest index with \(x\in E_k\). Then \(x\in F_k\).

∎

Proof Technique (Making Sets Disjoint).

Measures add up correctly over disjoint sets. So many proofs start by replacing a sequence \(E_1,E_2,\dots\) with disjoint sets that have the same union. Take \(F_1=E_1\) and \(F_k=E_k\setminus(E_1\cup\cdots\cup E_{k-1})\). Each new set keeps only the points not already covered. The union does not change, \(F_k\subset E_k\), and the sets \(F_k\) are disjoint. If the sets increase, \(E_1\subset E_2\subset\cdots\), this simplifies to \(F_k=E_k\setminus E_{k-1}\). The proofs of Theorems 13.1.4 and 13.3.9 use this trick.

Example 13.1.5. If \(X\) is a nonempty set, \(\mathcal{P}(X)\) and \(\{\emptyset,X\}\) are \(\sigma\)-algebras.

Proof. \(\mathcal{P}(X)\) contains every subset of \(X\). The complement of any subset of \(X\) is a subset of \(X\) and the union of countably many subsets of \(X\) is a subset of \(X\), so \(\mathcal{P}(X)\) is closed under complements and countable unions. Since \(X^c=\emptyset\), \(\emptyset^c=X\), and \(X\cup\emptyset=X\), \(\{\emptyset,X\}\) is a \(\sigma\)-algebra.

∎

Example 13.1.6. If \(X\) is uncountable, then \[\mathcal{A}=\{E\subset X: E\text{ is countable or }E^c\text{ is countable}\}\] is a \(\sigma\)-algebra, called the \(\sigma\)-algebra of countable or co-countable sets. Here “countable” means at most countable, so finite sets are included.

Proof. Let \(E\in\mathcal{A}\). If \(E\) is countable, then \((E^c)^c=E\) is countable and so \(E^c\in\mathcal{A}\). If \(E^c\) is countable, then \(E^c\in\mathcal{A}\) directly. Let \(\{E_n\}_{n\in\mathbb{N}}\subset \mathcal{A}\). If \(E_n\) is countable for all \(n\in\mathbb{N}\), then \(\bigcup_{n\in\mathbb{N}}E_n\) is countable (Theorem 2.2.6) and so \(\bigcup_{n\in\mathbb{N}}E_n\in\mathcal{A}\). If there exists an \(n_0\in\mathbb{N}\) with \(E_{n_0}\) uncountable, then \(E_{n_0}^c\) is countable and \[\left(\bigcup_{n\in\mathbb{N}}E_n\right)^c=\bigcap_{n\in\mathbb{N}}E_n^c\subset E_{n_0}^c.\] A subset of a countable set is countable. Therefore, \(\left(\bigcup_{n\in\mathbb{N}}E_n\right)^c\) is countable. So \(\bigcup_{n\in\mathbb{N}}E_n\in\mathcal{A}\).

∎

Proof Technique (Showing a Collection Is a \(\sigma\)-Algebra).

There are three things to check. The collection is nonempty, usually by showing \(X\) or \(\emptyset\) is in it. It is closed under complements. It is closed under countable unions. Check each one directly from the definition of the collection, as in Example 13.1.6. For the union, it is often easier to check disjoint unions, or increasing unions, and then use Theorem 13.1.4 or Exercise 13.1.3. Closure under intersections and differences then comes for free, by Proposition 13.1.2 and Remark 13.1.3.

Lemma 13.1.7. The intersection of a family of \(\sigma\)-algebras on a set \(X\) is a \(\sigma\)-algebra.

Proof. See Exercise 13.1.1.

∎

Lemma 13.1.7 gives a way to build \(\sigma\)-algebras. Start with any collection \(\mathcal{E}\) of subsets of \(X\). There is at least one \(\sigma\)-algebra containing \(\mathcal{E}\), namely \(\mathcal{P}(X)\). The intersection of all of them is a \(\sigma\)-algebra that contains \(\mathcal{E}\), and it is contained in every \(\sigma\)-algebra that contains \(\mathcal{E}\). So it is the smallest one.

Definition 13.1.8. If \(\mathcal{E}\subset\mathcal{P}(X)\), the smallest \(\sigma\)-algebra containing \(\mathcal{E}\), denoted \(\sigma(\mathcal{E})\), is called the \(\sigma\)-algebra generated by \(\mathcal{E}\). That is, \(\sigma(\mathcal{E})\) is the intersection of all \(\sigma\)-algebras on \(X\) that contain \(\mathcal{E}\).

Example 13.1.9. Let \(X=\{a,b,c\}\). For \(\mathcal{E}_1=\{\{a\}\}\), \(\sigma(\mathcal{E}_1)=\{\emptyset,\{a\},\{b,c\},X\}\). For \(\mathcal{E}_2=\{\{a\},\{b\}\}\), \(\sigma(\mathcal{E}_2)=\mathcal{P}(X)\).

Proof. If \(\{a\}\in\sigma(\mathcal{E}_1)\), then \(\{a\}^c=\{b,c\}\in\sigma(\mathcal{E}_1)\). So \(\{a\}\cup\{b,c\}=X\in\sigma(\mathcal{E}_1)\) and \(X^c=\emptyset\in\sigma(\mathcal{E}_1)\). So \(\sigma(\mathcal{E}_1)\) contains \(\{\emptyset,\{a\},\{b,c\},X\}\). This collection is itself a \(\sigma\)-algebra, since it is closed under complements and unions. So \(\sigma(\mathcal{E}_1)=\{\emptyset,\{a\},\{b,c\},X\}\).

If \(\{a\},\{b\}\in\sigma(\mathcal{E}_2)\), then \(\{a\}\cup\{b\}=\{a,b\}\in\sigma(\mathcal{E}_2)\). Then \(\{a,b\}^c=\{c\}\in\sigma(\mathcal{E}_2)\). Also, \(\{a\}^c=\{b,c\}\in\sigma(\mathcal{E}_2)\) and \(\{b\}^c=\{a,c\}\in\sigma(\mathcal{E}_2)\). Lastly, \(\{a,b\}\cup\{c\}=X\in\sigma(\mathcal{E}_2)\), implying \(X^c=\emptyset\in\sigma(\mathcal{E}_2)\). So every subset of \(X\) is in \(\sigma(\mathcal{E}_2)\), and \(\sigma(\mathcal{E}_2)=\mathcal{P}(X)\).

∎

Proposition 13.1.10. If \(\mathcal{E}\subset\mathcal{P}(X)\), \(\sigma(\mathcal{E})\) is unique.

Proof. Assume \(\mathcal{M}_1\) and \(\mathcal{M}_2\) are two smallest \(\sigma\)-algebras containing \(\mathcal{E}\). Then by Lemma 13.1.7, \(\mathcal{M}_1\cap\mathcal{M}_2\) is a \(\sigma\)-algebra containing \(\mathcal{E}\). But \(\mathcal{M}_1\cap\mathcal{M}_2\subset\mathcal{M}_1\) and \(\mathcal{M}_1\cap\mathcal{M}_2\subset\mathcal{M}_2\). Since \(\mathcal{M}_1\) and \(\mathcal{M}_2\) are both smallest \(\sigma\)-algebras containing \(\mathcal{E}\), \(\mathcal{M}_1\cap\mathcal{M}_2=\mathcal{M}_1\) and \(\mathcal{M}_1\cap\mathcal{M}_2=\mathcal{M}_2\). Thus \(\mathcal{M}_1=\mathcal{M}_2\).

∎

Lemma 13.1.11. If \(\mathcal{E}\subset\sigma(\mathcal{F})\), then \(\sigma(\mathcal{E})\subset\sigma(\mathcal{F})\).

Proof. \(\sigma(\mathcal{F})\) is a \(\sigma\)-algebra containing \(\mathcal{E}\). Therefore, it must contain the smallest \(\sigma\)-algebra containing \(\mathcal{E}\), \(\sigma(\mathcal{E})\).

∎

Proof Technique (The Good Sets Principle).

How can a statement be proved for every set in \(\sigma(\mathcal{E})\), when nobody can list those sets? Let \(\mathcal{G}\) be the collection of “good” sets, the sets for which the statement is true. Show two things. First, \(\mathcal{G}\) is a \(\sigma\)-algebra. Second, \(\mathcal{E}\subset\mathcal{G}\). Then \(\sigma(\mathcal{E})\subset\mathcal{G}\), because \(\sigma(\mathcal{E})\) is the smallest \(\sigma\)-algebra containing \(\mathcal{E}\). So every set in \(\sigma(\mathcal{E})\) is good. Lemma 13.1.11 is the special case where the good sets are the sets in \(\sigma(\mathcal{F})\). This argument appears again and again in Part III. For example, it shows that every Borel set is Lebesgue measurable.

Definition 13.1.12. A family of sets \(\mathcal{R}\subset\mathcal{P}(X)\) is called a ring if \(E_1,\dots,E_n\in\mathcal{R}\) implies \(\bigcup^{n}_{i=1}E_i\in\mathcal{R}\), and if \(E,F\in\mathcal{R}\), then \(E\setminus F\in\mathcal{R}\). A ring that is closed under countable unions is called a \(\sigma\)-ring.

Proposition 13.1.13. Let \(\mathcal{R}\) be a ring on a set \(X\).

  1. \(\mathcal{R}\) is closed under finite intersections. Similarly, if \(\mathcal{R}\) is a \(\sigma\)-ring, \(\mathcal{R}\) is closed under countable intersections.

  2. If \(\mathcal{R}\) is a \(\sigma\)-ring, then \(\mathcal{R}\) is a \(\sigma\)-algebra if and only if \(X\in\mathcal{R}\).

  3. If \(\mathcal{R}\) is a \(\sigma\)-ring, then \(\{E\subset X:E\cap F\in\mathcal{R}\text{ for all }F\in\mathcal{R}\}\) is a \(\sigma\)-algebra.

Proof. See Exercise 13.1.2.

∎

13.2 Borel Sets

On \(\mathbb{R}\) the most important \(\sigma\)-algebra is the one generated by the open sets. Every set that can be built from open sets by countably many unions, intersections and complements is in it. Chapter 14 shows that Lebesgue measure assigns a length to every such set.

Definition 13.2.1. If \(X=\mathbb{R}\), the \(\sigma\)-algebra generated by the family of open sets in \(\mathbb{R}\) is called the Borel \(\sigma\)-algebra and is denoted \(\mathcal{B}_\mathbb{R}\). The members of \(\mathcal{B}_\mathbb{R}\) are called Borel sets. \(\mathcal{B}_\mathbb{R}\) thus contains open sets, closed sets, countable intersections of open sets, countable unions of closed sets, and so forth.

Definition 13.2.2. A countable intersection of open sets is called a \(G_\delta\) set, a countable union of closed sets is called an \(F_\sigma\) set, a countable union of \(G_\delta\) sets is called a \(G_{\delta\sigma}\) set, a countable intersection of \(F_\sigma\) sets is called an \(F_{\sigma\delta}\) set, and so forth.

Example 13.2.3. Every countable subset of \(\mathbb{R}\) is an \(F_\sigma\) set, since it is a countable union of one-point sets, which are closed. In particular, \(\mathbb{Q}\) is an \(F_\sigma\) set. Its complement, the set of irrational numbers, is a \(G_\delta\) set, by De Morgan’s Laws. A half-open interval \((a,b]\) is both, since \((a,b]=\bigcap_{n\in\mathbb{N}}\left(a,b+\frac1n\right)\) and \((a,b]=\bigcup_{n\in\mathbb{N}}\left[a+\frac1n,b\right]\). All of these sets are Borel sets.

Example 13.2.4. If \(f:\mathbb{R}\to\mathbb{R}\), the set of points at which \(f\) is continuous is a \(G_\delta\).

Proof. See Exercise 13.2.1, or Theorem 6.6.2 in the starred Section 6.6.

∎

Theorem 13.2.5. \(\mathcal{B}_\mathbb{R}\) is generated by each of the following:

  1. the open intervals \(\mathcal{E}_1=\{(a,b):a<b\}\);

  2. the closed intervals \(\mathcal{E}_2=\{[a,b]:a<b\}\);

  3. the half open intervals \(\mathcal{E}_3=\{(a,b]:a<b\}\) or \(\mathcal{E}_4=\{[a,b):a<b\}\);

  4. the open rays \(\mathcal{E}_5=\{(a,\infty):a\in\mathbb{R}\}\) or \(\mathcal{E}_6=\{(-\infty,a):a\in\mathbb{R}\}\); and

  5. the closed rays \(\mathcal{E}_7=\{[a,\infty):a\in\mathbb{R}\}\) or \(\mathcal{E}_8=\{(-\infty,a]:a\in\mathbb{R}\}\).

Proof. We will show \(\mathcal{B}_\mathbb{R}=\sigma(\mathcal{E}_i)\), \(i=1,\dots,8\). First, note that the elements of \(\mathcal{E}_1\), \(\mathcal{E}_2\), \(\mathcal{E}_5\), \(\mathcal{E}_6\), \(\mathcal{E}_7\), and \(\mathcal{E}_8\) are open or closed, so they are Borel sets. Since \((a,b]=\bigcap_{n\in\mathbb{N}}\left(a,b+\frac{1}{n}\right)\) and \([a,b)=\bigcap_{n\in\mathbb{N}}\left(a-\frac{1}{n},b\right)\), all elements of \(\mathcal{E}_3\) and \(\mathcal{E}_4\) are \(G_\delta\) sets. So \(\mathcal{E}_i\subset\mathcal{B}_\mathbb{R}\) for \(i=1,\dots,8\), and so by Lemma 13.1.11, \(\sigma(\mathcal{E}_i)\subset \mathcal{B}_\mathbb{R}\) for \(i=1,\dots,8\).

Now by Theorem 4.1.12, every open set is a countable union of open intervals, so by Lemma 13.1.11, \(\mathcal{B}_\mathbb{R}\subset\sigma(\mathcal{E}_1)\). Some of these intervals may be unbounded. But \((a,\infty)=\bigcup_{n\in\mathbb{N}}(a,a+n)\), \((-\infty,b)=\bigcup_{n\in\mathbb{N}}(b-n,b)\) and \(\mathbb{R}=\bigcup_{n\in\mathbb{N}}(-n,n)\), so every open interval is in \(\sigma(\mathcal{E}_1)\).

Since \((a,b)=\bigcup_{n\in\mathbb{N}}\left[a+\frac{1}{n},b-\frac{1}{n}\right]\), \(\mathcal{E}_1\subset\sigma(\mathcal{E}_2)\). So \(\mathcal{B}_\mathbb{R}\subset\sigma(\mathcal{E}_2)\). (Here only the \(n\) with \(a+\frac1n<b-\frac1n\) are used.)

Since \((a,b)=\bigcup_{n\in\mathbb{N}}\left(a,b-\frac{1}{n}\right]\) and \((a,b)=\bigcup_{n\in\mathbb{N}}\left[a+\frac{1}{n},b\right)\), \(\mathcal{E}_1\subset\sigma(\mathcal{E}_3)\) and \(\mathcal{E}_1\subset\sigma(\mathcal{E}_4)\). So \(\mathcal{B}_\mathbb{R}\subset\sigma(\mathcal{E}_3)\) and \(\mathcal{B}_\mathbb{R}\subset\sigma(\mathcal{E}_4)\).

Now \((a,b]=(a,\infty)\cap(b,\infty)^c\) and \([a,b)=(-\infty,a)^c\cap(-\infty,b)\), and so \(\mathcal{E}_3\subset\sigma(\mathcal{E}_5)\) and \(\mathcal{E}_4\subset\sigma(\mathcal{E}_6)\). So \(\mathcal{B}_\mathbb{R}\subset\sigma(\mathcal{E}_5)\) and \(\mathcal{B}_\mathbb{R}\subset\sigma(\mathcal{E}_6)\).

Lastly, \([a,b)=[a,\infty)\cap[b,\infty)^c\) and \((a,b]=(-\infty,a]^c\cap(-\infty,b]\), and so \(\mathcal{E}_4\subset\sigma(\mathcal{E}_7)\) and \(\mathcal{E}_3\subset\sigma(\mathcal{E}_8)\). So \(\mathcal{B}_\mathbb{R}\subset\sigma(\mathcal{E}_7)\) and \(\mathcal{B}_\mathbb{R}\subset\sigma(\mathcal{E}_8)\).

∎

13.3 Measures

A measure assigns a size to each set in a \(\sigma\)-algebra. It must give the empty set size \(0\), and it must add up over countably many disjoint sets. Sizes may be infinite. So a measure takes values in \([0,\infty]\), with the usual conventions. For \(a\in[0,\infty]\), \(a+\infty=\infty+a=\infty\), and \(a\le\infty\). A series \(\sum a_n\) of terms in \([0,\infty]\) always has a sum in \([0,\infty]\). It is \(\infty\) if some \(a_n=\infty\) or if the partial sums are not bounded (Theorem 10.2.6), and otherwise it is the usual sum.

Definition 13.3.1. Let \(X\) be a set with \(\sigma\)-algebra \(\mathcal{M}\). A measure on \(\mathcal{M}\) (or on \((X,\mathcal{M})\) or on \(X\) if \(\mathcal{M}\) is understood) is a function \(\mu:\mathcal{M}\to[0,\infty]\) such that

  1. \(\mu(\emptyset)=0\); and

  2. if \(\{E_n\}_{n\in\mathbb{N}}\) is a sequence of pairwise disjoint sets in \(\mathcal{M}\), then \(\mu\left(\bigcup_{n\in\mathbb{N}}E_n\right)=\sum_{n\in\mathbb{N}}\mu(E_n)\).

Property (2) is called countable additivity.

Definition 13.3.2. If \(\mu\) is a measure on \((X,\mathcal{M})\), \((X,\mathcal{M},\mu)\) is called a measure space and the sets in \(\mathcal{M}\) are called measurable sets. If \(\mu(X)=1\), then \(\mu\) is a probability measure and \((X,\mathcal{M},\mu)\) is a probability space.

Remark 13.3.3. A measure is also finitely additive. If \(E_1,\dots,E_n\in\mathcal{M}\) are disjoint, set \(E_k=\emptyset\) for \(k>n\). Then countable additivity and \(\mu(\emptyset)=0\) give \(\mu\left(\bigcup_{k=1}^nE_k\right)=\sum_{k=1}^n\mu(E_k)\).

Definition 13.3.4. Let \((X,\mathcal{M},\mu)\) be a measure space. If \(\mu(X)<\infty\), \(\mu\) is called finite. If \(X=\bigcup_{n\in\mathbb{N}}E_n\), where \(E_n\in\mathcal{M}\) and \(\mu(E_n)<\infty\) for all \(n\in\mathbb{N}\), \(\mu\) is called \(\sigma\)-finite. If \(E\in\mathcal{M}\) with \(E=\bigcup_{n\in\mathbb{N}}E_n\), where \(E_n\in\mathcal{M}\) and \(\mu(E_n)<\infty\) for all \(n\in\mathbb{N}\), \(E\) is called \(\sigma\)-finite for \(\mu\). If for each \(E\in\mathcal{M}\) with \(\mu(E)=\infty\), there exists an \(F\in\mathcal{M}\) with \(F\subset E\) and \(0<\mu(F)<\infty\), \(\mu\) is called semifinite.

Example 13.3.5. Let \(X\ne\emptyset\), \(\mathcal{M}=\mathcal{P}(X)\), and \(f:X\to[0,\infty]\) be a function. Then for \(E\in\mathcal{M}\), define \(\mu(E)=\sum_{x\in E} f(x)\). (Note: \(\sum_{x\in E} f(x)=\sup\{\sum_{x\in F} f(x):F\subset E\text{ is finite}\}\).) Then \(\mu\) is a measure. \(\mu\) is semifinite if and only if \(f(x)<\infty\) for all \(x\in X\). \(\mu\) is \(\sigma\)-finite if and only if \(\mu\) is semifinite and \(\{x:f(x)>0\}\) is countable. See Exercise 13.3.1.

Example 13.3.6. In Example 13.3.5, if \(f(x)=1\) for all \(x\in X\), \(\mu\) is called counting measure. Then \(\mu(E)\) is the number of elements of \(E\) if \(E\) is finite, and \(\mu(E)=\infty\) if \(E\) is infinite. If, for some \(x_0\in X\), \(f(x_0)=1\) and \(f(x)=0\) for all \(x\ne x_0\), \(\mu\) is called the Dirac measure at \(x_0\). Then \(\mu(E)=1\) if \(x_0\in E\) and \(\mu(E)=0\) if \(x_0\notin E\).

Example 13.3.7. Flip a fair coin twice. The set of possible outcomes is \[X=\{HH,HT,TH,TT\}.\] Let \(\mathcal{M}=\mathcal{P}(X)\) and let \(P(E)\) be the number of elements of \(E\) divided by \(4\). This is Example 13.3.5 with \(f(x)=\frac14\) for every \(x\). So \((X,\mathcal{M},P)\) is a probability space. The event “at least one head” is the set \(E=\{HH,HT,TH\}\), and \(P(E)=\frac34\).

Example 13.3.8. Let \(X\) be an uncountable set and let \(\mathcal{M}\) be the \(\sigma\)-algebra of countable or co-countable sets. Then the function \(\mu\) on \(\mathcal{M}\) defined by \(\mu(E)=0\) if \(E\) is countable and \(\mu(E)=1\) if \(E\) is co-countable is a measure.

Proof. Since \(\emptyset\) is countable, \(\mu(\emptyset)=0\). No set is both countable and co-countable, since then \(X=E\cup E^c\) would be countable. So \(\mu\) is well defined.

Next, suppose \(E,F\in\mathcal{M}\) where \(E\) and \(F\) are both co-countable. Then \((E\cap F)^c=E^c\cup F^c\) is countable, and so \((E\cap F)^c\ne X\). Thus \(E\cap F\ne\emptyset\).

Now, let \(\{E_n\}_{n\in\mathbb{N}}\) be a sequence of disjoint sets in \(\mathcal{M}\). By the previous argument, at most one element of \(\{E_n\}_{n\in\mathbb{N}}\) can be co-countable. If this is the case, call that element \(E_{n_0}\). Then \(\mu(E_{n_0})=1\) and \(\mu(E_n)=0\) for all \(n\ne n_0\). By the proof of Example 13.1.6, \(\bigcup_{n\in\mathbb{N}}E_n\) is co-countable and so \(\mu\left(\bigcup_{n\in\mathbb{N}}E_n\right)=1\). Thus \(\mu\left(\bigcup_{n\in\mathbb{N}}E_n\right)=1=\sum_{n\in\mathbb{N}}\mu(E_n)\).

If \(E_n\) is countable for all \(n\in\mathbb{N}\), then \(\bigcup_{n\in\mathbb{N}}E_n\) is countable, and \(\mu\left(\bigcup_{n\in\mathbb{N}}E_n\right)=0=\sum_{n\in\mathbb{N}}\mu(E_n)\).

∎

Theorem 13.3.9. Let \((X,\mathcal{M},\mu)\) be a measure space.

  1. (Monotonicity) If \(E,F\in\mathcal{M}\) with \(E\subset F\), then \(\mu(E)\le\mu(F)\).

  2. (Subadditivity) If \(\{E_n\}_{n\in\mathbb{N}}\subset\mathcal{M}\), then \(\mu\left(\bigcup_{n\in\mathbb{N}}E_n\right)\le\sum_{n\in\mathbb{N}}\mu(E_n)\).

  3. (Continuity from below) If \(\{E_n\}_{n\in\mathbb{N}}\subset\mathcal{M}\) and \(E_1\subset E_2\subset\cdots\), then \(\mu\left(\bigcup_{n\in\mathbb{N}}E_n\right)=\lim_{n\to\infty}\mu(E_n)\).

  4. (Continuity from above) If \(\{E_n\}_{n\in\mathbb{N}}\subset\mathcal{M}\), \(E_1\supset E_2\supset\cdots\), and \(\mu(E_1)<\infty\), then \(\mu\left(\bigcap_{n\in\mathbb{N}}E_n\right)=\lim_{n\to\infty}\mu(E_n)\).

Proof.

  1. Write \(F=E\cup(F\setminus E)\), a disjoint union of sets in \(\mathcal{M}\). By finite additivity, \(\mu(F)=\mu(E)+\mu(F\setminus E)\ge\mu(E)\).

  2. Make the sets disjoint. Let \(F_1=E_1\) and \(F_k=E_k\setminus\bigcup_{i=1}^{k-1}E_i\) for \(k\ge2\). As in the proof of Theorem 13.1.4, the sets \(F_k\) are in \(\mathcal{M}\), they are disjoint, \(F_k\subset E_k\), and \(\bigcup F_k=\bigcup E_k\). By countable additivity and (1), \[\mu\left(\bigcup_{n\in\mathbb{N}}E_n\right)=\sum_{k\in\mathbb{N}}\mu(F_k)\le\sum_{k\in\mathbb{N}}\mu(E_k).\]

  3. Let \(E_0=\emptyset\) and \(F_k=E_k\setminus E_{k-1}\) for \(k\in\mathbb{N}\). These sets are disjoint, \(\bigcup_{k=1}^nF_k=E_n\) for each \(n\), and \(\bigcup_{k\in\mathbb{N}}F_k=\bigcup_{n\in\mathbb{N}}E_n\). So \[\mu\left(\bigcup_{n\in\mathbb{N}}E_n\right)=\sum_{k=1}^\infty\mu(F_k)=\lim_{n\to\infty}\sum_{k=1}^n\mu(F_k)=\lim_{n\to\infty}\mu(E_n),\] using finite additivity in the last step.

  4. Let \(F_n=E_1\setminus E_n\). Then \(F_1\subset F_2\subset\cdots\) and \(\bigcup_{n\in\mathbb{N}}F_n=E_1\setminus\bigcap_{n\in\mathbb{N}}E_n\). By (3), \[\mu\left(E_1\setminus\bigcap_{n\in\mathbb{N}}E_n\right)=\lim_{n\to\infty}\mu(E_1\setminus E_n).\] If \(A\subset E_1\) and \(A\in\mathcal{M}\), then \(\mu(E_1)=\mu(A)+\mu(E_1\setminus A)\), and all three numbers are finite, since \(\mu(E_1)<\infty\). So \(\mu(E_1\setminus A)=\mu(E_1)-\mu(A)\). Using this with \(A=\bigcap E_n\) and with \(A=E_n\), \[\mu(E_1)-\mu\left(\bigcap_{n\in\mathbb{N}}E_n\right)=\mu(E_1)-\lim_{n\to\infty}\mu(E_n).\] Subtracting \(\mu(E_1)\) from both sides gives the result.

In (3) and (4), the limits exist in \([0,\infty]\), since \(\{\mu(E_n)\}\) is monotone by (1).

∎

The hypothesis \(\mu(E_1)<\infty\) in (4) cannot be dropped. Let \(\mu\) be counting measure on \(\mathbb{N}\), and let \(E_n=\{n,n+1,n+2,\dots\}\). Then \(\mu(E_n)=\infty\) for every \(n\), but \(\bigcap_{n\in\mathbb{N}}E_n=\emptyset\). It is enough that \(\mu(E_n)<\infty\) for some \(n\). Start the sequence there.

Chapter 14 asks whether there is a measure \(m\) on a \(\sigma\)-algebra containing every interval, with \(m(I)\) equal to the length of \(I\) for every interval \(I\). The answer is yes. But Section 14.4 shows that such a measure cannot be defined on every subset of \(\mathbb{R}\), if it is also unchanged by translation. That is why measures are defined on \(\sigma\)-algebras and not on all of \(\mathcal{P}(X)\).

Notes

Émile Borel’s 1898 book assigned lengths to the sets that can be built from intervals by countable unions and complements [7]. Henri Lebesgue’s 1902 thesis turned this into a theory of measure and integration [41]. The notation \(G_\delta\) and \(F_\sigma\) is due to Felix Hausdorff [36]. The \(G\) stands for Gebiet, a German word for an open set, and the \(F\) for fermé, French for closed. The \(\delta\) and \(\sigma\) stand for the German words Durchschnitt (intersection) and Summe (union). Maurice Fréchet defined measures on abstract sets in 1915 [31]. Andrey Kolmogorov based probability theory on measure theory in 1933 [39]. The lemma in Exercise 13.3.7 is named for Émile Borel, who used it in probability in 1909, and Francesco Paolo Cantelli, who stated it in general in 1917.
