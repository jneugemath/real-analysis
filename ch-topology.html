Chapter 3 asked which points a sequence gets close to. This chapter asks the same question about sets. An open set is a set in which every point has some room around it. A closed set is a set that contains every point it gets close to. These ideas are called the topology of \(\mathbb{R}\).

The most important idea in the chapter is compactness. A set is compact if every open cover of it can be cut down to a finite one. That sounds abstract. What it does is turn a fact that holds near each point into a fact that holds on the whole set. The main result, Theorem 4.2.15, says a subset of \(\mathbb{R}\) is compact exactly when it is closed and bounded. Chapter 6 uses compactness to prove that a continuous function on \([a,b]\) is uniformly continuous.

4.1 Open and Closed Sets

Every point of an open interval \((a,b)\) has a little room on both sides that stays inside the interval. An open set is any set with this property. A closed set is the complement of an open set.

Definition 4.1.1. A set \(U\subset \mathbb{R}\) is said to be open if for all \(x\in U\), there exists an \(\varepsilon(x)>0\) such that \((x-\varepsilon,x+\varepsilon)\subset U\).

The notation \(\varepsilon(x)\) is a reminder that \(\varepsilon\) may depend on \(x\). Points near the edge of \(U\) usually need a smaller \(\varepsilon\).

Definition 4.1.2. Let \(E\subset \mathbb{R}\). A point \(x\in E\) is said to be an interior point of \(E\) if there exists an \(\varepsilon>0\) such that \((x-\varepsilon,x+\varepsilon)\subset E\). The set of interior points of \(E\) is denoted \(E^\circ\).

Theorem 4.1.3. A set \(U\subset \mathbb{R}\) is open if and only if \(U=U^\circ\).

Proof. See Exercise 4.1.1.

∎

Proof Technique (Proving a Set Is Open).

To prove a set \(U\) is open, start with an arbitrary \(x\in U\). Then find an \(\varepsilon>0\) that works for that \(x\). The choice of \(\varepsilon\) is allowed to depend on \(x\). A good first guess is the distance from \(x\) to the nearest point outside \(U\), or a fraction of it. Then check that every \(y\) with \(|y-x|<\varepsilon\) is in \(U\). Example 4.1.4 does this for \((0,1)\). There, \(\varepsilon\) is half the distance from \(x\) to the nearer endpoint.

Example 4.1.4. The set \((0,1)\) is open. By letting \(x\in(0,1)\) and defining \(\varepsilon=\min\left\{\frac{x}{2},\frac{1-x}{2}\right\}\), \[x-\varepsilon\ge x-\frac{x}{2}=\frac{x}{2}>0,\] and \[x+\varepsilon\le x+\frac{1-x}{2}=\frac{1+x}{2}<1.\] So \((x-\varepsilon,x+\varepsilon)\subset(0,1)\) and \((0,1)\) is open. See Figure 4.1.

Example 4.1.5. If \(E=(0,42]\), \(E^\circ=(0,42)\). The point \(42\) is not an interior point, since every interval \((42-\varepsilon,42+\varepsilon)\) contains numbers greater than \(42\).

Example 4.1.6. If \(E=\left\{\frac{1}{n}:n\in\mathbb{N}\right\}\), \(E^\circ=\emptyset\). Every interval \((x-\varepsilon,x+\varepsilon)\) contains an irrational number by Exercise 1.8.5, and \(E\) has no irrational numbers. So no point of \(E\) is an interior point.

Theorem 4.1.7. Every open interval in \(\mathbb{R}\) is an open subset of \(\mathbb{R}\).

Proof. See Exercise 4.1.2.

∎

By Definition 1.8.6, \((a,b)\) is called an open interval only when \(a<b\) are real numbers. The sets \((a,\infty)\), \((-\infty,b)\) and \((-\infty,\infty)=\mathbb{R}\) are called unbounded open intervals. They are also open sets. See Exercise 4.1.4 and Example 4.1.16.

Families of sets \(\{A_\alpha\}_{\alpha\in\Lambda}\) and index sets were defined in Definition 1.1.12. The index set \(\Lambda\) can be finite, countable or uncountable.

Example 4.1.8. An enumeration of a set \(S\) gives an index set \(J\subset \mathbb{N}\).

Example 4.1.9. Any countable set can be indexed by \(\mathbb{N}\).

Example 4.1.10. Uncountable sets can also be used to index. For example, with \(U_x=(x-1,x+1)\), \(\mathbb{R}\) is the index set of the collection \(\{U_x\}_{x\in\mathbb{R}}\).

Theorem 4.1.11.

  1. If \(\{U_\alpha\}_{\alpha\in\Lambda}\) is a collection of open subsets of \(\mathbb{R}\), then \(\bigcup_{\alpha\in\Lambda}U_\alpha\) is open.

  2. If \(\{U_1,\dots,U_n\}\) is a finite collection of open subsets of \(\mathbb{R}\), then \(\bigcap_{i=1}^n U_i\) is open.

Proof.

  1. Let \(x\in \bigcup_{\alpha\in\Lambda} U_\alpha\). So there exists an \(\alpha_0\in\Lambda\) such that \(x\in U_{\alpha_0}\). Since \(U_{\alpha_0}\) is open, there exists an \(\varepsilon>0\) such that \[(x-\varepsilon,x+\varepsilon)\subset U_{\alpha_0}\subset\bigcup_{\alpha\in\Lambda} U_\alpha.\] So \(\bigcup_{\alpha\in\Lambda} U_\alpha\) is open.

  2. Let \(x\in\bigcap_{i=1}^n U_i\). So \(x\in U_i\) for \(i=1,\dots,n\). Since each \(U_i\) is open, there exists an \(\varepsilon_i>0\) such that \((x-\varepsilon_i,x+\varepsilon_i)\subset U_i\) for \(i=1,\dots,n\). Set \(\varepsilon=\min\{\varepsilon_1,\dots,\varepsilon_n\}>0\). Then \((x-\varepsilon,x+\varepsilon)\subset U_i\) for \(i=1,\dots,n\), implying \((x-\varepsilon,x+\varepsilon)\subset \bigcap_{i=1}^n U_i\). So \(\bigcap_{i=1}^n U_i\) is open.

∎

Part (2) needs the collection to be finite. The proof takes the minimum of \(\varepsilon_1,\dots,\varepsilon_n\). The minimum of finitely many positive numbers is positive, but infinitely many positive numbers can have infimum \(0\). Example 4.1.18 gives infinitely many open sets whose intersection is not open.

Theorem 4.1.12. Every nonempty open set of real numbers is the union of an at most countable collection of disjoint open intervals, bounded or unbounded.

Proof.

Let \(U\subset\mathbb{R}\) be a nonempty open set, and let \(x\in U\). Since \(U\) is open, there exists an \(\varepsilon>0\) with \((x-\varepsilon,x+\varepsilon)\subset U\). Let \[a_x=\inf\{z<x:(z,x)\subset U\}\quad\text{and}\quad b_x=\sup\{y>x:(x,y)\subset U\}.\] These sets are nonempty, since \(x-\varepsilon\) is in the first one and \(x+\varepsilon\) is in the second one. If the first set is not bounded below, \(a_x=-\infty\). If the second set is not bounded above, \(b_x=\infty\). (See Remark 3.6.7.) So \(a_x\le x-\varepsilon<x<x+\varepsilon\le b_x\). Let \(I_x=(a_x,b_x)\). It is an open interval, possibly unbounded, and \(x\in I_x\).

First, \(I_x\subset U\). Let \(w\in I_x\). If \(w=x\), then \(w\in U\). Suppose \(x<w<b_x\). Since \(w\) is less than the supremum \(b_x\), \(w\) is not an upper bound of \(\{y>x:(x,y)\subset U\}\). So there exists a \(y>w\) with \((x,y)\subset U\). Thus \(w\in(x,y)\subset U\). The case \(a_x<w<x\) is similar.

Second, if \(b_x\) is a real number, then \(b_x\notin U\). Suppose \(b_x\in U\). Since \(U\) is open, there exists a \(\delta>0\) with \((b_x-\delta,b_x+\delta)\subset U\). Since \((x,b_x)\subset I_x\subset U\), this gives \((x,b_x+\delta)\subset U\). So \(b_x+\delta\) is in the set whose supremum is \(b_x\), a contradiction. In the same way, if \(a_x\) is a real number, then \(a_x\notin U\).

Third, \(U=\bigcup_{x\in U}I_x\). Each \(x\in U\) lies in \(I_x\), and each \(I_x\) is a subset of \(U\).

Fourth, any two of the intervals \(I_x\) are either equal or disjoint. Suppose \(I_x=(a,b)\) and \(I_y=(c,d)\) have a point \(w\) in common. Suppose \(a<c\). Then \(c\) is a real number and \(a<c<w<b\). So \(c\in I_x\subset U\). But \(c\notin U\) by the second step, a contradiction. So \(c\le a\). Switching the roles of \(I_x\) and \(I_y\) gives \(a\le c\). So \(a=c\). The same argument gives \(b=d\). Thus \(I_x=I_y\).

Last, the collection of distinct intervals \(I_x\) is at most countable. Each of them contains a rational number by Theorem 1.8.11. Choose one rational number in each of them. Since distinct intervals are disjoint, distinct intervals get distinct rational numbers. So the collection is in one-to-one correspondence with a subset of \(\mathbb{Q}\). Since \(\mathbb{Q}\) is countable by Corollary 2.2.7, the collection is at most countable by Theorem 2.2.4.

∎

Corollary 4.1.13. Every nonempty open set of real numbers is the union of an at most countable collection of open intervals.

Proof. From the proof of Theorem 4.1.12, each open set is the disjoint union of open intervals. But an open interval \((a,\infty)=\bigcup_{n\in\mathbb{Z}, n>a}(a,n)\) and an open interval \((-\infty,b)=\bigcup_{n\in\mathbb{Z}, n<b}(n,b)\). Also, \((-\infty,\infty)=\bigcup_{n\in\mathbb{N}}(-n,n)\). So each open set is the union of a countable collection of open intervals. The collection is at most countable by Theorem 2.2.6.

∎

Theorem 4.1.14 (Lindelöf).

Let \(\{U_\alpha\}_{\alpha\in \Lambda}\) be a collection of open sets of real numbers. Then there is a countable subcollection \(\{U_n\}_{n\in\mathbb{N}}\) of \(\{U_\alpha\}_{\alpha\in \Lambda}\) such that \(\bigcup_{\alpha\in \Lambda}U_\alpha=\bigcup_{n\in\mathbb{N}}U_n\).

Proof.

Let \(U=\bigcup_{\alpha\in \Lambda}U_\alpha\). If \(U=\emptyset\), then every \(U_\alpha\) is empty, and any one of them, repeated, works. So assume \(U\ne\emptyset\).

Let \(\mathcal{J}\) be the collection of open intervals \((p,q)\) with \(p,q\in\mathbb{Q}\) and \(p<q\). Each interval in \(\mathcal{J}\) is determined by its endpoints. So sending the interval \((p,q)\) to the ordered pair \((p,q)\) gives a one-to-one map from \(\mathcal{J}\) into \(\mathbb{Q}\times\mathbb{Q}\). Since \(\mathbb{Q}\sim\mathbb{N}\) by Corollary 2.2.7, \(\mathbb{Q}\times\mathbb{Q}\sim\mathbb{N}\times\mathbb{N}\), which is countable by Theorem 2.2.1. So \(\mathcal{J}\) is at most countable by Theorem 2.2.4.

Let \(\mathcal{J}_0\) be the collection of \(J\in\mathcal{J}\) such that \(J\subset U_\alpha\) for some \(\alpha\in\Lambda\). For each \(J\in\mathcal{J}_0\), choose one \(\alpha_J\in\Lambda\) with \(J\subset U_{\alpha_J}\). Then \[\bigcup_{J\in\mathcal{J}_0}U_{\alpha_J}\subset U.\] Now let \(x\in U\). Then \(x\in U_\alpha\) for some \(\alpha\in\Lambda\). Since \(U_\alpha\) is open, there exists an \(\varepsilon>0\) such that \((x-\varepsilon,x+\varepsilon)\subset U_\alpha\). By Theorem 1.8.11, there exist \(p,q\in\mathbb{Q}\) with \(x-\varepsilon<p<x<q<x+\varepsilon\). Then \(J=(p,q)\subset U_\alpha\), so \(J\in\mathcal{J}_0\). Thus \(x\in J\subset U_{\alpha_J}\). So \[U=\bigcup_{J\in\mathcal{J}_0}U_{\alpha_J}.\] The collection \(\mathcal{J}_0\) is nonempty and at most countable. So the sets \(U_{\alpha_J}\), \(J\in\mathcal{J}_0\), can be listed as \(U_1,U_2,U_3,\dots\), repeating sets if there are only finitely many. Then \(U=\bigcup_{n\in\mathbb{N}}U_n\).

∎

Definition 4.1.15. A set \(F\subset \mathbb{R}\) is said to be closed if \(F^c=\mathbb{R}\setminus F\) is open.

The empty set satisfies the definition of an open set because the condition is vacuously true. See the Vacuous Truth box in Section 1.1.

Example 4.1.16. \(\mathbb{R}\) and \(\emptyset\) are both open and closed. Let \(x\in\mathbb{R}\). Then \((x-1,x+1)\subset\mathbb{R}\). So \(\mathbb{R}\) is open. So \(\emptyset=\mathbb{R}^c\) is closed.

Now, let \(x\in\emptyset\). So for \(\varepsilon=1\), \((x-1,x+1)\subset\emptyset\). This is vacuously true, since there is no \(x\in\emptyset\). So \(\emptyset\) is open. Thus \(\mathbb{R}=\emptyset^c\) is closed.

“Closed” does not mean “not open.” The sets \(\mathbb{R}\) and \(\emptyset\) are both. The interval \([0,1)\) is neither. It is not open, since every interval \((-\varepsilon,\varepsilon)\) around \(0\) contains negative numbers. It is not closed, since its complement contains \(1\) and every interval \((1-\varepsilon,1+\varepsilon)\) contains points of \([0,1)\).

Theorem 4.1.17.

  1. If \(\{F_\alpha\}_{\alpha\in\Lambda}\) is a collection of closed subsets of \(\mathbb{R}\), then \(\bigcap_{\alpha\in \Lambda}F_\alpha\) is closed.

  2. If \(\{F_1,\dots,F_n\}\) is a finite collection of closed subsets of \(\mathbb{R}\), then \(\bigcup_{i=1}^n F_i\) is closed.

Proof. This follows directly from Theorem 4.1.11 and De Morgan’s Laws (Theorem 1.1.14) and is an exercise.

∎

Proof Technique (Using Complements).

Every statement about closed sets is a statement about open sets in disguise. To prove something about a closed set \(F\), look at the open set \(F^c\). De Morgan’s Laws turn the complement of a union into an intersection of complements. So facts about unions of open sets become facts about intersections of closed sets. Exercise 4.1.5 uses this idea to prove Theorem 4.1.17.

Example 4.1.18. Let \(U_n=\left(-\frac{1}{n},\frac{1}{n}\right)\). Then \(\bigcap_{n=1}^\infty U_n=\{0\}\) is closed. To see the intersection is \(\{0\}\), notice \(0\in U_n\) for all \(n\). If \(x\ne0\), then by the Archimedean Principle (Theorem 1.8.8) there is an \(n\in\mathbb{N}\) with \(\frac1n<|x|\), and \(x\notin U_n\). So an intersection of infinitely many open sets need not be open.

Example 4.1.19. Let \(G_n=\left(0,1+\frac{1}{n}\right)\). Then \(\bigcap_{n=1}^\infty G_n=(0,1]\). This set is neither open nor closed.

Definition 4.1.20. Let \(E\subset \mathbb{R}\).

  1. A point \(a\in\mathbb{R}\) is called a limit point of \(E\) if for all \(\varepsilon>0\), there exists an \(x\in E\), \(x\ne a\), with \(|x-a|<\varepsilon\).

  2. A point \(a\in E\) is called an isolated point of \(E\) if it is not a limit point.

Example 4.1.21. \((0,1)\) has limit points \([0,1]\).

Example 4.1.22. \(\left\{\frac{1}{n}:n\in\mathbb{N}\right\}\) has limit point \(0\). Every point of this set is an isolated point.

A limit point of \(E\) does not have to be in \(E\), as both examples show. A limit point of a set is also not the same as a cluster point of a sequence (Definition 3.6.1). The constant sequence \(x_n=1\) has cluster point \(1\). The set \(\{x_n:n\in\mathbb{N}\}=\{1\}\) has no limit points.

Theorem 4.1.23. Let \(E\subset \mathbb{R}\). The point \(a\in\mathbb{R}\) is a limit point of \(E\) if and only if there exists a sequence \(\{x_n\}\) in \(E\) with \(x_n\ne a\) for all \(n\in\mathbb{N}\) such that \(\lim_{n\to\infty} x_n=a\).

Proof. (\(\Rightarrow\)) Let \(a\) be a limit point of \(E\). Then for all \(n\in\mathbb{N}\), there exists an \(x_n\in E\) such that \(x_n\ne a\) and \(|x_n-a|<\frac{1}{n}\). Then by the Squeeze Theorem (Theorem 3.2.10), \(x_n\to a\).

(\(\Leftarrow\)) Suppose there exists a sequence \(\{x_n\}\) in \(E\) with \(x_n\ne a\) for all \(n\in\mathbb{N}\) such that \(\lim_{n\to\infty} x_n=a\). Let \(\varepsilon>0\). Then there exists an \(N\in\mathbb{N}\) such that for all \(n\ge N\), \(|x_n-a|<\varepsilon\). In particular, \(x_N\in E\), \(x_N\ne a\), and \(|x_N-a|<\varepsilon\). So \(a\) is a limit point of \(E\).

∎

Theorem 4.1.24. The set \(F\subset \mathbb{R}\) is closed if and only if \(F\) contains all of its limit points.

Proof. (\(\Rightarrow\)) Let \(F\) be closed. Then \(F^c\) is open. So if \(x\in F^c\), there exists an \(\varepsilon>0\) such that \((x-\varepsilon,x+\varepsilon)\subset F^c\). So \((x-\varepsilon,x+\varepsilon)\cap F=\emptyset\), and therefore \(x\) is not a limit point of \(F\). So \(F\) contains all of its limit points.

(\(\Leftarrow\)) Let \(F\subset \mathbb{R}\) be a set that contains all of its limit points. Let \(x\in F^c\). Since \(F\) contains all of its limit points, \(x\) is not a limit point of \(F\). So there exists an \(\varepsilon>0\) such that \((x-\varepsilon,x+\varepsilon)\cap F=\emptyset\). So \((x-\varepsilon,x+\varepsilon)\subset F^c\) and \(F^c\) is open. So \(F\) is closed.

∎

Definition 4.1.25. For \(E\subset \mathbb{R}\), \(E'\) denotes the set of limit points of \(E\). The closure of \(E\), \(\overline{E}\), is \[\overline{E}=E\cup E'.\]

Theorem 4.1.26. If \(E\subset\mathbb{R}\), then

  1. \(\overline{E}\) is closed;

  2. \(E=\overline{E}\) if and only if \(E\) is closed; and

  3. \(\overline{E}\subset F\) for every closed set \(F\subset \mathbb{R}\) such that \(E\subset F\).

Proof.

  1. Let \(x\in\overline{E}^c\). Then \(x\notin E\) and \(x\) is also not a limit point of \(E\). Thus there exists an \(\varepsilon>0\) such that \((x-\varepsilon,x+\varepsilon)\cap E=\emptyset\).

    Assume by way of contradiction that \((x-\varepsilon,x+\varepsilon)\cap E'\ne\emptyset\). So there exists a \(y\in(x-\varepsilon,x+\varepsilon)\cap E'\). So \(y\) is a limit point of \(E\). Since \((x-\varepsilon,x+\varepsilon)\) is open, there exists a \(\delta>0\) such that \((y-\delta,y+\delta)\subset(x-\varepsilon,x+\varepsilon)\). But since \(y\in E'\), \((y-\delta,y+\delta)\cap E\ne\emptyset\), a contradiction. So \((x-\varepsilon,x+\varepsilon)\cap \overline{E}=\emptyset\) and \((x-\varepsilon,x+\varepsilon)\subset \overline{E}^c\). So \(\overline{E}^c\) is open and \(\overline{E}\) is closed.

  2. If \(E=\overline{E}\), then by (1), \(E\) is closed. If \(E\) is closed, \(E'\subset E\) by Theorem 4.1.24 and \(\overline{E}=E\).

  3. If \(E\subset F\) and \(F\) is closed, then \(E'\subset F\). To see this, notice every limit point of \(E\) is a limit point of \(F\), since \(E\subset F\). So \(E'\subset F'\subset F\) by Theorem 4.1.24. Thus \(\overline{E}\subset F\).

∎

So \(\overline{E}\) is the smallest closed set containing \(E\).

Definition 4.1.27. A set \(D\subset \mathbb{R}\) is dense in \(\mathbb{R}\) if \(\overline{D}=\mathbb{R}\).

Example 4.1.28. \(\mathbb{Q}\) and \(\mathbb{R}\setminus \mathbb{Q}\) are dense in \(\mathbb{R}\). Let \(x\in\mathbb{R}\) and \(\varepsilon>0\). By Theorem 1.8.11, there is a rational number in \((x,x+\varepsilon)\). It is not \(x\). So \(x\) is a limit point of \(\mathbb{Q}\), and \(\overline{\mathbb{Q}}=\mathbb{R}\). Exercise 1.8.5 gives the same for \(\mathbb{R}\setminus\mathbb{Q}\).

Definition 4.1.29. A set \(A\subset\mathbb{R}\) is connected if there do not exist two disjoint open sets \(U\) and \(V\) such that \(A\cap U\ne\emptyset\), \(A\cap V\ne\emptyset\), and \((A\cap U)\cup (A\cap V)=A\).

Theorem 4.1.30. A nonempty subset \(A\) of \(\mathbb{R}\) is connected if and only if it is an interval.

Proof. (\(\Rightarrow\)) Assume \(A\) is not an interval. Then there exist \(a,b\in A\) with \(a<b\) and \(t\in(a,b)\) with \(t\notin A\). Define \(U=(-\infty,t)\) and \(V=(t,\infty)\). Then \(U\cap V=\emptyset\). Also \(a\in A\cap U\) and \(b\in A\cap V\), so \(A\cap U\ne\emptyset\), \(A\cap V\ne \emptyset\). Last, since \(t\notin A\), \((A\cap U)\cup (A\cap V)=A\), so \(A\) is not connected.

(\(\Leftarrow\)) This direction is an exercise.

∎

4.2 Compact Sets

Many facts are easy for finite sets and false for infinite ones. A finite set of numbers has a largest element. A finite set of positive numbers has a positive minimum. Compact sets are infinite sets that behave like finite sets in one precise way. This section defines compactness and proves that the compact subsets of \(\mathbb{R}\) are exactly the closed and bounded sets.

Definition 4.2.1. Let \(E\subset\mathbb{R}\). A collection \(\mathcal{U}=\{U_\alpha\}_{\alpha\in\Lambda}\) of open subsets of \(\mathbb{R}\) is called an open cover of \(E\) if \(E\subset \bigcup_{\alpha\in\Lambda} U_\alpha\).

Example 4.2.2. Let \(E=(0,1)\) and let \(U_n=\left(0,1-\frac{1}{n}\right)\). Then \(\{U_n\}_{n\in\mathbb{N}}\) is an open cover of \(E\). Each \(x\in(0,1)\) is in \(U_n\) once \(\frac1n<1-x\).

Example 4.2.3. Let \(E=\mathbb{R}\) and let \(U_x=(x-1,x+1)\). Then \(\{U_x\}_{x\in\mathbb{R}}\) is an open cover of \(\mathbb{R}\).

Definition 4.2.4. Let \(E\subset \mathbb{R}\) and \(\{U_\alpha\}_{\alpha\in\Lambda}\) be an open cover of \(E\). If there exists a \(\Lambda_0\subset\Lambda\) such that \(\{U_\beta\}_{\beta\in\Lambda_0}\) is an open cover of \(E\), \(\{U_\beta\}_{\beta\in\Lambda_0}\) is called a subcover of \(\{U_\alpha\}_{\alpha\in\Lambda}\). If \(\Lambda_0\) is finite, it is called a finite subcover.

Definition 4.2.5. A subset \(K\subset \mathbb{R}\) is compact if every open cover of \(K\) has a finite subcover.

Proof Technique (Proving a Set Is Not Compact).

To prove a set \(K\) is compact, every open cover of \(K\) has to be handled. To prove \(K\) is not compact, one open cover is enough. Find an open cover of \(K\) with no finite subcover. A good choice is a sequence of open sets \(U_1\subset U_2\subset U_3\subset\cdots\) whose union contains \(K\) but none of which contains \(K\). The union of finitely many of them is the one with the largest index, and it misses part of \(K\). Example 4.2.6 does this.

Example 4.2.6. \((0,1)\) is not compact. To show this, assume by way of contradiction that \((0,1)\) is compact. Then, since \(\{U_n\}_{n\in\mathbb{N}}=\left\{\left(0,1-\frac{1}{n}\right)\right\}_{n\in\mathbb{N}}\) covers \((0,1)\), there exists \(n_1<n_2<\cdots<n_k\) such that \[(0,1)\subset \bigcup_{i=1}^k \left(0,1-\frac{1}{n_i}\right)=\left(0,1-\frac{1}{n_k}\right),\] a contradiction, since \(1-\frac{1}{2n_k}\) is in \((0,1)\) but not in \(\left(0,1-\frac{1}{n_k}\right)\). So \((0,1)\) is not compact.

Example 4.2.7. \([0,\infty)\) is not compact. See Exercise 4.2.1.

Example 4.2.8. A finite set is compact. To see this, let \(P=\{p_1,\dots,p_n\}\) be a finite set. Let \(\{U_\alpha\}_{\alpha\in\Lambda}\) be an open cover of \(P\). So for each \(p_k\in P\), \(k=1,\dots,n\), there exists an \(\alpha_{k}\in\Lambda\) such that \(p_k\in U_{\alpha_k}\). So \(\{U_{\alpha_k}\}_{k=1}^n\) is a finite subcover of \(P\) and hence, \(P\) is compact.

Proof Technique (Finite Subcover Arguments).

Many proofs about a compact set \(K\) follow one pattern. For each point \(y\in K\), choose an open set around \(y\) with some useful property. These sets form an open cover of \(K\). Compactness gives finitely many of them that still cover \(K\). Then take a minimum or a maximum over the finitely many choices. The minimum of finitely many positive numbers is positive. The minimum of infinitely many might not exist, and their infimum might be \(0\). The proof of Theorem 4.2.9 uses this pattern twice.

Theorem 4.2.9. A compact subset of \(\mathbb{R}\) is closed and bounded.

Proof.

Let \(K\subset \mathbb{R}\) be compact. If \(K=\emptyset\), then \(K\) is closed and bounded. So assume \(K\ne\emptyset\).

First, \(K\) is bounded. Every real number is in \((-n,n)\) for some \(n\in\mathbb{N}\), by the Archimedean Principle. So the intervals \((-n,n)\), \(n\in\mathbb{N}\), form an open cover of \(K\). Since \(K\) is compact, finitely many of them cover \(K\), say \((-n_1,n_1),\dots,(-n_m,n_m)\). Let \(N=\max\{n_1,\dots,n_m\}\). Each of these intervals is a subset of \((-N,N)\). So \(K\subset(-N,N)\), and \(K\) is bounded.

Next, \(K\) is closed. Let \(x\in K^c\). For each \(y\in K\), \(y\ne x\). Let \(\varepsilon_y=\frac12|x-y|>0\). The intervals \((x-\varepsilon_y,x+\varepsilon_y)\) and \((y-\varepsilon_y,y+\varepsilon_y)\) are disjoint. Indeed, if \(z\) were in both, then \[|x-y|\le|x-z|+|z-y|<2\varepsilon_y=|x-y|.\] The intervals \((y-\varepsilon_y,y+\varepsilon_y)\), \(y\in K\), form an open cover of \(K\). Since \(K\) is compact, there exist \(y_1,\dots,y_n\in K\) such that \[K\subset\bigcup_{i=1}^n(y_i-\varepsilon_{y_i},y_i+\varepsilon_{y_i}).\] Let \(\varepsilon=\min\{\varepsilon_{y_1},\dots,\varepsilon_{y_n}\}>0\). For each \(i\), \((x-\varepsilon,x+\varepsilon)\subset(x-\varepsilon_{y_i},x+\varepsilon_{y_i})\), which is disjoint from \((y_i-\varepsilon_{y_i},y_i+\varepsilon_{y_i})\). So \((x-\varepsilon,x+\varepsilon)\cap K=\emptyset\), and \((x-\varepsilon,x+\varepsilon)\subset K^c\). Thus \(K^c\) is open and \(K\) is closed.

∎

Lemma 4.2.10. Every closed subset of a compact set is compact.

Proof.

Let \(K\) be compact and let \(F\subset K\) be closed. Let \(\{U_\alpha\}_{\alpha\in\Lambda}\) be an open cover of \(F\). Since \(F\) is closed, \(F^c\) is open. Each point of \(K\) is either in \(F\), and so in some \(U_\alpha\), or in \(F^c\). So the sets \(U_\alpha\), \(\alpha\in\Lambda\), together with \(F^c\) form an open cover of \(K\). Since \(K\) is compact, finitely many of these sets cover \(K\). Adding \(F^c\) to the list if needed, \[K\subset U_{\alpha_1}\cup\cdots\cup U_{\alpha_n}\cup F^c\] for some \(\alpha_1,\dots,\alpha_n\in\Lambda\). No point of \(F\) is in \(F^c\). So \(F\subset U_{\alpha_1}\cup\cdots\cup U_{\alpha_n}\), and \(F\) is compact.

∎

Theorem 4.2.11 (Bolzano–Weierstrass Property).

If \(S\) is an infinite subset of a compact set \(K\), then \(S\) has a limit point in \(K\).

Proof.

Assume by way of contradiction that no point of \(K\) is a limit point of \(S\). Then for each \(x\in K\), there exists an \(\varepsilon_x>0\) such that \((x-\varepsilon_x,x+\varepsilon_x)\) contains no point of \(S\) other than \(x\). So each interval \((x-\varepsilon_x,x+\varepsilon_x)\) contains at most one point of \(S\). These intervals, for \(x\in K\), form an open cover of \(K\). Since \(K\) is compact, finitely many of them cover \(K\), and so they cover \(S\). Since each of them contains at most one point of \(S\), \(S\) is finite. This is a contradiction. So \(S\) has a limit point in \(K\).

∎

Theorem 4.2.12 (Cantor’s Intersection Theorem).

If \(\{K_n\}_{n=1}^\infty\) is a sequence of nonempty compact subsets of \(\mathbb{R}\) with \(K_n\supset K_{n+1}\) for all \(n\in\mathbb{N}\), then \(K=\bigcap_{n=1}^\infty K_n\) is nonempty and compact.

Proof. Let \(U_n=K_n^c\). By Theorem 4.2.9, \(K_n\) is closed and therefore \(U_n\) is open. Assume by way of contradiction that \(K=\emptyset\). Then \(\bigcup_{n=1}^\infty U_n=\mathbb{R}\). So \(\{U_n\}\) is an open cover of \(\mathbb{R}\) and hence \(K_1\). So there exists \(n_1<n_2<\cdots<n_k\) such that \(K_1\subset\bigcup_{j=1}^k U_{n_j}\). This implies \(K_1^c\supset \bigcap_{j=1}^k K_{n_j}\), or \[K_1\cap K_{n_1}\cap K_{n_2}\cap\cdots\cap K_{n_k}=\emptyset,\] a contradiction, since the sets are nested and so this intersection is \(K_{n_k}\), which is nonempty. Thus \(K\ne\emptyset\). By Theorem 4.1.17, \(K\) is closed and since \(K\subset K_1\), by Lemma 4.2.10, \(K\) is compact.

∎

A collection of sets has the finite intersection property if every finite subcollection has a nonempty intersection. The nested compact sets in Cantor’s Intersection Theorem have it. The next corollary drops the nesting.

Corollary 4.2.13. Let \(\{F_\alpha\}_{\alpha\in\Lambda}\) be a collection of closed sets with the property that every finite subcollection of \(\{F_\alpha\}_{\alpha\in\Lambda}\) has a nonempty intersection. Suppose one of the sets \(F_\alpha\) is bounded. Then \(\bigcap_{\alpha\in\Lambda}F_\alpha\ne\emptyset\).

Proof. See Exercise 4.2.7.

∎

This extends the Nested Interval Theorem (Theorem 3.4.4) from closed intervals to compact sets. Compactness cannot be dropped. For example, \(\bigcap_{n=1}^\infty[n,\infty)=\emptyset\).

Theorem 4.2.14 (Heine–Borel).

Every closed and bounded interval \([a,b]\) is compact.

Proof.

Let \(\mathcal{U}=\{U_\alpha\}_{\alpha\in\Lambda}\) be an open cover of \([a,b]\). Call a point \(r\in[a,b]\) good if \([a,r]\) is covered by finitely many of the sets in \(\mathcal{U}\). Let \(E\) be the set of good points. Some \(U_\alpha\) contains \(a\), so \([a,a]=\{a\}\) is covered by one set in \(\mathcal{U}\). So \(a\in E\), and \(E\ne\emptyset\). Also, \(E\) is bounded above by \(b\). By the least upper bound property, \(c=\sup E\) exists, and \(a\le c\le b\).

Since \(c\in[a,b]\), there exists an \(\alpha_c\in\Lambda\) with \(c\in U_{\alpha_c}\). Since \(U_{\alpha_c}\) is open, there exists an \(\varepsilon>0\) such that \((c-\varepsilon,c+\varepsilon)\subset U_{\alpha_c}\). By Theorem 1.8.7, there exists a good point \(r\) with \(c-\varepsilon<r\le c\). So \[[a,r]\subset U_{\alpha_1}\cup\cdots\cup U_{\alpha_n}\] for some \(\alpha_1,\dots,\alpha_n\in\Lambda\). Let \(t=\min\left\{b,c+\frac{\varepsilon}{2}\right\}\). Then \([r,t]\subset(c-\varepsilon,c+\varepsilon)\subset U_{\alpha_c}\). So \[[a,t]\subset U_{\alpha_1}\cup\cdots\cup U_{\alpha_n}\cup U_{\alpha_c},\] and \(t\) is good. Since \(c=\sup E\), \(t\le c\). If \(c<b\), then \(t>c\), a contradiction. So \(c=b\), and then \(t=b\). Thus \(b\) is good. That is, \([a,b]\) is covered by finitely many of the sets in \(\mathcal{U}\).

∎

Proof Technique (Proving Several Statements Are Equivalent).

To prove statements (1), (2) and (3) are equivalent, it is enough to prove (1)\(\Rightarrow\)(2), (2)\(\Rightarrow\)(3) and (3)\(\Rightarrow\)(1). This is a cycle of implications. Any one statement implies any other by following the cycle. For example, (2)\(\Rightarrow\)(1) follows from (2)\(\Rightarrow\)(3) and (3)\(\Rightarrow\)(1). Three proofs replace six. Theorem 4.2.15 is proved this way.

Theorem 4.2.15 (Heine–Borel–Bolzano–Weierstrass).

Let \(K\subset \mathbb{R}\). The following are equivalent.

  1. \(K\) is closed and bounded.

  2. \(K\) is compact.

  3. Every infinite subset of \(K\) has a limit point in \(K\).

Proof. (1)\(\Rightarrow\)(2) Since \(K\) is bounded, there exists an \(M>0\) such that \(K\subset [-M,M]\). Now, by the Heine–Borel Theorem (Theorem 4.2.14), \([-M,M]\) is compact. So by Lemma 4.2.10, \(K\) is compact.

(2)\(\Rightarrow\)(3) Theorem 4.2.11.

(3)\(\Rightarrow\)(1) Suppose every infinite subset of \(K\) has a limit point in \(K\).

First, \(K\) is bounded. Assume by way of contradiction that \(K\) is not bounded. Choose \(x_1\in K\) with \(|x_1|>1\). Having chosen \(x_1,\dots,x_n\), choose \(x_{n+1}\in K\) with \(|x_{n+1}|>\max\{n+1,|x_n|\}\). This is possible since \(K\) is not bounded. Then \(|x_1|<|x_2|<|x_3|<\cdots\), so the points \(x_n\) are distinct, and \(|x_n|>n\) for all \(n\). Let \(S=\{x_n:n\in\mathbb{N}\}\). Then \(S\) is an infinite subset of \(K\). Let \(y\in\mathbb{R}\), and choose \(N\in\mathbb{N}\) with \(N>|y|+1\). By the Reverse Triangle Inequality (Theorem 1.7.3), for all \(n\ge N\), \[|x_n-y|\ge|x_n|-|y|>n-|y|\ge N-|y|>1.\] So \((y-1,y+1)\) contains at most the finitely many points \(x_1,\dots,x_{N-1}\) of \(S\). By Exercise 4.1.9, \(y\) is not a limit point of \(S\). So \(S\) has no limit point in \(\mathbb{R}\), and so none in \(K\). This contradicts (3). So \(K\) is bounded.

Next, \(K\) is closed. Let \(x\) be a limit point of \(K\). By Theorem 4.1.24, it is enough to show \(x\in K\). For each \(n\in\mathbb{N}\), there exists an \(x_n\in K\) with \(x_n\ne x\) and \(|x_n-x|<\frac{1}{n}\). Let \(S=\{x_n:n\in\mathbb{N}\}\). If \(S\) were finite, then \(\delta=\min\{|s-x|:s\in S\}\) would be positive, and \(|x_n-x|<\frac1n<\delta\) for large \(n\). This is impossible, since each \(x_n\) is in \(S\). So \(S\) is infinite. By (3), \(S\) has a limit point \(z\in K\). Suppose \(z\ne x\). Let \(\varepsilon=\frac{1}{2}|z-x|\), and choose \(N\in\mathbb{N}\) with \(\frac{1}{N}<\varepsilon\). For all \(n\ge N\), \[|x_n-z|\ge|z-x|-|x_n-x|>2\varepsilon-\varepsilon=\varepsilon.\] So \((z-\varepsilon,z+\varepsilon)\) contains at most the finitely many points \(x_1,\dots,x_{N-1}\) of \(S\). By Exercise 4.1.9, \(z\) is not a limit point of \(S\), a contradiction. So \(z=x\). Thus \(x\in K\), and \(K\) is closed.

∎

Closed and bounded is the easiest of the three conditions to check. Compactness is the most useful in proofs. The third condition connects compactness to sequences, as Corollary 4.2.16 shows.

Corollary 4.2.16. Let \(K\) be a nonempty compact subset of \(\mathbb{R}\). Then every sequence in \(K\) has a convergent subsequence that converges to a point in \(K\).

Proof. See Exercise 4.2.3.

∎

Notes

Peter Gustav Lejeune Dirichlet used the idea behind the Heine–Borel Theorem in his 1852 lectures, to prove that a continuous function on a closed interval is uniformly continuous. Eduard Heine published that result in 1872 [38]. Émile Borel proved the Heine–Borel Theorem for countable open covers in 1895 [6]. Pierre Cousin proved a version for arbitrary covers the same year [17], and Henri Lebesgue gave a proof for arbitrary covers in his 1904 lectures [43]. The name Heine–Borel Theorem is due to Arthur Schoenflies [65]. Ernst Lindelöf proved his theorem in 1903 [48].
