Solutions for Chapter 11. Sequences and Series of Functions

Exercise 11.2.1. Hint. If \(|f_n(x)-f(x)|<\varepsilon\) for all \(x\in E\), then \(M_n\le\varepsilon\). If \(M_n<\varepsilon\), then \(|f_n(x)-f(x)|<\varepsilon\) for all \(x\in E\).

Solution. (\(\Rightarrow\)) Suppose \(f_n\to f\) uniformly on \(E\). Let \(\varepsilon>0\). There is an \(N\in\mathbb{N}\) such that \(|f_n(x)-f(x)|<\frac\varepsilon 2\) for all \(n\ge N\) and all \(x\in E\). For \(n\ge N\), \(\frac\varepsilon 2\) is an upper bound of \(\{|f_n(x)-f(x)|:x\in E\}\). So \(0\le M_n\le\frac\varepsilon 2<\varepsilon\). So \(M_n\to0\).

(\(\Leftarrow\)) Suppose \(M_n\to0\). Let \(\varepsilon>0\). There is an \(N\in\mathbb{N}\) such that \(M_n<\varepsilon\) for all \(n\ge N\). Then for \(n\ge N\) and \(x\in E\), \[|f_n(x)-f(x)|\le M_n<\varepsilon.\] So \(f_n\to f\) uniformly on \(E\).

Exercise 11.2.2. Hint. By Corollary 11.2.6, the terms of a uniformly convergent series converge uniformly to \(0\). Find \(\sup_{|x|<2}\left|\left(\frac x2\right)^k\right|\).

Solution. Suppose the series converges uniformly on \((-2,2)\). By Corollary 11.2.6 with \(\varepsilon=\frac12\), there is an \(N\in\mathbb{N}\) such that \[\left|\sum_{k=n+1}^m\left(\frac x2\right)^k\right|<\frac12\quad\text{for all }m>n\ge N\text{ and all }x\in(-2,2).\] Take \(n=N\) and \(m=N+1\). Then \(\left|\left(\frac x2\right)^{N+1}\right|<\frac12\) for all \(x\in(-2,2)\). But let \(x=2\cdot2^{-1/(N+1)}\). Then \(0<x<2\) and \(\left(\frac x2\right)^{N+1}=\frac12\). This is a contradiction. So the convergence is not uniform on \((-2,2)\).

Exercise 11.2.6. Hint. Let \(|f|\le M\). Then \(|x^nf(x)|\le M\). The limit is \(0\) on \([0,1)\) and \(f(1)\) at \(1\). Its integral is \(0\), by Exercise 9.2.2.

Solution. Since \(f\in\mathcal{R}[0,1]\), \(f\) is bounded. Choose \(M>0\) with \(|f(x)|\le M\) for all \(x\in[0,1]\). Let \(g_n(x)=x^nf(x)\). Since \(x^n\) is continuous, \(g_n\in\mathcal{R}[0,1]\) by Theorem 9.2.11 (3). Also \(|g_n(x)|\le M\) for all \(x\in[0,1]\) and all \(n\in\mathbb{N}\).

If \(0\le x<1\), then \(x^n\to0\) by Example 3.1.7, so \(g_n(x)\to0\). Also \(g_n(1)=f(1)\) for all \(n\). So \(g_n\to g\) pointwise on \([0,1]\), where \(g(x)=0\) for \(x\in[0,1)\) and \(g(1)=f(1)\). By Exercise 9.2.2, \(g\in\mathcal{R}[0,1]\) and \(\int_0^1g=0\). By the Bounded Convergence Theorem (Theorem 11.2.21), \[\lim_{n\to\infty}\int_0^1x^nf(x)\,dx=\int_0^1g=0.\]

Exercise 11.2.7. Hint. (a) Define a new sequence of functions \(\{g_n\}\) by \(g_n(x)=\max_{k\in\{1,\dots,n\}} f_k(x)\) for each \(x\in[a,b]\). Show \(\{g_n\}\) is a sequence of continuous functions that converges uniformly to \(g\). (b) Try \(f_n(x)=\max\{0,1-n|x-\frac1n|\}\) on \([0,1]\). These are tents of height \(1\) that move toward \(0\).

Exercise 11.2.8. Hint. Try the moving tents from the hint to Exercise 11.2.7 (b).

Solution. For \(n\in\mathbb{N}\) and \(x\in[0,1]\), let \[f_n(x)=\max\left\{0,\ 1-n\left|x-\frac1n\right|\right\}.\] The graph of \(f_n\) is a tent of height \(1\) over \(\left[0,\frac2n\right]\), with its peak at \(\frac1n\). Each \(f_n\) is continuous, since \(x\mapsto1-n\left|x-\frac1n\right|\) is continuous and the maximum of two continuous functions is continuous. Also \(0\le f_n(x)\le1\).

The sequence converges pointwise to \(0\). First, \(f_n(0)=\max\{0,1-1\}=0\) for all \(n\). Now let \(0<x\le1\). If \(n>\frac2x\), then \(x-\frac1n>\frac1n\), so \(1-n\left|x-\frac1n\right|<0\) and \(f_n(x)=0\). So \(f_n(x)\to0\).

The convergence is not uniform. Since \(f_n\left(\frac1n\right)=1\), \(\sup_{x\in[0,1]}|f_n(x)-0|=1\) for every \(n\). By Theorem 11.2.7, \(\{f_n\}\) does not converge uniformly to \(0\).

Here \([0,1]\) is compact and the limit \(0\) is continuous. So Dini’s Theorem fails only because the sequence is not decreasing. For example, \(f_1(x)=x\), so \(f_1\left(\frac1n\right)=\frac1n<1=f_n\left(\frac1n\right)\) for \(n\ge2\).

Exercise 11.4.1. By Lemma 11.4.2, \(B_n1=\sum_kp_{n,k}(x)=1\) and \(B_nx=\sum_k\frac knp_{n,k}(x)=\frac{nx}n=x\). In the proof of that lemma, \(\sum_kk(k-1)p_{n,k}(x)=n(n-1)x^2\), so \(\sum_kk^2p_{n,k}(x)=n(n-1)x^2+nx\). Thus \[B_nx^2=\sum_{k=0}^n\frac{k^2}{n^2}p_{n,k}(x)=\frac{n(n-1)x^2+nx}{n^2}=x^2+\frac{x(1-x)}n.\]

Exercise 11.4.2. By linearity, \(\int_0^1f(x)p(x)\,dx=0\) for every polynomial \(p\). Let \(M\) be a bound for \(|f|\) on \([0,1]\) (Theorem 6.3.15), and let \(\varepsilon>0\). By Theorem 11.4.3, there is a polynomial \(p\) with \(|f(x)-p(x)|<\varepsilon\) on \([0,1]\). Then \[0\le\int_0^1f^2=\int_0^1f(f-p)+\int_0^1fp=\int_0^1f(f-p)\le M\varepsilon.\] Since \(\varepsilon\) is arbitrary, \(\int_0^1f^2=0\). Suppose \(f(c)\ne0\) for some \(c\). Then \(f^2(c)>0\), and since \(f^2\) is continuous, \(f^2(x)>\frac{f^2(c)}2\) on some interval \([\alpha,\beta]\subset[0,1]\) with \(\alpha<\beta\). Then \(\int_0^1f^2\ge\frac{f^2(c)}2(\beta-\alpha)>0\). This is a contradiction. So \(f=0\).

The iterates are \(\varphi_0=1\), \(\varphi_1(t)=1+\int_0^t2s\,ds=1+t^2\), \(\varphi_2(t)=1+\int_0^t2s(1+s^2)\,ds=1+t^2+\frac{t^4}2\). By induction, \(\varphi_n(t)=\sum_{k=0}^n\frac{t^{2k}}{k!}\). Indeed, if this holds for \(n\), then \[\varphi_{n+1}(t)=1+\int_0^t\sum_{k=0}^n\frac{2s^{2k+1}}{k!}\,ds=1+\sum_{k=0}^n\frac{t^{2k+2}}{(k+1)!}=\sum_{j=0}^{n+1}\frac{t^{2j}}{j!}.\] These are the partial sums of the series for \(e^u\) with \(u=t^2\). So the solution is \(y(t)=e^{t^2}\).

Exercise 11.5.2. Clearly \(y=0\) works. For \(y(t)=t^3\), \(y(0)=0\) and \(y'(t)=3t^2\). Also \(y(t)^{2/3}=\left(\sqrt[3]{t^3}\right)^2=t^2\). So \(y'=3y^{2/3}\). The Lipschitz condition fails. If \(|3y^{2/3}-3z^{2/3}|\le L|y-z|\) for all \(y,z\), then taking \(z=0\) gives \(3|y|^{2/3}\le L|y|\), so \(3\le L|y|^{1/3}\) for all \(y\ne0\). This is false for small \(y\).
