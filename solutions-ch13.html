Solutions for Chapter 13. \(\sigma\)-Algebras and Measures

Exercise 13.1.1. Let \(\{\mathcal{M}_\alpha\}_{\alpha\in A}\) be a family of \(\sigma\)-algebras on a set \(X\). Let \(\mathcal{M}=\bigcap_{\alpha\in A}\mathcal{M}_\alpha\). First, \(\mathcal{M}\) is nonempty. Each \(\mathcal{M}_\alpha\) contains \(X\) by Remark 13.1.3, so \(X\in\mathcal{M}\). Let \(\{E_i\}_{i=1}^\infty\subset \mathcal{M}\). So for each \(\alpha\in A\), \(\{E_i\}_{i=1}^\infty\subset\mathcal{M}_\alpha\). Since for each \(\alpha\in A\), \(\mathcal{M}_\alpha\) is a \(\sigma\)-algebra, \(\bigcup_{i=1}^\infty E_i\in\mathcal{M}_\alpha\) for all \(\alpha\in A\). So \(\bigcup_{i=1}^\infty E_i\in\mathcal{M}\).

Next, let \(E\in\mathcal{M}\). So for all \(\alpha\in A\), \(E\in\mathcal{M}_\alpha\). Since for each \(\alpha\in A\), \(\mathcal{M}_\alpha\) is a \(\sigma\)-algebra, \(E^c\in\mathcal{M}_\alpha\) for all \(\alpha\in A\). So \(E^c\in\mathcal{M}\). So \(\mathcal{M}\) is a \(\sigma\)-algebra. Finite unions are covered too. Now \(\emptyset=X^c\in\mathcal{M}\), and \(E_1\cup\cdots\cup E_n=\bigcup_{i=1}^\infty E_i\) with \(E_i=\emptyset\) for \(i>n\).

Exercise 13.1.2. (a) Let \(E_1,E_2\in\mathcal{R}\). Then \(E_1\cap E_2=(E_1\cup E_2)\setminus\big((E_1\setminus E_2)\cup(E_2\setminus E_1)\big)\in\mathcal{R}\). Indeed, a point of \(E_1\cup E_2\) lies in neither \(E_1\setminus E_2\) nor \(E_2\setminus E_1\) exactly when it lies in both sets. An inductive argument shows \(\mathcal{R}\) is closed under finite intersections.

(b) (\(\Rightarrow\)) Let \(E\in\mathcal{R}\). Such an \(E\) exists since a \(\sigma\)-algebra is nonempty. Then by the properties of a \(\sigma\)-ring, \(E\setminus E=\emptyset\in\mathcal{R}\). Since \(\mathcal{R}\) is a \(\sigma\)-algebra, \(\emptyset^c=X\in\mathcal{R}\).

(\(\Leftarrow\)) Since \(\mathcal{R}\) is a \(\sigma\)-ring, it is closed under countable unions. Let \(E\in\mathcal{R}\). Since \(X\in\mathcal{R}\), \(X\setminus E=E^c\in\mathcal{R}\), and so \(\mathcal{R}\) is closed under complements. Also \(\mathcal{R}\) is nonempty, since \(X\in\mathcal{R}\). So \(\mathcal{R}\) is a \(\sigma\)-algebra.

(c) Let \(\mathcal{S}=\{E\subset X:E\cap F\in\mathcal{R}\text{ for all }F\in\mathcal{R}\}\). First, \(X\in\mathcal{S}\), since \(X\cap F=F\in\mathcal{R}\) for every \(F\in\mathcal{R}\). So \(\mathcal{S}\) is nonempty. Let \(\{E_n\}_{n\in\mathbb{N}}\subset\mathcal{S}\). Let \(F\in\mathcal{R}\). Since \(E_n\cap F\in\mathcal{R}\) for all \(n\in\mathbb{N}\), \[\left[\bigcup_{n\in\mathbb{N}} E_n\right] \cap F=\bigcup_{n\in\mathbb{N}}(E_n\cap F)\in\mathcal{R}.\] So \(\bigcup_{n\in\mathbb{N}} E_n\in\mathcal{S}\).

Next, let \(E\in\mathcal{S}\). Let \(F\in\mathcal{R}\). Then \(E^c\cap F=F\setminus(E\cap F)\in\mathcal{R}\). So \(E^c\in\mathcal{S}\) and \(\mathcal{S}\) is a \(\sigma\)-algebra.

Exercise 13.2.1. Hint. For \(n\in\mathbb{N}\), let \(U_n\) be the set of points \(c\) for which there is a \(\delta>0\) with \(|f(x)-f(y)|<\frac1n\) for all \(x,y\in(c-\delta,c+\delta)\). Show \(U_n\) is open.

Solution.Let \(S=\{x\in\mathbb{R}: f \text{ is continuous at } x\}\). Now for each \(x\in S\) and \(n\in\mathbb{N}\), there exists a \(\delta_{x,n}>0\) such that for all \(y\in\mathbb{R}\) with \(|x-y|<\delta_{x,n}\), \(|f(x)-f(y)|<\frac1n\). Let \(G_n=\bigcup_{x\in S}(x-\delta_{x,n},x+\delta_{x,n})\). Let \(G=\bigcap_{n\in\mathbb{N}} G_n\). Each \(G_n\) is a union of open intervals, so it is open. Thus \(G\) is a \(G_\delta\).

For \(z\in S\), \(z\in G_n\) for all \(n\in\mathbb{N}\), and so \(z\in G\). Thus \(S\subset G\).

Now let \(z\in G\). Let \(\varepsilon>0\). Choose an \(N\in\mathbb{N}\) such that \(N>\frac2\varepsilon\). Since \(z\in G\), \(z\in G_N\). So there exists an \(x\in S\) such that \(z\in (x-\delta_{x,N}, x+\delta_{x,N})\). In particular, \(|f(z)-f(x)|<\frac1N\). Choose \(\delta=\delta_{x,N}-|x-z|>0\). So for all \(y\in \mathbb{R}\) with \(|z-y|<\delta\), \[|x-y|\leq |x-z|+|z-y|< |x-z|+\delta=\delta_{x,N}.\] So for all \(y\in \mathbb{R}\) with \(|z-y|<\delta\), \[|f(z)-f(y)|\leq |f(z)-f(x)|+|f(x)-f(y)|< \frac1N + \frac1N = \frac2N<\varepsilon.\] So \(f\) is continuous at \(z\) and thus \(z\in S\). So \(G\subset S\) and \(G=S\).

Exercise 13.2.2. Hint. If \(x\in U_n\) for every \(n\), there are points \(y_n\in F\) with \(|x-y_n|<\frac1n\). Since \(F\) is closed, \(x\in F\). For open sets, take complements.

Solution. Each \(U_n\) is a union of open intervals, so it is open by Theorem 4.1.11. If \(y\in F\), then \(y\in\left(y-\frac1n,y+\frac1n\right)\subset U_n\) for every \(n\). So \(F\subset\bigcap_nU_n\).

Conversely, let \(x\in\bigcap_nU_n\). For each \(n\) there is a \(y_n\in F\) with \(|x-y_n|<\frac1n\). If \(x=y_n\) for some \(n\), then \(x\in F\). Otherwise, let \(\varepsilon>0\) and choose \(n\) with \(\frac1n<\varepsilon\). Then \(y_n\in F\), \(y_n\ne x\) and \(|y_n-x|<\varepsilon\). So \(x\) is a limit point of \(F\), and \(x\in F\) by Theorem 4.1.24. So \(\bigcap_nU_n\subset F\), and \(F=\bigcap_nU_n\) is a \(G_\delta\) set.

Now let \(U\) be open. Then \(U^c\) is closed, so \(U^c=\bigcap_nV_n\) with each \(V_n\) open. By De Morgan’s Laws (Theorem 1.1.13), \(U=\bigcup_nV_n^c\). Each \(V_n^c\) is closed. So \(U\) is an \(F_\sigma\) set.

Exercise 13.3.1. (a) First, \(\mu(\emptyset)=\sum_{x\in\emptyset}f(x)=0\). Let \(\{E_i\}_{i=1}^\infty\subset\mathcal{M}\) be a disjoint sequence. Then \[\mu\left(\bigcup_{i=1}^\infty E_i\right)=\sum_{x\in \bigcup_{i=1}^\infty E_i}f(x)=\sum_{i=1}^\infty\sum_{x\in E_i}f(x)=\sum_{i=1}^\infty \mu(E_i).\] So \(\mu\) is a measure.

The middle equality needs a word, since each sum is a supremum over finite sets. Let \(E=\bigcup_iE_i\). If \(F\subset E\) is finite, then \(F\) meets only finitely many \(E_i\), and the sets \(F\cap E_i\) are disjoint. So \[\sum_{x\in F}f(x)=\sum_{i=1}^\infty\sum_{x\in F\cap E_i}f(x)\le\sum_{i=1}^\infty\mu(E_i).\] Taking the supremum over \(F\) gives \(\mu(E)\le\sum_i\mu(E_i)\). Conversely, fix \(n\) and finite sets \(F_i\subset E_i\) for \(i=1,\dots,n\). Their union \(F\) is a finite subset of \(E\). So \(\sum_{i=1}^n\sum_{x\in F_i}f(x)=\sum_{x\in F}f(x)\le\mu(E)\). Taking the supremum over each \(F_i\) in turn gives \(\sum_{i=1}^n\mu(E_i)\le\mu(E)\). Now let \(n\to\infty\).

(b) (\(\Rightarrow\)) Suppose there exists an \(x\in X\) such that \(f(x)=\infty\). So \(\{x\}\in\mathcal{P}(X)=\mathcal{M}\) and \(\mu(\{x\})=f(x)=\infty\). Now the only subsets of \(\{x\}\) are \(\{x\}\) and \(\emptyset\). But \(\mu(\{x\})=\infty\) and \(\mu(\emptyset)=0\). So \(\mu\) is not semifinite. So by contrapositive, if \(\mu\) is semifinite, \(f(x)<\infty\) for all \(x\in X\).

(\(\Leftarrow\)) Suppose \(f(x)<\infty\) for all \(x\in X\). Let \(E\in\mathcal{M}\) with \(\mu (E)=\sum_{x\in E}f(x)=\infty\). So there exists an \(x\in E\) such that \(f(x)>0\). By the assumption, \(f(x)<\infty\). Now \(\{x\}\in\mathcal{P}(X)=\mathcal{M}\), \(\{x\}\subset E\), and \(\mu(\{x\})=f(x)\). So \(0<\mu(\{x\})<\infty\). Thus \(\mu\) is semifinite.

(c) (\(\Rightarrow\)) Suppose \(\mu\) is \(\sigma\)-finite. So there exists a sequence \(\{E_n\}_{n\in\mathbb{N}}\subset\mathcal{M}\) with \(\mu (E_n)<\infty\) for all \(n\in\mathbb{N}\) such that \(X=\bigcup_{n=1}^\infty E_n\). First, let \(x\in X\). Then there exists an \(E_N\) with \(x\in E_N\). So \(f(x)\le\mu(E_N)<\infty\). So \(f(x)<\infty\) for all \(x\in X\) and \(\mu\) is semifinite by (b). Now, since for each \(n\in\mathbb{N}\), \(\mu (E_n)=\sum_{x\in E_n}f(x)<\infty\), the set \(\{x\in E_n:f(x)>0\}\) must be countable for all \(n\in\mathbb{N}\). Indeed, let \(k\in\mathbb{N}\). If \(F\) is a finite subset of \(\{x\in E_n:f(x)>\frac1k\}\) with \(p\) elements, then \(\frac pk\le\sum_{x\in F}f(x)\le\mu(E_n)\). So \(\{x\in E_n:f(x)>\frac1k\}\) has at most \(k\mu(E_n)\) elements. Then \(\{x\in E_n:f(x)>0\}=\bigcup_{k\in\mathbb{N}}\{x\in E_n:f(x)>\frac1k\}\) is a countable union of finite sets. So \(\{x: f(x)>0\}=\bigcup_{n\in\mathbb{N}}\{x\in E_n:f(x)>0\}\) is countable by Theorem 2.2.6.

(\(\Leftarrow\)) Suppose \(\mu\) is semifinite and \(\{x:f(x)>0\}\) is countable. Enumerate the elements of \(\{x:f(x)>0\}\), \(\{x_n\}_{n\in\mathbb{N}}\). Let \(G=\{x:f(x)=0\}\). Then \(\mu( G)=0\). Also, \(\mu(\{x_n\})<\infty\) for all \(n\in\mathbb{N}\) by (b). Now \(X=G\cup\left[\bigcup_{n\in\mathbb{N}}\{x_n\}\right]\). So \(\mu\) is \(\sigma\)-finite. If \(\{x:f(x)>0\}\) is finite, list its elements and stop. The same argument works.

Exercise 13.3.2. First, the constant sequence \(E_n=\emptyset\) satisfies the hypotheses of (ii). So \(\mu(\emptyset)=\lim_{n\to\infty}\mu(E_n)=0\). Note that from (i), by induction, we have that for \(\{E_i\}_{i=1}^k\) with \(E_i\cap E_j=\emptyset\) for all \(i\neq j\), \(\mu\left(\bigcup_{i=1}^kE_i\right)=\sum_{i=1}^k \mu (E_i)\).

Now, let \(\{E_i\}_{i=1}^\infty\) be a disjoint sequence in \(\mathcal{M}\). First, if \(\mu (E_k)=\infty\) for any \(k\in\mathbb{N}\), \(\infty=\mu (E_k)\leq\mu\left(\bigcup_{i=1}^\infty E_i\right)\) and \(\sum_{i=1}^\infty \mu (E_i)=\infty\). The inequality holds since, by (i), \(\mu\left(\bigcup_iE_i\right)=\mu(E_k)+\mu\left(\bigcup_{i\ne k}E_i\right)\ge\mu(E_k)\). So \(\mu\left(\bigcup_{i=1}^\infty E_i\right)=\sum_{i=1}^\infty \mu (E_i)\). So assume \(\mu (E_i)<\infty\) for all \(i\in\mathbb{N}\). Let \(\varepsilon>0\). For all \(k\in\mathbb{N}\), define \(F_k=\bigcup_{i=k}^\infty E_i\). Then \(\{F_n\}_{n=1}^{\infty}\) is a sequence in \(\mathcal{M}\) with \(F_{n+1}\subset F_n\) for all \(n\) and \(\bigcap^\infty_{n=1} F_n=\emptyset\). So \(\lim_{n\to\infty}\mu(F_n)=0\). Thus there exists an \(N\in\mathbb{N}\) such that for all \(n\geq N\), \(\mu (F_n)<\varepsilon\). So for all \(n\geq N\), the finite sequence \(\{E_i\}_{i=1}^{n-1}\cup\{F_n\}\subset\mathcal{M}\) is disjoint and \(\bigcup_{i=1}^\infty E_i=\bigcup_{i=1}^{n-1}E_i\cup F_n\). So for all \(n\geq N\), \[\mu\left(\bigcup_{i=1}^\infty E_i\right)=\mu\left(\bigcup_{i=1}^{n-1}E_i\cup F_n\right)=\sum_{i=1}^{n-1}\mu (E_i) + \mu (F_n)<\sum_{i=1}^{n-1}\mu (E_i) + \varepsilon.\] Thus, for all \(n\geq N\), \(\left|\mu\left(\bigcup_{i=1}^\infty E_i\right)-\sum_{i=1}^{n-1}\mu (E_i)\right|<\varepsilon\). So \(\lim_{n\to \infty}\sum_{i=1}^{n-1}\mu (E_i)=\sum_{i=1}^\infty\mu (E_i)=\mu\left(\bigcup_{i=1}^\infty E_i\right)\). So \((\mathbb{R},\mathcal{M},\mu)\) is a measure space.
