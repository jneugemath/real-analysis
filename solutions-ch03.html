Solutions for Chapter 3. Sequences of Real Numbers

Exercise 3.1.1. (a) Let \(\varepsilon>0\). Choose \(N\in\mathbb{N}\) such that \(N>\frac{10}{9\varepsilon}\). Then, for all \(n\ge N\), \[\left|x_n-\frac{5}{3}\right|=\left|\frac{5n}{3n+2}-\frac{5}{3}\right|=\left|\frac{15n-15n-10}{9n+6}\right|=\frac{10}{9n+6}\le \frac{10}{9n}<\frac{10}{9\left(\frac{10}{9\varepsilon}\right)}=\varepsilon.\] So \(x_n\to\frac{5}{3}\).

(b) Let \(\varepsilon>0\). Choose \(N\in\mathbb{N}\) such that \(N>\left(\frac{5}{2\varepsilon}\right)^{2/3}\). Then, for all \(n\ge N\), \[|x_n-6|=\left|\frac{12n^2+5\sqrt{n}}{2n^2}-6\right|=\left|\frac{12n^2+5\sqrt{n}-12n^2}{2n^2}\right|=\frac{5\sqrt{n}}{2n^2}=\frac{5}{2n^{3/2}}<\frac{5}{2\left(\left(\frac{5}{2\varepsilon}\right)^{2/3}\right)^{3/2}}=\varepsilon.\] So \(x_n\to6\).

(c) Let \(\varepsilon>0\). Choose \(N\in\mathbb{N}\) such that \(N>\frac{1}{\varepsilon}\). Then, for all \(n\ge N\), \[|x_n-1|=\left|1-\frac{(-1)^n}{n} - 1\right|=\frac{1}{n}<\frac{1}{\frac{1}{\varepsilon}}=\varepsilon.\] So \(x_n\to 1\).

(d) Let \(\varepsilon>0\). Choose \(N\in\mathbb{N}\) such that \(N>\max\left\{75,\frac{16}{9\varepsilon},\sqrt{\frac{67}{\varepsilon}}\right\}\). Then, for all \(n\ge N\), \[\left|x_n-\frac{8}{3}\right|=\left|\frac{(1+4n)^2}{6n^2+n-75}-\frac{8}{3}\right|=\left|\frac{48n^2+24n+3-48n^2-8n+600}{18n^2+3n-225}\right|=\left|\frac{16n+603}{18n^2+3n-225}\right|.\] Since for all \(n\geq N\), \(n>75\), \(3n-225>0\). So \(|18n^2+3n-225|=18n^2+3n-225>18n^2\). So for all \(n\ge N\), \[\left|x_n-\frac{8}{3}\right|\le \frac{16n+603}{18n^2}=\frac{8}{9n}+\frac{67}{2n^2}<\frac{8}{9\left(\frac{16}{9\varepsilon}\right)}+\frac{67}{2\left(\sqrt{\frac{67}{\varepsilon}}\right)^2}=\frac{\varepsilon}{2}+\frac{\varepsilon}{2}=\varepsilon.\] Thus \(x_n\to \frac{8}{3}\).

Exercise 3.2.2. Let \(\varepsilon>0\). Since \(\{y_n\}\) is bounded, there exists an \(M>0\) such that for all \(n\in\mathbb{N}\), \(|y_n|\le M\). Since \(x_n\to0\), there exists an \(N\in\mathbb{N}\) such that for all \(n\ge N\), \(|x_n-0|<\frac{\varepsilon}{M}\). Thus, for all \(n\ge N\), \[|x_ny_n-0|=|y_n||x_n-0|\le M|x_n-0|<M\frac{\varepsilon}{M}=\varepsilon.\] So \(x_ny_n\to0\).

Notice that if \(\{y_n\}\) is unbounded, the conclusion may not be true. For example, consider \(x_n=\frac{1}{n}\) and \(y_n=n\). Then \(x_n\to 0\), but \(x_ny_n=1\) for all \(n\in\mathbb{N}\), and so \(x_ny_n\to 1\ne 0\).

Exercise 3.3.1. First, note that \(x_1=2>\frac{7}{6}\). Now, assume for some \(k\in\mathbb{N}\), \(x_k>\frac{7}{6}\). Then \[x_{k+1}=\frac{4x_k+7}{10}>\frac{\frac{14}{3}+7}{10}=\frac{7}{6}.\] So by induction, for all \(n\in\mathbb{N}\), \(x_n>\frac{7}{6}\). So \(\{x_n\}\) is bounded below.

Next, notice that \(x_1=2>\frac{3}{2}=x_2\). Now assume for some \(k\ge2\) that \(x_{k-1}>x_k\). Then \[x_{k+1}=\frac{4x_k+7}{10}<\frac{4x_{k-1}+7}{10}=x_k.\] Therefore, by induction, \(x_{n-1}>x_n\) for all \(n\ge 2\). Since \(\{x_n\}\) is bounded below by \(\frac76\) and decreasing, it is also bounded above by \(x_1\). So \(\{x_n\}\) is bounded and monotone. Therefore, \(\{x_n\}\) converges by Theorem 3.2.13, say \(x_n\to a\).

Now, since \(x_n\to a\), \(x_{n+1}\to a\) and so \(a=\frac{4a+7}{10}\). Therefore, \(a=\frac{7}{6}\).

Exercise 3.4.1. Hint. Choose \(n_1\) with \(x_{n_1}>1\). Given \(n_k\), use that \(\{x_n:n>n_k\}\) is not bounded above either.

Solution. First, for every \(N\in\mathbb{N}\), the set \(\{x_n:n>N\}\) is not bounded above. Otherwise there is an \(M\) with \(x_n\le M\) for all \(n>N\). Then every term is at most \(\max\{M,x_1,\dots,x_N\}\), and \(\{x_n\}\) is bounded above. That is a contradiction.

Now choose the indices one at a time. Since \(\{x_n\}\) is not bounded above, \(1\) is not an upper bound, so there is an \(n_1\) with \(x_{n_1}>1\). Suppose \(n_1<n_2<\cdots<n_k\) have been chosen with \(x_{n_j}>j\) for \(j=1,\dots,k\). Since \(\{x_n:n>n_k\}\) is not bounded above, there is an \(n_{k+1}>n_k\) with \(x_{n_{k+1}}>k+1\). This defines a strictly increasing sequence \(\{n_k\}\) with \(x_{n_k}>k\) for all \(k\in\mathbb{N}\). By Definition 3.4.1, \(\{x_{n_k}\}\) is the required subsequence.

Exercise 3.5.1. Hint. For \(m>n\), bound \(x_m-x_n\) using \(k!\ge2^{k-1}\) (Exercise 1.2.10) and Exercise 1.2.7.

Exercise 3.5.2. Let \(n\in\mathbb{N}\). Then \[x_{2n}-x_n=\sum_{k=n+1}^{2n}\frac1k\ge\sum_{k=n+1}^{2n}\frac{1}{2n}=n\cdot\frac{1}{2n}=\frac12,\] since each of the \(n\) terms is at least \(\frac{1}{2n}\).

Suppose \(\{x_n\}\) is Cauchy. With \(\varepsilon=\frac12\), there is an \(N\in\mathbb{N}\) such that \(|x_m-x_n|<\frac12\) for all \(m,n\ge N\). Take \(n=N\) and \(m=2N\). Then \(x_{2N}-x_N<\frac12\), which contradicts the inequality above. So \(\{x_n\}\) is not Cauchy. By the Cauchy Criterion (Theorem 3.5.2), \(\{x_n\}\) diverges.

Exercise 3.6.1. Let \(a=\limsup x_n\). If \(a=\infty\), then \(\infty\) is a cluster point by Theorem 3.6.12 (1), and it is the largest one. If \(a=-\infty\), then \(x_n\to-\infty\) by Theorem 3.6.12 (2), so every subsequence diverges to \(-\infty\), and \(-\infty\) is the only cluster point. So suppose \(a\in\mathbb{R}\).

First, \(a\) is a cluster point. Choose \(n_1<n_2<\cdots\) as follows. For each \(k\in\mathbb{N}\), by Theorem 3.6.11 with \(\varepsilon=\frac1k\), there exists an \(N_k\in\mathbb{N}\) such that \(x_n<a+\frac1k\) for all \(n\ge N_k\). By the same theorem, there exists an \(n_k\ge\max\{N_k,n_{k-1}+1\}\) with \(x_{n_k}>a-\frac1k\) (take \(n_0=0\)). Then \(|x_{n_k}-a|<\frac1k\) for every \(k\). So \(x_{n_k}\to a\), and \(a\) is a cluster point of \(\{x_n\}\).

Now, by way of contradiction, assume \(b\) is a cluster point of \(\{x_n\}\) with \(b>a\). Define \(\varepsilon=\frac{b-a}{2}>0\). Since \(b\) is a cluster point of \(\{x_n\}\), there exists a subsequence \(x_{n_j}\to b\). So there exists a \(J\in\mathbb{N}\) such that for all \(j\ge J\), \(|x_{n_j}-b|<\frac{b-a}{2}\). This implies that for all \(j\ge J\), \(x_{n_j}>b-\frac{b-a}{2}=\frac{a+b}{2}\). But, by Theorem 3.6.11, there exists an \(N\in\mathbb{N}\) such that for all \(n\ge N\), \(x_n<a+\frac{b-a}{2}=\frac{a+b}{2}\). Choose \(j_0\ge J\) with \(n_{j_0}\ge N\). Then \[\frac{a+b}{2}<x_{n_{j_0}}<\frac{a+b}{2},\] a contradiction. So \(a\) is the largest cluster point of \(\{x_n\}\). A similar argument shows \(\liminf x_n\) is the smallest cluster point of \(\{x_n\}\). Alternatively, apply the result to \(\{-x_n\}\) and use Theorem 3.6.10 (1).
